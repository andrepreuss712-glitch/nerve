Wave 6: OAuth-Härtung — oauth_id UNIQUE-Constraint + Microsoft Email-Hijacking-Mitigation.

**H-21: oauth_id UNIQUE-Constraint**
Verhindert, dass zwei User-Accounts dieselbe oauth_id haben können (z.B. durch Race-Conditions oder manuelle DB-Eingriffe). Partielle UNIQUE-Index auf NOT NULL-Werte (SQLite: WHERE oauth_id IS NOT NULL). Idempotent mit Duplicate-Check VOR Anlage.

**H-18: Microsoft-OAuth Email-Hijacking-Mitigation**
Microsoft-Accounts können je nach Tenant-Konfiguration nicht-verrifizierte Email-Adressen liefern. Im Gegensatz zu Google (email_verified=True in JWT) fehlt dieser Flag bei Microsoft. Mitigation: Neue Microsoft-User (erstmaliger Login) erhalten Confirmation-Email via email_service. email_confirmed=False wird gesetzt. User kann App nutzen (kein Redirect-Block), aber Email-Verification ist dokumentiert.

Option A implementiert: send_confirmation_email() neu erstellen (analog send_welcome). Kein Redirect-Block für unbestätigte Emails in dieser Phase (minimaler Eingriff, bestehende User unberührt).

Bestehende User-Pfade (existing-user in microsoft_callback): UNVERÄNDERT. Nur neue User (Neuanlage-Pfad) durchlaufen Email-Confirmation.

# H-21: oauth_id UNIQUE-Constraint (idempotent, mit Duplicate-Check)
try:
    with engine.connect() as db:
        from sqlalchemy import text
        # 1. Duplicate-Check VOR Constraint-Anlage
        dup_row = db.execute(text(
            "SELECT oauth_id FROM users WHERE oauth_id IS NOT NULL "
            "GROUP BY oauth_id HAVING COUNT(*) > 1 LIMIT 1"
        )).fetchone()
        if dup_row:
            print(f"[DB] STOPP: oauth_id-Duplicate gefunden ({dup_row[0]}) "
                  "— manuelle Bereinigung noetig vor UNIQUE-Index")
        else:
            # 2. Idempotent: CREATE UNIQUE INDEX IF NOT EXISTS (SQLite-spezifisch)
            db.execute(text(
                "CREATE UNIQUE INDEX IF NOT EXISTS uq_users_oauth_id "
                "ON users(oauth_id) WHERE oauth_id IS NOT NULL"
            ))
            db.commit()
            print("[DB] Migration: uq_users_oauth_id UNIQUE-Index OK")
except Exception as _e:
    print(f"[DB] oauth_id UNIQUE-Index Migration-Fehler: {_e}")
```

@auth_bp.route('/auth/confirm_email')
def confirm_email():
    """H-18: Email-Confirmation für Microsoft-OAuth-User. Phase 08.10 minimal-stub."""
    from itsdangerous import URLSafeTimedSerializer, BadSignature, SignatureExpired
    from config import SECRET_KEY
    token = request.args.get('token', '')
    db = get_session()
    try:
        email = URLSafeTimedSerializer(SECRET_KEY, salt='nerve-email-confirm').loads(token, max_age=86400)
        user = db.query(User).filter_by(email=email).first()
        if user:
            user.email_confirmed = True
            db.commit()
            flash('E-Mail erfolgreich bestätigt!', 'success')
        else:
            flash('Ungültiger Bestätigungslink.', 'error')
    except (BadSignature, SignatureExpired):
        flash('Bestätigungslink ungültig oder abgelaufen.', 'error')
    except Exception as _e:
        print(f'[AUTH] confirm_email error: {_e}')
        flash('Fehler bei der E-Mail-Bestätigung.', 'error')
    finally:
        db.close()
    return redirect(url_for('dashboard.index'))
```
