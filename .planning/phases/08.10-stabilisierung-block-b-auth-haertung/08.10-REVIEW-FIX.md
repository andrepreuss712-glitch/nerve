## Fixes Applied

### CR-02: OAuth TOCTOU — `email_confirmed=False` now atomic with user creation

**File:** `routes/oauth.py`
**Commit:** d6dce1a

Set `new_user.email_confirmed = False` directly on the `new_user` object (still in the open `db` session) **before** `session.clear()` + `_login_user(db, new_user)` + `db.commit()`. This means `email_confirmed=False` is committed atomically with user creation — no race window where the new Microsoft OAuth user could pass the H-18 gate with `email_confirmed=True`.

The separate `db_confirm` second DB session (lines 156–164) was removed entirely. `send_confirmation_email()` remains in the `try/except` block as before.

Acceptance verified:
- `grep -n "db_confirm" routes/oauth.py` → 0 Treffer
- `grep -n "new_user.email_confirmed = False" routes/oauth.py` → 1 Treffer (line 131)

### CR-01: `confirm_email` redirects to login with flash

**File:** `routes/auth.py`
**Commit:** 8ccc274

`url_for('auth.login')` verified via `app.test_request_context()` before commit → `/login`.
