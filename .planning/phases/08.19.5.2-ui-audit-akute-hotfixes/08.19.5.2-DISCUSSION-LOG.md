## Wizard-Fix-Richtung

### Teilfrage 1: JSON vs. FormData

| Option | Description | Selected |
|--------|-------------|----------|
| Backend auf JSON | request.get_json() — konsistent mit allen anderen API-Routen ab Zeile 343. Frontend bleibt fast unverändert, nur X-CSRFToken-Header hinzufügen. | ✓ |
| Frontend auf FormData | fetch() auf multipart/form-data umstellen. Backend-Feldnamen bleiben. Mehr Frontend-Änderungen. | |

**User's choice:** Backend auf JSON (Recommended)
**Notes:** Konsistenz mit existierendem API-Pattern entscheidend. CSRF-Pattern aus profile_editor.html kopieren.

- Plan-Phase Aufgaben: Pro Backend-Feld entscheiden (Pflicht-Wizard vs. optional-Editor), Frontend-Only-Felder klären (preismodell, phasen behalten oder entfernen), Cross-AI prüft Wizard-UX unter 5 Minuten.
