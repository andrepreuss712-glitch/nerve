## Cross-AI MEDIUM-3 Disposition

**MEDIUM-3 (Cross-AI 2026-05-03): PiP State-Loss v1 akzeptiert — SPEC.md Fallback-Acceptance.**

`window.documentPictureInPicture.requestWindow()` erfordert einen User-Gesture (Chrome-Spec). Ein programmatischer PiP-Neustart bei Navigation ist mit dieser API grundsaetzlich unmoeglich. Nahtloses PiP ("PiP ueberlebt Navigation") kann in v1 nicht implementiert werden.

**Implementierter Kompromiss (v1):**
- Bei Navigation weg + aktivem Call: `localStorage.setItem('nerve_pip_was_active', '1')` im pagehide-Handler
- Auf Zielseite: Inline-Script prueft Flag beim Laden, zeigt Re-Launch-Banner
- Banner-Klick: User-Gesture → `NerveLauncher.open()` → PiP neu starten
- Bei normalem Call-Ende: `localStorage.removeItem('nerve_pip_was_active')` in `_stopMic()`

**Architekturentscheidung im Code dokumentiert** (pip-launcher.js:1580-1583, Kommentar im pagehide-Handler).
