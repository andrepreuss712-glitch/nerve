<decisions>
## Implementation Decisions

### D-01: Logout-Intercept-Scope

- **D-01:** Interceptor-Selector ist `'.n-nav-item, a.popup-item-logout'` — erfasst sowohl alle Haupt-Nav-Links als auch den Logout-Link im User-Popup-Dropdown. Logout (`<a href="/logout" class="popup-item popup-item-logout">`) ist ein `<a>`-Tag, kein `<form>` — kein Form-Submit-Handler nötig.

### D-02: REQ-8 Form-Intercept — Obsolet (SPEC korrigiert)

- **D-02:** Form-Submit-Interception aus REQ-8 entfernt. In base.html existieren keine Nav-`<form>`-Elemente; der Logout ist ein `<a>`-Tag. SPEC.md wurde entsprechend aktualisiert. Plan-Agent implementiert nur `<a>`-Klick-Interception.

### D-03: Modal Show/Hide-Mechanismus

- **D-03:** `.n-modal-overlay` nutzt `classList.add/remove('open')` — konsistent mit bestehenden consent-overlay und headset-overlay in pip-launcher.js (Zeilen ~1095–1280). CSS in nerve.css: `.n-modal-overlay { display:none }` + `.n-modal-overlay.open { display:flex; ... }`.

### D-04: login.html Fallback-Strategie

- **D-04:** Plan-Agent sucht NICHT explizit nach "login.html". Stattdessen: Grep aller `templates/*.html` nach hardcoded Dark-Mode-Farben (`#0c0c18|#1a1a2e|#2e2e48` etc.) — alle Treffer die noch nicht in der bekannten 8er-Liste sind, kommen in Wave 1. Namens-Frage löst sich selbst.

### Claude's Discretion

- Token-Mapping-Tabelle (#0c0c18 → var(--X) etc.): Plan-Agent erstellt Tabelle via Grep von nerve.css `:root {}` vor erstem Edit (REQ-2-Pflicht). Keine Vorab-Festlegung durch Andre.
- Wave-Reihenfolge (Wave 1 vollständig committed vor Wave 2): wie in SPEC, Plan-Agent entscheidet Granularität der Plans.
- Prüfung ob programmatic navigation via `onclick` in `.n-nav-item`-Links vorkommt: `<a href="javascript:void(0)" onclick="NerveLauncher.open()">` triggert keinen Page-Load → kein Intercept-Bedarf. Plan-Agent verifiziert ob weitere onclick-Nav-Links existieren.

</decisions>

## Existing Code Insights

### Reusable Assets
- **pip-launcher.js headset-overlay** (Zeilen ~1183–1280): Vollständigstes Modal-Pattern — ESC-Handler via `document.addEventListener('keydown', onKeydown)` + Cleanup via `removeEventListener`, Overlay-Click `if (e.target === overlay)`. Direkt als Vorlage für `.n-modal-overlay`-Implementierung.
- **pip-launcher.js lnr-overlay** (Zeilen ~1063–1088): Nutzt bereits `var(--page-bg,#fff)` + `var(--glass-border)` — beweist Token-Konsistenz in pip-launcher.js-Overlays.

### Established Patterns
- Modal-CSS: `.overlay { display:none }` + `.overlay.open { display:flex; position:fixed; inset:0; z-index:... }` — aus consent/headset-overlay in pip-launcher.js
- Overlay-Click-Dismiss: `overlay.onclick = (e) => { if (e.target === overlay) schließen() }` — aus lnr-overlay
- ESC-Handler: `document.addEventListener('keydown', fn)` mit `if (e.key === 'Escape')` + `removeEventListener` beim Schließen — aus consent/headset-overlay

### Integration Points
- `pip-launcher.js` `state.micStarted` — Bedingung für Intercept (gesperrt in SPEC)
- `pip-launcher.js` Intercept-Selector: `document.querySelectorAll('.n-nav-item, a.popup-item-logout')` (D-01)
- `base.html` dormanter Modal-`<div id="nerveNavModal" class="n-modal-overlay">` — wird von pip-launcher.js per `classList.add('open')` geöffnet
