### WR-03: `_briefing_cache` Is a Module-Level Mutable Dict — Thread-Safety Risk

**Files modified:** `services/precall_service.py`
**Commit:** 4ee8050
**Applied fix:** Added `import threading` to the module imports and declared `_cache_lock = threading.Lock()` alongside `_briefing_cache`. Wrapped the eviction loop + cache read in `recherche_firma()` with `with _cache_lock:`, and wrapped the cache write (after `empfehlungen` are set) with `with _cache_lock:`. The eviction and read are batched in the same lock acquisition to avoid a TOCTOU window. The cache hit TTL check after the lock release is a benign double-check (reads a local `cached` value already captured under the lock).
