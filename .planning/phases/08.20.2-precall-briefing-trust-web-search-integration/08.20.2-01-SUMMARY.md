## What Was Built

### PRECALL_FIELDS_SYSTEM_PROMPT
New system prompt replacing `PRECALL_SYSTEM_PROMPT` with:
- **Confidence rules** (D-03): `high` (1 Primaerquelle or ≥2 independent), `medium` (1 Sekundaerquelle), `not_found` (no data or contradiction)
- **Source hierarchy** (D-07): PRIMAER (Impressum, Handelsregister, Bundesanzeiger, offizielle Website), SEKUNDAER (LinkedIn, Crunchbase, North Data, Wikipedia, Wirtschaftsmedien), AUSGESCHLOSSEN (Reddit, Kununu, Glassdoor, AI-generated)
- **Widerspruchs-Regel**: conflicting values across sources → `not_found`
- **36-month freshness rule**: sources older than 36 months excluded for factual statements (except Gruendungsjahr)
- **Few-shot example**: complete SAP SE fields JSON demonstrating all confidence levels and `not_found` structure
- **Schicht-2 hardening rules** (REQ-5): factual claims must derive from Schicht-1 fields or be marked `(Annahme)` / `(nicht verifiziert)`

### _generiere_briefing() (Schicht-1+2)
Returns `{fields, text, firmenname, ansprechpartner, quellen_count}`:
- Parses Claude JSON response with markdown code fence stripping
- Graceful degradation: JSON parse error → all 4 Pflichtfelder set to `NOT_FOUND_FIELD`
- Field validation: extra keys stripped via dict comprehension, confidence whitelist enforced
- `not_found` enforcement: `value == 'not_found'` and `source_url == None` always normalized
- Optional fields removed from `fields` if `confidence == 'not_found'`
- `max_tokens` increased to 1200 (JSON output larger than free text)

### _generiere_empfehlungen() (Schicht-3)
New standalone function:
- Must be called AFTER `set_briefing_for_sid()` for Section 8 of `build_profile_context()` to be populated
- Logs `[PreCall] Empfehlungen: sid=None, Section 8 nicht im Kontext (non-fatal)` when `sid=None`
- Only uses fields with `confidence in ('high', 'medium')` as factbase — no hallucinated data
- Returns `''` when no verified fields exist (observable log message emitted)
- Non-fatal failure pattern: `build_profile_context` import errors degrade gracefully

### recherche_firma() Orchestration
- **Cache key**: `f"{firmenname.strip().lower()}_{profile_id}"` (D-06 — profile-specific)
- **Call order**: `_generiere_briefing()` → `set_briefing_for_sid()` → `_generiere_empfehlungen()`
- **Cache stored AFTER** `briefing['empfehlungen'] = empfehlungen` — cache hits return full 6-key dict
- `set_briefing_for_sid()` receives `schicht1_summary + "\n\n" + text` (NOT empfehlungen)
- Return dict: 6 keys — `fields`, `text`, `empfehlungen`, `firmenname`, `ansprechpartner`, `quellen_count`

### _brave_search() Query Sharpening (D-01)
Query changed from `firmenname + ansprechpartner + branche` to:
`f"{firmenname} Impressum Geschäftsführer Mitarbeiterzahl {branche or ''}"`
This biases results toward Primaerquellen for better per-field URL mapping.
