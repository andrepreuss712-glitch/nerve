## What Was Built

### templates/base.html — Confidence Card CSS

Added 15 CSS rules after `.launcher-briefing-html strong`:

- `.precall-fields-grid` — CSS Grid, 2 columns, gap 8px, collapses to 1 column at `max-width: 480px`
- `.precall-field-cell` — glass card per field (border-radius 8px, min-height 52px)
- `.precall-field-label` / `.precall-field-value` — typography base styles
- `.confidence-high` — green (#00D4AA) icon and label color
- `.confidence-medium` — yellow (#F59E0B) icon and label color
- `.confidence-not-found` — muted icon/label, value with `opacity: .6`
- `.precall-section-label` — uppercase 11px section headers with letter-spacing
- `@media(max-width:480px)` — responsive single-column collapse

### static/pip-launcher.js — renderStep4() rewrite

Replaced flat markdown-block layout with 3 DOM sections:

**Sektion A — Pflichtfeld-Karte:**
- `REQUIRED_KEYS = ['geschaeftsfuehrer', 'branche', 'mitarbeiterzahl', 'hauptprodukt']`
- `CONFIDENCE_ICONS = { high: '✓', medium: '~', not_found: '—' }`
- `buildFieldCell()` renders each field with confidence CSS class, icon, label, value
- `not_found` fields always visible with "Nicht gefunden" dimmed text
- `escHtml(conf)` applied to CSS class interpolation (T-08.20.2-11 mitigation)
- `escHtml(f.value)` applied to all non-not_found values (T-08.20.2-09 mitigation)

**Sektion B — Fliesstext:**
- Rendered via `mdToHtml(briefingText)` with view/edit toggle
- Edit button: `(hasAnyData && briefingText)` condition — absent when no Fliesstext
- Toggle switches between view div and textarea; button text changes to "Vorschau"

**Sektion C — Empfehlungen:**
- `empfHtml` built from `briefingObj.empfehlungen` via `mdToHtml(empfehlungen)`
- Inline comment: `// mdToHtml sanitizes — safe` (T-08.20.2-13 mitigation — verified mdToHtml escapes &/</>)
- Section only rendered when `empfehlungen` is non-empty

**api_beenden payload:**
- Added `precall_fields: (state.precallBriefing && state.precallBriefing.fields) ? state.precallBriefing.fields : null`
- Provides Schicht-1 fields dict to Plan 02 backend persistence
