## Architektur-Entscheidung (André 2026-07-01, Leitsatz 3 Drei-Wege)
**Wo wohnen die Antwort-Regeln (Paradigma + 3 Rollen)? → WEG 3: Datei + Andock-Stelle.**
Die Regeln kommen als Text in eine Code-Datei (`services/answer_paradigm.py`, der „NERVE-Standard").
`build_answer_context()` liest sie über EINE markierte Andock-Stelle `load_answer_config(user_id, sid)`.
Heute gibt die Andock-Stelle den Python-Standard zurück; wenn die Coach-Tür (DB) drankommt, klinkt
sie sich dort ein — ohne den Antwort-Pfad neu aufzureißen. Klein + schnell (keine DB im Live-Pfad) +
Anti-Abrieb. Foundation-Register-Eintrag markiert die Andock-Stelle.
