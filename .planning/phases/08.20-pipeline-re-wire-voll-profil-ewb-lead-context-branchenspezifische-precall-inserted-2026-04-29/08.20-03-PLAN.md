<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SocketIO SID → set_briefing_for_sid() | Only authenticated SocketIO connections should write briefings |
| User profile data → QA system prompt | Cross-contamination risk if wrong user's context injected |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-0820-11 | Information Disclosure | recherche_firma() writes to _per_sid_briefing — must verify SID belongs to calling user | mitigate | set_briefing_for_sid() only called in recherche_firma() success path, which is triggered by authenticated user action (SocketIO event with their SID). No SID injection possible — Flask-SocketIO validates SID belongs to the emitting socket. |
| T-0820-12 | Information Disclosure | QA pipeline receives build_profile_context(user_id, sid) — wrong user_id could leak another user's profile | mitigate | user_id is sourced from Flask session (g.user.id) or SocketIO session — not from untrusted input. Org-scoped in DB query. |
| T-0820-13 | Tampering | Malicious content in PRECALL_SYSTEM_PROMPT via branche string injection | mitigate | build_branchen_hint() is a pure static dict lookup — branche string only used as a dict key after .lower().strip(). No string interpolation of user content into prompt template. |
| T-0820-14 | Spoofing | Anti-Header-Constraint bypass — LLM ignores instruction | accept | Anti-Header-Constraint is best-effort instruction. Even if LLM produces a ## header in briefing, it gets embedded in Sektion 8 as freetext — it cannot override the outer 9-section structure built by build_profile_context(). Low risk. |
</threat_model>
