# Phase 08.20 Plan 02: 9-Section build_profile_context + _profile_cache + BUG-A/BUG-B Fix Summary

**One-liner:** Rewrote `build_profile_context()` to deterministic 9-section Markdown with warm `_profile_cache` hot path (0 DB queries, < 5ms), fixed BUG-A (`build_ewb_prompt()` now passes `sid`) and BUG-B (FAQ reads from `_profile_cache`, not global `ls.state`).

## What Was Built

### Task 1: 9-Section build_profile_context() + _profile_cache Loading + BUG-B Fix

**services/prompt_pipeline.py — complete rewrite of build_profile_context():**

9-section canonical order (D-01 LOCKED):
1. `## Branche` — `basis.branche` + `basis.branche_kontext`
2. `## Basis` — unternehmen/Produkt/Preismodell/Konsequenz/USPs/Eigene Formulierungen/Beweise/Opener
3. `## Zielkunde` — zielkunde.* + zielgruppe.* fields
4. `## Schmerzen` — schmerzen dict/list rendered as bullet list (sorted keys for determinism)
5. `## Einwände` — `einwaende_detail` as `- {einwand} ({einwand_typ}) | {gegenargument}`
6. `## Phasen` — numbered list `1. {name}`
7. `## KI-Verhalten` — Anrede + ton/wisdom/stil
8. `## PreCall-Briefing` — per-SID volatile, from `get_briefing_for_sid()`
9. `## Lead-Kontext` — per-SID volatile, session_anrede + vorwissen_level

**HOT PATH (sid + _profile_cache populated):**
- `pdata` from `get_profile_for_sid(sid)` — no DB
- `opener_content`, `faqs` from `_session_state[sid]['_profile_cache']` — no DB
- `briefing` from `_session_state[sid]['_briefing']` — no DB
- Total DB queries: 0, latency < 5ms (HIGH-3 fix)

**FALLBACK (sid=None or cache absent):**
- Lightweight DB query: User → active_profile_id → Profile.daten
- Lightweight DB query: ProfileOpener ORDER BY id LIMIT 1
- Lightweight DB query: ProfileFaq LIMIT 20

**BUG-B fix:** Removed `with ls.state_lock: _faq_profile_id = ls.state.get('active_profile_id')` pattern. FAQs now read from `_profile_cache['faqs']` (hot path) or fresh DB query (fallback).

**_resolve_anrede() updated:** Now checks `_session_state[sid]['session_anrede']` first (per-SID), then falls back to `ls.state['session_anrede']` (legacy global, HTTP paths).

**services/live_session.py — _load_profile_cache() added:**

```python
def _load_profile_cache(sid: str, user_id: int, profile_id: int) -> None:
```

Loads at session start:
- `ProfileOpener` — ORDER BY id LIMIT 1 (deterministic) → stored as `opener_content` using field `inhalt`
- `User.vorname` → stored as `user_firstname`
- `ProfileFaq` mode='literal' LIMIT 20 (fallback: all FAQs) → stored as list `[{'q': frage_muster, 'a': antwort}]`

Ghost-SID safe: checks `sid in _session_state` under lock before writing.

**services/deepgram_service.py — _load_profile_cache() call added:**

After `set_profile_for_sid()` in the Phase 08.19.4 block, `_load_profile_cache(sid, user_id, profile_id)` is called with the already-resolved `_profile_id2`. Non-fatal try/except wraps the call.
