## setdefault Race Guards (MEDIUM fix — from REVIEWS.md)

Pattern to apply at the TOP of each of the two SocketIO handlers (`start_live_session`,
`disconnect`) in deepgram_service.py, before any read/write on `_session_state[sid]`:

```python
# setdefault race guard: audio/events may arrive before init hook completes (MEDIUM fix 08.20)
with ls._session_state_lock:
    ls._session_state.setdefault(_sid, {})
```

Where `_sid` is the local SID variable (either `request.sid` or the resolved sid).
This is a safe no-op if the key already exists — `setdefault` only inserts if absent.

Note: `_make_on_message()` already has `ls._per_sid_profile.setdefault(sid, ('', {}))` under
`_per_sid_lock`. The `_session_state` guard is the missing parallel for that dict.

## Du-form detection helper

```python
_DU_FORMS = [
    'kannst du', 'hast du', 'bist du', 'machst du', 'willst du',
    'weisst du', 'denkst du', 'sagst du', 'hoerst du',
    'siehst du', 'brauchst du', 'kennst du', 'findest du', 'glaubst du',
]
# CLAUDE.md ASCII rule: variable names use ASCII; string content may use real Umlauts.
# Note: 'weißt du' spelled as 'weisst du' in the list (ASCII-safe for pattern matching).

def _check_anrede_switch(sio, sid: str, transcript_text: str, ls_module) -> None:
    """Check if transcript contains Du-forms indicating anrede switch. Non-blocking."""
    try:
        text_lower = transcript_text.lower()
        _du_count = sum(1 for form in _DU_FORMS if form in text_lower)
        if _du_count >= 2:
            _current_anrede = 'sie'
            try:
                with ls_module._session_state_lock:
                    _current_anrede = ls_module._session_state.get(sid, {}).get('session_anrede', 'sie')
            except Exception:
                pass
            if _current_anrede == 'sie':
                sio.emit('anrede_switch_detected', {
                    'detected_form': 'du',
                    'confidence': round(min(1.0, _du_count / 3.0), 2),
                    'sid': sid,
                }, room=sid)
                print(f"[Anrede-Detection] Du-switch detected: {_du_count} forms in utterance sid={sid}")
    except Exception as _ae:
        print(f"[Anrede-Detection] check failed (non-fatal): {_ae}")
```

function loadEwbPreview() {
  var btn = document.getElementById('ewb-preview-btn');
  var loading = document.getElementById('ewb-preview-loading');
  var output = document.getElementById('ewb-preview-output');
  var pre = document.getElementById('ewb-preview-pre');
  var empty = document.getElementById('ewb-preview-empty');
  var err = document.getElementById('ewb-preview-error');

  // Get profile_id from URL path
  var profileId = window.location.pathname.split('/').filter(Boolean).pop();

  btn.disabled = true;
  btn.textContent = 'Wird geladen…';
  loading.style.display = 'inline';
  empty.style.display = 'none';
  err.style.display = 'none';

  fetch('/api/profile/preview-context?profile_id=' + encodeURIComponent(profileId))
    .then(function(r) {
      if (!r.ok) throw new Error('HTTP ' + r.status);
      return r.json();
    })
    .then(function(data) {
      pre.textContent = data.context || '(leer)';
      output.style.display = 'block';
      btn.textContent = 'Neu laden';
    })
    .catch(function() {
      err.style.display = 'block';
      btn.textContent = 'Vorschau laden';
    })
    .finally(function() {
      btn.disabled = false;
      loading.style.display = 'none';
    });
}
