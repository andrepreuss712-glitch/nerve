# Plan 05 Summary — Lead-Kontext UI Components + Backend Handlers

## What Was Built

### D-05: Vorwissen-Picker (Option C)
- Launcher Step 4b (`lnr-step-vorwissen`) inserted between PreCall result acceptance and Skript-Auswahl (Step 5)
- 4 pills: Wenig Ahnung / Vertraut damit / Kennt uns gut / Weiß nicht (default active = null)
- `vorwissen_level` sent in `session-start` SocketIO payload alongside anrede
- PiP Override-Indicator in base.html sidebar with edit flyout (`pip-vorwissen-indicator` / `pip-vorwissen-edit`)
- `set_vorwissen` SocketIO handler writes to `_session_state[sid]['vorwissen_level']`

### D-06: Du/Sie Toggle + Auto-Detection (Option A)
- Du/Sie toggle row in PiP sidebar (`pip-anrede-du` / `pip-anrede-sie` buttons)
- `set_anrede` SocketIO handler validates `du`/`sie` and writes to `_session_state[sid]['session_anrede']`
- `anrede_switch_rejected` handler logs rejection for algorithm tuning (no state change)
- `_DU_FORMS` list (15 du-forms, ASCII-safe) + `_check_anrede_switch()` helper at module level in deepgram_service.py
- Du-detection called in `_make_on_message` on `result.is_final` — 2-trigger threshold per utterance
- `anrede_switch_detected` emitted → Toast displayed in PiP with confirm/dismiss buttons
- Toast debounce: 60s minimum between toasts, auto-dismiss after 15s

### D-08: EWB-Preview-Panel (Option B — On-Demand)
- Section 7 "Was die KI über dieses Profil sieht" in profile_editor.html
- "Vorschau laden" button triggers `loadEwbPreview()` → `GET /profiles/api/profile/preview-context?profile_id=<id>`
- Endpoint: `@profiles_bp.route('/api/profile/preview-context')` in routes/profiles.py
- Org-scoping: `profile.org_id == g.user.org_id` → 403 on mismatch
- Calls `build_profile_context(user_id=g.user.id, sid=None)` — sections 8+9 show fallback markers
- Response rendered in `<pre>` block with monospace font, max-height 600px, scrollable

### MEDIUM Fix: setdefault Race Guards
- `_session_state.setdefault(_sid, {})` added at top of `handle_start_live_session` (under `_session_state_lock`)
- Same guard added at top of `handle_disconnect`
- Prevents KeyError if `vorwissen_level` or other SocketIO events arrive before `init_session_state()` completes
