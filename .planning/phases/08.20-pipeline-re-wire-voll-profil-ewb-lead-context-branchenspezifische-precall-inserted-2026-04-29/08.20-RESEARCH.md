## Gap 1: Streaming-Status im EWB-Pfad

### streame_manual_ewb_variante() — STREAMING AKTIV

`services/claude_service.py:706-716`:
```python
with claude_client.messages.stream(
    model=config.MODEL_PIP_VARIANTE,
    max_tokens=250,
    system=_system_manual,
    messages=[{'role': 'user', 'content': user_msg}]
) as stream:
    for token in stream.text_stream:
        full_text += token
        sio.emit('pip_token', {'slot': slot, 'token': token, 'raw_text': True}, room=sid)
```

Streaming ist vollstaendig aktiv. Tokens werden per `socketio.emit('pip_token', ...)` per Token an den SID-Raum gepusht. `claude_client.messages.stream()` (synchrones Python SDK streaming) wird verwendet, NICHT async.

### streame_auto_variante() — STREAMING AKTIV

`services/claude_service.py:597-605`:
```python
with claude_client.messages.stream(
    model=config.MODEL_PIP_AUTOVAR,
    max_tokens=200,
    system=_system_autovar,
    messages=[{'role': 'user', 'content': user_msg}]
) as stream:
    for token in stream.text_stream:
        full_text += token
        sio.emit('pip_token', {'slot': slot, 'token': token, 'raw_text': True}, room=sid)
```

Gleiches Muster. Beides ist `streame_auto_variante()` (auto-trigger via Keyword-Matcher oder analyse_loop). Das ist der EWB-Auto-Variant-Pfad.

### Haupt-Analyse-Loop (analysiere_mit_claude) — KEIN STREAMING

`services/claude_service.py:500-504`:
```python
msg = claude_client.messages.create(
    model=config.MODEL_ANALYSE,
    max_tokens=400,
    ...
)
```

`messages.create()` — kein Streaming. Das ist korrekt: analyse_loop liefert JSON-Einwand-Erkennung, kein lesbarer Text. Streaming waere hier falsch.

### Token-Push-Pattern: SocketIO per Token

Drei Events werden emittiert (alle mit `room=sid`):
- `pip_stream_start` — vor erstem Token, initialisiert Frontend-Slot
- `pip_token` — pro Token, payload `{slot, token, raw_text: True}`
- `pip_token_done` — nach letztem Token, payload `{slot, result, raw_text: True}`

Fehlerfall: `pip_stream_error` mit friendly error string.

**Frontend-Pattern:** `static/app.js` oder `templates/live.html` — Empfaenger dieser Events — wurde nicht gelesen, aber die Emit-Seite zeigt das Protokoll eindeutig.

### Ergebnis fuer Plan-01

Streaming ist bereits aktiv fuer beide EWB-Pfade (manual + auto). Plan-01 muss KEIN Streaming aktivieren. Plan-01 muss:
1. Das System-Prompt beider Pfade auf Voll-Profil-Kontext upgraden (aktuell: minimalistische hardcoded 1-Liner).
2. `MODEL_PIP_AUTOVAR` von Haiku auf Sonnet switchen (per D-07 LOCKED) — ENV-Var existiert bereits in `config.py:64`.

### aktuelles Modell EWB-Pfade

`config.py:64-65`:
```python
MODEL_PIP_AUTOVAR  = os.getenv("MODEL_PIP_AUTOVAR",  "claude-haiku-4-5-20251001")
MODEL_PIP_VARIANTE = os.getenv("MODEL_PIP_VARIANTE", "claude-haiku-4-5-20251001")
```

Beide Default = Haiku. D-07 (DACH Sonnet-Default) erfordert: `MODEL_PIP_AUTOVAR` Default-Aenderung auf `claude-sonnet-4-5-20251022` fuer DACH. ENV-Var-Override ist schon implementiert.

## Gap 4: Caching-Cost-Implication Voll-Profil

### Aktuelle build_profile_context() Token-Schaetzung

Aktuell emittierte Felder (aus `services/prompt_pipeline.py:152-229`):

| Feld | Typische Laenge | Ca. Chars |
|------|-----------------|-----------|
| Unternehmen | 1 Zeile | ~50 |
| Produkt | 1-3 Saetze | ~200 |
| Preismodell | 1 Zeile | ~80 |
| USPs (Liste) | 3-5 Items | ~200 |
| Konsequenz | 1-2 Saetze | ~120 |
| branche_kontext | 1-2 Saetze | ~150 |
| eigene_formulierungen (Liste) | 2-5 Items | ~200 |
| beweise (Liste) | 2-4 Items | ~200 |
| FAQ-Block (bis 20 FAQs) | 20x (F+A) | ~2000 |
| Ton/Stil | 1 Zeile | ~50 |
| Anrede-Constraint | 1 Zeile | ~80 |
| Tabu-Instruction | 0-300 Chars | ~200 |
| **Total heute** | | **~3530 Chars** |

Ca. 3530 Chars / 4 = ~880 Token. Der Cache-Threshold ist `4096 chars` (`claude_service.py:9`: `_CACHE_MIN_CHARS = 4096`). **Heute wird die Threshold mit einem normalen Profil NICHT ueberschritten** (3530 < 4096).

Cache-Control wird auf das System-Prompt-Objekt gesetzt (nicht Messages). Gleiche Struktur in `streame_auto_variante` (`claude_service.py:585-591`) und `qa_pipeline.generate_qa_response()` (`qa_pipeline.py:415-416`).

### Voll-Profil 9-Sektionen Token-Schaetzung

D-01 9 Sektionen (aus CONTEXT.md):

| Sektion | Typische Laenge | Ca. Chars |
|---------|-----------------|-----------|
| ## Branche (branche + branche_kontext) | 2-3 Zeilen | ~250 |
