**One-liner:** Session-detail-Route liefert jetzt sechs neue Template-Context-Keys (3 Scoring-Listen aus phasen_details + 2 Kunden-Meta aus PersonalityType.name + schwierigkeit_raw), und `/training/end` liefert log_id fuer Wave-3-Redirect — alles aus bestehenden DB-Feldern, keine Migration.

## What Was Built

### routes/dashboard.py

**Helper `_parse_kunden_meta(pt_name)`** (lines 16-29):
- Parst `PersonalityType.name`-Strings via Regex `^(.+?),\s*(\d+)$`
- `'Markus Wendland, 48'` → `('Markus Wendland', '48')`
- Archetype-Namen ohne Komma-Alter (`'Beschaeftigter Chef'`) → `(None, None)`
- Empty-String / None → `(None, None)` (T-07.2-03 Information-Disclosure-Mitigation)
- Verwendet module-level `import re` (Zeile 2), keine neue Import-Zeile noetig

**session_detail() Context-Erweiterung** (Zeilen 821-865):
- **schwierigkeit_raw** (Zeilen 821-834): raw-Key-Extraktion aus phasen_details ('leicht'|'mittel'|'schwer'|None). Whitelist-gesichert. Nur gesetzt wenn schwierigkeit_label erfolgreich geparsed wurde → garantiert konsistent zu schwierigkeit_label.
- **scoring_kategorien / scoring_wendepunkte_detail / scoring_verbesserungen** (Zeilen 836-857): Drei unabhaengige Dict-Lookups aus phasen_details mit isinstance-Guards (pd ist dict? _cat/_wp/_vb ist list?). Silent-except-pass → Template rendert Empty-State.
- **kunden_name / kunden_alter** (Zeilen 859-865): Training-only; faellt auf `(None, None)` zurueck fuer Archetype-Namen.

**render_template() Erweiterung** (Zeilen 893-902):
- 6 neue Kwargs angehaengt; alle bestehenden Kwargs unveraendert (Phase 07.1 Regression-Schutz).

### routes/training.py

**training_end() Response-Erweiterung** (3 Blocks):
- `_log_id = None` Default vor dem ConversationLog-try-Block (Zeile 694) — robust gegen DB-Fehler.
- `_log_id = log_entry.id` direkt nach `db_log.commit()` (Zeile 762) — vor Engine-try-Block + vor `db_log.close()` gelesen (CLAUDE.md Pattern).
- `result['log_id'] = _log_id` direkt vor `return jsonify(result)` (Zeile 814) — injiziert Feld in bestehende result-dict ohne generate_scoring()-Output zu touchieren.
