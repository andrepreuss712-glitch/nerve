## What Was Built

### Task 1: Backup Script + Infrastructure Docs

**scripts/backup_postgres.sh:**
- `#!/bin/bash` shebang (C-6a requirement — bash-specific features used)
- `pg_dump nerve | gzip` to `/opt/nerve/backups/postgres/nerve-TIMESTAMP.sql.gz`
- Size check: file < 1KB → delete + `exit 1` (catches silent pg_dump failures, T-08.23.2.A-08-04 mitigation)
- 30-day rolling retention: `find -name "nerve-*.sql.gz" -mtime +30 -delete` (T-08.23.2.A-08-02 mitigation)

**docs/systemd-backup-setup.md:**
- Full content for all 3 unit files: `nerve-backup.service`, `nerve-backup.timer`, `nerve-backup-alert.service`
- `OnCalendar=*-*-* 03:30:00`, `Persistent=true`, `RandomizedDelaySec=15min`
- Activation command sequence for post-cutover server setup

**deploy.sh:**
- Server-side pytest step inserted before `systemctl restart nerve`
- `TEST_DATABASE_URL=postgresql://nerve_test_user@/nerve_test` passed explicitly
- `PYTEST_EXIT=$?` (C-6a: not PIPESTATUS — works under both bash and sh in heredoc context)
- Deploy aborts with clear error message on test failure

### Task 2: /api/health + Dashboard Warning

**routes/app_routes.py — new `/api/health` route:**
- No `@login_required` — health checks are public operational endpoints
- **C-6b env guard:** `os.environ.get('DATABASE_URL', '')` checked first; if not starting with `postgresql` → return `backup_status='ok'` immediately (no filesystem access in local dev/SQLite)
- Production path: glob `/opt/nerve/backups/postgres/nerve-*.sql.gz`, compute age from mtime
- Thresholds: age <= 25h → `ok`; age > 25h → `stale`; no files → `missing`
- Response: `{'status': 'ok', 'backup_status': ..., 'backup_age_hours': ...}`

**templates/dashboard.html — warning strip:**
- `<div id="backup-warning-strip">` inserted at top of `{% block content %}`, `display:none` by default
- Inline `<script>` does `fetch('/api/health')` on page load
- Shows strip only when `backup_status !== 'ok'`
- Detail text: "Letztes Backup vor X Stunden." (stale) or "Kein Backup gefunden." (missing)
- Silent `catch` block — non-critical warning never causes console errors
