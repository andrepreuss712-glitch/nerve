**Section 3: Create Databases (exact SQL from D-13)**
```sql
-- Run as postgres user: sudo -u postgres psql
CREATE DATABASE nerve WITH ENCODING 'UTF8' LC_COLLATE='de_DE.UTF-8' LC_CTYPE='de_DE.UTF-8' TEMPLATE template0;
CREATE DATABASE nerve_test WITH ENCODING 'UTF8' LC_COLLATE='de_DE.UTF-8' LC_CTYPE='de_DE.UTF-8' TEMPLATE template0;
```

**Section 4: Create Users with Restricted Permissions (D-14)**
```sql
-- Create nerve_app user (production)
CREATE USER nerve_app;  -- no password: unix socket peer auth

-- Create nerve_test_user (test DB only)
CREATE USER nerve_test_user;

-- Grant permissions on nerve DB (no DROP/CREATE/ALTER/TRUNCATE)
GRANT CONNECT ON DATABASE nerve TO nerve_app;
GRANT USAGE ON SCHEMA public TO nerve_app;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO nerve_app;
GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO nerve_app;

-- ALTER DEFAULT PRIVILEGES so future tables from 08.23.2.F/G/H are automatically accessible
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT, INSERT, UPDATE, DELETE ON TABLES TO nerve_app;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT USAGE, SELECT ON SEQUENCES TO nerve_app;

-- Grant permissions on nerve_test DB
GRANT CONNECT ON DATABASE nerve_test TO nerve_test_user;
\c nerve_test
GRANT USAGE ON SCHEMA public TO nerve_test_user;
GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO nerve_test_user;
GRANT USAGE, SELECT ON ALL SEQUENCES IN SCHEMA public TO nerve_test_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT SELECT, INSERT, UPDATE, DELETE ON TABLES TO nerve_test_user;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT USAGE, SELECT ON SEQUENCES TO nerve_test_user;
```

**Section 5: Configure Unix Socket Auth (D-15)**
```bash
# Edit pg_hba.conf (location: /etc/postgresql/16/main/pg_hba.conf)
# Add these lines BEFORE the "local all all peer" default line:

# nerve production app
local   nerve       nerve_app                           peer
# nerve test runner
local   nerve_test  nerve_test_user                     peer

# Edit postgresql.conf:
# Set: listen_addresses = ''   (disable TCP entirely)

# Reload Postgres
systemctl reload postgresql
```

**Section 6: Configure Linux Users for Peer Auth**
```bash
# Peer auth requires matching Linux user. The app runs as www-data.
# Create postgres role for www-data:
sudo -u postgres createuser --no-superuser --no-createdb --no-createrole www-data 2>/dev/null || true
# (nerve_app must match the Linux user running the app — verify: ps aux | grep gunicorn)

# If app runs as www-data, rename nerve_app → www-data approach won't work cleanly.
# Better: create a dedicated 'nerve_app' Linux user that gunicorn runs as:
adduser --system --no-create-home --shell /bin/false nerve_app
# Then in /etc/systemd/system/nerve.service: User=nerve_app
# Update gunicorn to run as nerve_app user
```

**Section 7: Verify Connection**
```bash
# Switch to nerve_app Linux user and test:
sudo -u nerve_app psql -d nerve -c "SELECT version();"
# Expected: PostgreSQL 16.x ...
```

**Section 8: Set DATABASE_URL in .env**
```bash
# On server, edit /opt/nerve/app/.env:
DATABASE_URL=postgresql://nerve_app@/nerve

# Verify:
grep DATABASE_URL /opt/nerve/app/.env
```

**Section 9: Dry-Run Test (3-5 days before cutover)**
```bash
# On server, with app still running on SQLite:
cd /opt/nerve/app
SQLITE_URL=sqlite:///database/nerve.db \
DATABASE_URL=postgresql://nerve_app@/nerve \
DRY_RUN=1 \
/opt/nerve/venv/bin/python scripts/migrate_to_postgres.py

# If dry-run OK, run actual migration against Postgres:
SQLITE_URL=sqlite:///database/nerve.db \
DATABASE_URL=postgresql://nerve_app@/nerve \
/opt/nerve/venv/bin/python scripts/migrate_to_postgres.py

# Verify:
DATABASE_URL=postgresql://nerve_app@/nerve \
/opt/nerve/venv/bin/python scripts/validate_postgres_migration.py

# After dry-run: truncate all Postgres tables (so production cutover starts fresh):
sudo -u nerve_app psql -d nerve -c "
  DO \$\$ DECLARE r RECORD;
  BEGIN
    FOR r IN SELECT tablename FROM pg_tables WHERE schemaname = 'public' LOOP
      EXECUTE 'TRUNCATE TABLE ' || quote_ident(r.tablename) || ' CASCADE';
    END LOOP;
  END \$\$;
"
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hetzner VPS → Postgres unix socket | No TCP access; peer auth only — reduces attack surface |
| nerve_app user → nerve DB | No DROP/CREATE/ALTER/TRUNCATE — limits blast radius of app compromise |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08.23.2.A-07-01 | Elevation of Privilege | nerve_app has no superuser rights | mitigate | GRANT statement explicitly omits DROP/CREATE/ALTER/TRUNCATE; ALTER DEFAULT PRIVILEGES for future tables. |
| T-08.23.2.A-07-02 | Denial of Service | TCP access to Postgres from external | mitigate | listen_addresses='' in postgresql.conf disables TCP entirely; only unix socket accessible |
| T-08.23.2.A-07-03 | Information Disclosure | SQLite backup contains production user emails/hashes | accept | Backup stored locally on André's laptop (encrypted disk). Not transmitted to external service. |
| T-08.23.2.A-07-04 | Repudiation | No record of when SQLite backup was taken | mitigate | Filename includes timestamp (date +%Y%m%d-%H%M%S); backup-log.txt records timestamp |
</threat_model>
