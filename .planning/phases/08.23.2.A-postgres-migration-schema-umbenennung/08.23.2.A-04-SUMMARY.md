## Deferred Issues

**Pre-existing: JSONB/SQLite incompatibility in db_session fixture**

Tests using `db_session` in `test_per_sid_migration.py` (`test_load_profile_cache_populates_sid`) and all `test_ab_stats.py` tests fail with:

```
sqlalchemy.exc.CompileError: (in table 'calls', column 'meddpicc_extracted'): 
Compiler SQLiteTypeCompiler can't render element of type JSONB
```

This is caused by the `Call` model (added in Plan 01/02) containing a JSONB column. SQLite's in-memory test DB cannot compile JSONB DDL. This failure pre-dates Plan 04 and is unrelated to this plan's changes. The affected tests passed before the `calls` model was added.

Resolution: Test fixture needs to skip `calls`/`call_events` table creation for SQLite tests, or use `@pytest.mark.postgres` marker (D-12). Out of scope for Plan 04 — tracked for Plan 05 or test infrastructure fix.
