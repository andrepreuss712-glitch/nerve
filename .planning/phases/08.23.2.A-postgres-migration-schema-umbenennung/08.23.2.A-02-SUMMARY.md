## What Was Built

- `requirements.txt`: added `alembic>=1.13.0` and `psycopg2-binary>=2.9.9` after `sqlalchemy>=2.0.0` line
- `alembic.ini`: `sqlalchemy.url = %(DATABASE_URL)s` — reads from environment at runtime
- `alembic/env.py`: imports `database.db.Base` and `database.models` (side-effect), sets `target_metadata = Base.metadata`, reads DATABASE_URL from `os.environ` with SQLite fallback, `compare_type=True` in both offline and online modes
- `alembic/versions/.gitkeep`: versions directory tracked in git, ready for Wave 3 baseline migration

## Decisions Made

- **D-01:** DATABASE_URL never hardcoded — `os.environ.get('DATABASE_URL', 'sqlite:///database/nerve.db')` in env.py. Threat T-08.23.2.A-02-01 mitigated.
- **D-02:** `compare_type=True` added in both offline and online modes — ensures column type changes (e.g. VARCHAR length, Integer→BigInteger) are detected by autogenerate.
- **D-03:** psycopg2-binary only, no async postgres driver — Flask stack is synchronous per SPEC constraint 1.
