## Migrations-Skript-Ansatz

| Option | Description | Selected |
|--------|-------------|----------|
| Python-Skript via SQLAlchemy | scripts/migrate_to_postgres.py, nutzt bestehende Modelle, debuggbar | ✓ |
| pgloader | Tool spezialisiert auf SQLite→Postgres, schnell für große Daten | |
| CSV-Export/Import | Export als CSV, COPY INTO Postgres | |

**User's choice:** Python-Skript via SQLAlchemy. Begründung: Datenmenge Pre-Launch trivial, keine neue Werkzeug-Abhängigkeit, SQLAlchemy-Modelle kennen alle Strukturen, Validierung inline möglich, CSV hat zu viele Typ-Konvertierungs-Mausefallen (NULL-Ambiguität, Boolean, JSON-Escaping, TIMESTAMPTZ-Drift).
