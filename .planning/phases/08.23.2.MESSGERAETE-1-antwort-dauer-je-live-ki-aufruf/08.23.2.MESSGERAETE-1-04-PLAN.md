### Reihenfolge und ihre Begruendung
`ttft_ms` ist **nullable ohne Default**. Der neue Code schreibt das Feld nur, wenn es existiert;
laeuft er vor der Migration, wuerde `log_api_cost` beim `INSERT` auf eine unbekannte Spalte laufen —
und weil `log_api_cost` **niemals raist** (Punkt 30), waere die Folge ein **stiller Verlust aller
Kostenzeilen** waehrend des Zwischenfensters. Deshalb **MIGRATION VOR CODE**, ohne Ausnahme.
Ein Code-Rollback ist danach gutartig: alter Code ignoriert die Spalte, sie bleibt NULL.

⚠ **Das ist scharf, nicht theoretisch:** `log_api_cost` uebergibt `ttft_ms=` ab Plan 02
**immer** explizit an `ApiCostLog(...)` — auch als `None`. Das INSERT nennt die Spalte also bei
JEDER Buchung. Laeuft der neue Code gegen eine DB ohne `ttft_ms`, scheitert jedes INSERT, und
weil `log_api_cost` per Punkt 30 **nie raist**, waere die Folge ein **stiller Totalverlust aller
Kostenzeilen** — genau die Sorte Fehler, die man erst Wochen spaeter am leeren Dashboard bemerkt.
**Deshalb: Migration per Einzeldatei-`scp` VOR dem Deploy. Es gibt kein Zwischenfenster.**

**(b) Der praezisierende Zweit-SELECT — er ist der eigentliche Beweis.**
Der SELECT aus (a) zaehlt **alle** Buchungsarten. Weil `latency_ms` nach D-07 bewusst **nur** an der

```bash
ssh -i ~/.ssh/nerve_vps root@178.104.82.166 \
  "sudo -u postgres psql -d nerve -c \"
    SELECT context_tag, unit_type, COUNT(*), COUNT(latency_ms), COUNT(ttft_ms),
           ROUND(AVG(latency_ms)) AS avg_lat, ROUND(AVG(ttft_ms)) AS avg_ttft
    FROM api_cost_log
    WHERE created_at > now() - interval '1 hour'
    GROUP BY context_tag, unit_type ORDER BY context_tag, unit_type;\""
```

**Akzeptanz — beide Richtungen, sonst ist die Phase nicht fertig:**
1. Fuer **jede** Live-Sorte, die im Anruf vorkam, gilt bei `unit_type = 'per_1k_input_tokens'`:
   **`COUNT(latency_ms) = COUNT(*)`** und `avg_lat > 0`.
2. Fuer **jede andere** `unit_type` derselben Sorte gilt: **`COUNT(latency_ms) = 0`**
   (die D-07-Doppelzaehlungs-Sperre greift wirklich, nicht nur im Test).

   (das erste Token kommt vor dem letzten — eine simple, aber wirksame Plausibilitaets-Probe
   gegen vertauschte Werte).
4. Fuer alle **blockierenden** Sorten gilt: **`COUNT(ttft_ms) = 0`** (TTFT gibt es nur beim Stream).
5. Zusaetzlich erscheinen die Sorten **`analyse`** und **`ewb`** — das sind die
