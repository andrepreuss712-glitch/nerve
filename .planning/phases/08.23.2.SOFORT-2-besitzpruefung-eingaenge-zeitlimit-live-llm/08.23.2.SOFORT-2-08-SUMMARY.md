breitere Handler schluckt — der ganze Plan-07-Zweig ist dann unerreichbar.

⚠ **Produktion war nie betroffen** (echte SDK 0.86.0 auf dem Server hat die Klasse, am Server
verifiziert). Betroffen war der **Beweis** der Erreichbarkeit — also genau die Aussage, wegen
der Plan 07 einen Runtime-Wächter hat. **Ein statischer Wächter wäre hier grün geblieben.**
Dass `test_timeout_zweig_ist_erreichbar` es gefangen hat, ist Punkt 31 zu unseren Gunsten.

**Fix `3e7f3bc`, zwei Schichten:** (1) das echte SDK gewinnt, wenn installiert — `import
anthropic` VOR dem `setdefault`, dasselbe Muster, das drei Zeilen tiefer schon für `requests`
steht; (2) die Attrappe trägt die Ausnahmen jetzt selbst, **mit** der am Server verifizierten
Vererbungskette `APITimeoutError → APIConnectionError → APIError → AnthropicError → Exception`
und dem Pflicht-Schlüsselwort `request=`. Flach nachgebaut wäre der Erreichbarkeits-Test
aussagelos, weil er genau die Vererbungs-Falle prüft. **Beide** Dateien repariert — wer nur
eine anfasst, verschiebt den Fehler auf die Test-Reihenfolge.
Zweiter Fehler, gleiche Wurzel: `_FakeAnthropic.__init__` warf seine kwargs weg → kein
`max_retries`-Attribut. Der echte Konstruktor legt es ab; die Attrappe jetzt auch.

echo "ANKER_PIP      $(grep -F '[PiP-'                sof2_logfenster.txt | wc -l)"

| Zahl | Soll | Rolle |
|---|---|---|
| `ZEILEN` | **>= 50** | Existenz-Anker 1: das Fenster wurde wirklich gelesen |
| `ANKER_BEENDEN` | **>= 1** | Existenz-Anker 2: der Test-Anruf liegt **im** Fenster (`routes/app_routes.py:103` druckt bei jedem Beenden) |
| `ANKER_PIP` | **>= 1** | ⛔ Existenz-Anker 3 — **der entscheidende neue**: der `grep` auf `[PiP-` liefert auf diesem Fenster ueberhaupt Treffer. Ohne ihn ist `STREAM_FEHLER = 0` nicht von „PiP-Zeilen erscheinen in diesem Journal gar nicht" unterscheidbar |
| `STREAM_FEHLER` | **== 0** | die eigentliche Aussage: **keine** Stream-Kappung, kein Stream-Abbruch |
| `SOFORT2` | **== 0** | keine Kappung der acht blockierenden Pfade (die zweite Sicht neben dem Founder-Zaehler) |

⚠ Ist `ANKER_BEENDEN` == 0 **oder** `ANKER_PIP` == 0, sind die zwei Nullen **wertlos**. Dann
Fenster vergroessern (`inspect.sh logs 1000`) und neu lesen — **nicht** als bestanden werten.

⚠ `| wc -l` statt `grep -c`: `grep -c` endet bei 0 Treffern mit Status 1. Genau dafuer stand
