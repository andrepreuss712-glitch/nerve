## ⚠️ Offen — Blocker für nächste Phase 06.3

**Sekundärer Feedback-Loop über analyse_loop** (NICHT Keyword-Matcher):

1. User sagt "keine Zeit" → Keyword matcht + rendert Slot 0 ✅
2. Berater liest EWB laut vor → Deepgram-Final enthält "Zeit knapp…"
3. `analyse_loop` macht **neue Claude-Detection** auf Slot-0 JSON-Stream
4. Anthropic liefert `overloaded_error` (`req_011Ca7aai3cNtw1ebw8dDCdV`, type=overloaded_error)
5. Fehlermeldung erscheint in Slot 0 ("aus ewb 0")
6. Anthropic 529 deutet auf zu viele parallele Calls hin — `analyse_loop` überschlägt sich weil der Vorlese-Text kontinuierlich als Einwand-Satz getaggt wird

**Root-Cause-Hypothese:** `analyse_loop` respektiert den **Keyword-Dominanz-State** nicht. Wenn `state.slot0LastKeywordTyp` frontend-seitig aktiv ist, sollte das Backend (`analyse_loop` in `services/claude_service.py`) keine Claude-Detection für Slot 0 triggern.

### Vorschlag Phase 06.3

1. **Primär-Fix:** `analyse_loop` pausiert Detection-Calls für Slot 0 solange Keyword-Dominanz aktiv ist
   - Einfachster Weg: neue `ls.state['slot0_keyword_active_until']` timestamp, gesetzt wenn Keyword-Pipe feuert (deepgram_service.py keyword-match-branch) → `analyse_loop` prüft vor Claude-Call ob `now < slot0_keyword_active_until`
   - 3s Dominanz analog zum Frontend-Schutz
2. **Alternative (saubererer Refactor):** analyse_loop-Detection nur noch als Fallback wenn Keyword-Matcher nicht gematcht hat — entspricht dem ursprünglichen 06.2-CONTEXT.md "Keyword = Primary"
3. **Defense-in-Depth:** Anthropic 529 Retry-Backoff für `analyse_loop` prüfen (ist bei `streame_manual_ewb_variante` schon drin, aber vermutlich nicht im `analyse_loop` → `analysiere_mit_claude_streaming`-Pfad)

### Repro für 06.3
- Cold Call starten
- "Achso, Sie haben dafür gerade keine Zeit" sagen
- EWB-Antwort laut und vollständig vorlesen (~30-60s)
- Beobachten: Slot 0 bekommt Overload-Fehlermeldung, Backend-Log zeigt `req_011Ca...` + 529 vom analyse_loop-Pfad

### Work-around bis 06.3
Cold Call baseline ist stabil — `analyse_loop`-Overload passiert nur bei bestimmten Vorlese-Situationen. Für UAT: kurz vorlesen, nicht minutenlange Reden, dann hält das System.
