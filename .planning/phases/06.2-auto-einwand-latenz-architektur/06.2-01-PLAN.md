  - id: task-2
    title: "Dedup-State + Reset-API"
    description: >
      EinwandKeywordMatcher-Klasse mit per-Instance Dedup-State:

        class EinwandKeywordMatcher:
            def __init__(self, dedup_window_sec: float = 10.0):
                self._last_seen: dict[str, float] = {}  # keyword -> monotonic ts
                self._dedup_window = dedup_window_sec

            def match_with_dedup(self, transcript: str, profile_einwaende: list) -> dict | None:
                match = match_keyword(transcript, profile_einwaende)
                if not match:
                    return None
                now = time.monotonic()
                last = self._last_seen.get(match['keyword'], 0)
                if now - last < self._dedup_window:
                    return None
                self._last_seen[match['keyword']] = now
                return match

            def reset_keyword(self, keyword: str) -> None:
                """Called on utterance_end to allow re-trigger for next sentence."""
                self._last_seen.pop(keyword, None)

            def reset_all(self) -> None:
                """Called on call end / session restart."""
                self._last_seen.clear()

      Thread-safe falls notwendig (threading.Lock um _last_seen).

    autonomous: true
