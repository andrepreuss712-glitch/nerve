# Phase 08.19.4 Plan 02: SID Lifecycle Wiring + Public Profile Globals Removal Summary

SID-Lifecycle in deepgram_service.py verdrahtet (connect laedt Profil aus DB und ruft init_session_state + set_profile_for_sid auf; disconnect/stop rufen pop_session_state auf); oeffentliche active_profile_data/active_profile_name Module-Globals aus live_session.py entfernt und durch private _legacy_*-Compat-Wrapper ersetzt.

## What Was Built

### Task 1 — deepgram_service.py

- `ls.state['active_sid'] = _sid` Global-Zuweisung entfernt (active_sid jetzt per-SID in `_session_state[sid]`)
- Per-SID Profile + Session State Init Block nach FT-Block in `handle_start_live_session` eingefuegt:
  - Laedt User.active_profile_id aus DB (eigene DB-Session, getrennt vom FT-Block)
  - Laedt Profile.daten (JSON) wenn active_profile_id gesetzt
  - Idempotent: `pop_session_state(_sid)` wenn SID bereits in `_session_state` (Reconnect ohne Disconnect)
  - Ruft `ls.init_session_state(_sid, user_id, org_id, profile_id, market, language, mode)` auf
  - Ruft `ls.set_profile_for_sid(_sid, name, daten)` auf
  - Log-Zeile: `[08.19.4] SID {sid}: profile={name!r} pid={id} org={org_id}`
  - Ganzer Block in try/except — fehlgeschlagener DB-Load crasht nie die Session
- `handle_stop_live_session`: `ls.drop_matcher(_sid)` durch `ls.pop_session_state(_sid)` ersetzt
- `handle_disconnect`: `ls.drop_matcher(_sid)` durch `ls.pop_session_state(_sid)` ersetzt
- `_make_on_message`: `_per_sid_profile.setdefault(sid, ('', {}))` Guard am Anfang von `on_message` (thread-safe, mit Lock)

### Task 2 — live_session.py

- `active_profile_data = {}` Modul-Global entfernt
- `active_profile_name = ''` Modul-Global entfernt
- `active_profile_lock = threading.Lock()` Modul-Global entfernt
- Ersetzt durch private `_legacy_profile_lock`, `_legacy_profile_data`, `_legacy_profile_name`
- `set_active_profile()`: Docstring DEPRECATED, `_logger.warning()` Call, verwendet `_legacy_*` Namen
- `get_active_profile()`: Docstring DEPRECATED, `_logger.warning()` Call, verwendet `_legacy_*` Namen
- Compat Round-Trip verifiziert: `set_active_profile('test', {'x': 1})` -> `get_active_profile()` gibt `('test', {'x': 1})`
