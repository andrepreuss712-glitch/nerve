### WR-03 (CRITICAL): `coaching_loop` reads global `coaching_buffer` instead of per-SID buffer

**Files modified:** `services/live_session.py`, `services/claude_service.py`, `tests/test_session_scoping.py`
**Commit:** 9e27745
**Applied fix:** Full per-SID coaching buffer migration (mandatory fix plan followed exactly):

1. **New data structures in `live_session.py`:** Added `_per_sid_coaching_buffer: dict = {}` and `_per_sid_coaching_lock = threading.Lock()` alongside the existing per-SID infrastructure.

2. **`init_session_state()`:** Initialises `_per_sid_coaching_buffer[sid] = []` under `_per_sid_coaching_lock` for each new session.

3. **`pop_session_state()`:** Pops `_per_sid_coaching_buffer[sid]` under `_per_sid_coaching_lock` on disconnect cleanup.

4. **`_flush_segment()` (producer):** Replaced the unconditional `coaching_buffer.append(...)` with `_per_sid_coaching_buffer.setdefault(sid, []).append(...)` under `_per_sid_coaching_lock`. The module-global `coaching_buffer` is retained only as a fallback for pre-08.19.4 edge cases without a SID.

5. **`coaching_loop()` (consumer) in `claude_service.py`:** Replaced the `with ls.coaching_lock: ... ls.coaching_buffer ...` block with a per-SID drain: reads `ls._per_sid_coaching_buffer.get(sid, [])` under `ls._per_sid_coaching_lock`, captures the segments, and clears the per-SID list.

6. **Tests in `tests/test_session_scoping.py`:** Added `TestPerSidCoachingBufferIsolation` with three runtime-assertion tests:
   - `test_two_sids_independent_coaching_buffers`: confirms SID B's buffer is empty after writing to SID A
   - `test_disconnect_cleanup_coaching`: confirms SID is removed from `_per_sid_coaching_buffer` after `pop_session_state`
   - `test_concurrent_coaching_writes_no_contamination`: two threads write 30 segments each to separate SIDs; asserts no cross-contamination and correct counts

   All 3 tests pass (`python -m pytest tests/test_session_scoping.py` — 10 passed, 1 skipped).
