### CR-01: `_parse_json` raises on empty or malformed Claude output

**Files modified:** `services/claude_service.py`
**Commit:** `052a928`
**Applied fix:** Added empty-string guard at function entry, added bounds check (`start == -1 or end == 0 or start >= end`) before slicing, and wrapped `json.loads()` in a `try/except json.JSONDecodeError` returning `{}` on failure. ### CR-02: `_letzte_gemeldete_version` grows unbounded and persists stale state across sessions

**Files modified:** `routes/app_routes.py`
**Commit:** `e93512b`
**Applied fix:** Two changes in `app_routes.py`:
1. Added `_MAX_VERSION_CACHE = 500` constant at module level alongside the dict declaration.

### WR-05: `match_faq` indexes unfiltered `faqs` list with filtered-list index

**Files modified:** `services/qa_pipeline.py`
**Commit:** `2aa95ea`
**Applied fix:** Replaced the filtered comprehension that built only `faq_texts` with a two-step approach: first build `filtered_faqs = [f for f in faqs if f.get('frage_muster')]`, then derive `faq_texts = [f['frage_muster'] for f in filtered_faqs]`. The final return now uses `filtered_faqs[best_idx]` instead of `faqs[best_idx]`, ensuring the index is always relative to the same list that was embedded and scored.
