## Klassifikator-Architektur

### Latenz-Strategie

| Option | Description | Selected |
|--------|-------------|----------|
| Sequential + Threshold-Skip | Klassifikator läuft, wenn Keyword-Matcher fired → kein 2. Call | ✓ |
| Immer beide Calls parallel | Klassifikation + Antwort-Gen gleichzeitig, doppelter API-Cost | |
| Single-Call Kombination | Ein Haiku-Call klassifiziert + antwortet | |

**User's choice:** Sequential + Threshold-Skip
**Notes:** Haiku-only constraint absolut (CLAUDE.md). Threshold-Skip spart API-Calls für bekannte Einwände.

---

### Slot-Kollision (Keyword-Matcher vs. Klassifikator)

| Option | Description | Selected |
|--------|-------------|----------|
| Keyword-Matcher hat Vorrang | Slot 0 fired → Klassifikator für diesen Utterance ignoriert | ✓ |
| Zuerst ankommen gewinnt | Race-basiert, nicht reproduzierbar | |
| Beide rendern, User sieht beide | Slot 0 + Slot 1 beide aktiv | |

**User's choice:** Keyword-Matcher hat Vorrang
**Notes:** Deterministische Prio-Regel, kein Race-Condition-Risiko.

---

### Confidence-Schwelle

| Option | Description | Selected |
|--------|-------------|----------|
| 0.75 fix, kein A/B | Briefing-Wert | |
| 0.80 als sichererer Default | Höhere Hürde, weniger Fehlauslöser | ✓ |
| Konfigurierbarer Wert im Admin-Panel | Mehr Aufwand, sofort flexibel | |

**User's choice:** 0.80 + `CLASSIFIER_CONFIDENCE_THRESHOLD` Env-Var (kein Admin-Panel-UI in v1)
**Notes:** "0.75 aus dem Briefing war ohne Live-Daten zu optimistisch. Bei 0.80 sind wir sicher still — nach Wave 7 Quality-Gate Daten kann runtergedreht werden." Admin-Panel post-Launch.

---

### Fallback bei Low-Confidence

| Option | Description | Selected |
|--------|-------------|----------|
| Stumm bleiben | Kein Output, Vertriebler formuliert selbst | |
| Soft-Hint ohne Antwort (mit Design-Anpassung) | Dezenter Text im Slot, kein Emoji, grau | ✓ |

**User's choice:** Soft-Hint mit Design-Anpassung
**Notes:** "Statt aggressiv ('⚠️ Einwand erkannt') lieber subtil: kleiner grauer Text 'Einwand gehört — du selbst' oder 'kein sicherer Treffer'. Kein Emoji, kein Warn-Gelb." Text-Finalisierung in Plan-Phase per AskUserQuestion (2-3 Varianten). Post-Call-Transparenz optional, nicht v1-Pflicht.
