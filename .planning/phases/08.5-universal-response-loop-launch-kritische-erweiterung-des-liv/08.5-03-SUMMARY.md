## Threat Model Mitigations Applied

- **T-08.5-03-01 (Cross-org profile_faqs leak):** `_qa_load_faqs` queries by `active_profile_id` from `ls.state`, which is set during authenticated session start (profile activation validated by `g.org.id` filter at all 4 call sites).
- **T-08.5-03-02 (529-loop regression):** `kw_fired_for_line == line_id` guard under `state_lock` in `_qa_pipeline_dispatch`. Keyword-Matcher writes flag before returning match. Both paths confirmed by TDD tests 1, 3.
- **T-08.5-03-03 (XSS via Haiku response):** `slot.textContent = txt` in `qa_slot1` handler; `span.textContent = hintText` in `qa_soft_hint` handler. No `innerHTML` with event data.
- **T-08.5-03-05 (DoS flood):** `ANALYSE_INTERVALL` 4s limits loop rate; `slot1_variant_busy_until` +8s prevents overflow emits; `kw_fired_for_line` guard prevents double-tap on same utterance.
