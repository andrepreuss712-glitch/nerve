# Phase 08.5 Plan 04: Anrede-UX-Umzug (PreCall → Skript-Auswahl) Summary

Anrede selection moved from optional PreCall-Step (Step 3) to mandatory Skript-Auswahl step (Step 5). Profile ki_ansprache field UI-deprecated as "Vorauswahl". lastSessionAnrede persistence added for sticky UX across calls.

## What Was Built

### Task 1: pip-launcher.js Changes

**Step A — Removed from renderStep3 (lines 227-258 before change):**
- Deleted the 5-line Anrede block: label "Wie soll der Assistent dich ansprechen?", launcher-anrede-row div, Du/Sie buttons
- Removed `savedAnrede` local variable declaration (was only used for the removed block)
- Removed `state.precallFormData.anrede` preset that was in renderStep3 (now done in renderStep5)
- Retained comment noting Anrede was moved to Step 5

**Step B — Added to renderStep5 (inserted before launcher-actions div):**
- `savedAnrede5` variable: fallback chain `state.lastSessionAnrede || ki.ansprache || 'Sie'`
- `precallFormData.anrede` preset at top of renderStep5 (ensures anredeForSession has value even without user click)
- Anrede row HTML: label "Anrede im Gespräch *", `id="lnr-anrede-row5"`, Du/Sie buttons with `window.NerveLauncher._setAnrede()` handlers

**Step C — Single-script auto-select edge case (D-10):**
- Added guard at top of renderStep5: `if (state.skripte.length === 1 && !state.selectedSkriptId) { state.selectedSkriptId = state.skripte[0].id; }`
- This pre-selects the only available script but does NOT skip to Step 6
- Step 5 renders normally with the Anrede row visible

**Step D — lastSessionAnrede persistence:**
- IIFE init: reads `localStorage.getItem('nerve_last_anrede')` into `state.lastSessionAnrede`
- `_cleanup()`: writes `state.precallFormData.anrede` to both `state.lastSessionAnrede` and `localStorage.setItem('nerve_last_anrede', ...)` before state reset

**Unchanged (verified):**
- `_setAnrede(anrede)` function — signature and body identical
- `anredeForSession` line (~line 983+) — still reads `state.precallFormData.anrede === 'Du' ? 'Du' : 'Sie'`
- All existing payload wiring to backend

## Threat Model Mitigations Applied

- **T-08.5-04-01 (Tampering — manipulated anrede value):** Backend anrede whitelist `{'Du', 'Sie'}` at session-start handler unchanged. `anredeForSession` uses ternary `=== 'Du' ? 'Du' : 'Sie'` — any non-'Du' value maps to 'Sie'.
- **T-08.5-04-02 (XSS via tooltip):** `fl-hint` tooltip is a static Jinja literal — no user data interpolated.
- **T-08.5-04-03 (localStorage DoS):** `nerve_last_anrede` stores max 3 chars ('Du' or 'Sie') — negligible storage.

## Known Stubs

None — Anrede selection fully wired from Step 5 UI through `_setAnrede()` → `precallFormData.anrede` → `anredeForSession` → `start_live_session` payload → backend.
