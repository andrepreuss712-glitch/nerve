## What Was Built

### services/qa_pipeline.py — Public API

**classify_utterance(text, kontext, user_id) -> dict**
- Haiku call (claude-haiku-4-5-20251001, max_tokens=150)
- Returns `{"kategorie": str, "confidence": float, "einwand_zitat": str|None}`
- kategorie whitelist: `einwand_unknown | frage | smalltalk_none | einwand_known`
- Unknown kategorie values coerced to `smalltalk_none` (T-08.5-02-06 mitigation)
- Fail-open: empty/whitespace text returns `smalltalk_none/0.0` without API call
- Fail-open: any exception returns fallback dict, never raises

**generate_qa_response(utterance, category, profile_data, anrede, version, user_id) -> str**
- Haiku call (claude-haiku-4-5-20251001, max_tokens=400)
- Only responds for `einwand_unknown` or `frage` categories; returns "" otherwise
- Loads profile context via `build_profile_context(user_id, mode='live')`
- Fail-closed: any exception returns "", never raises

**match_faq(utterance, faqs, threshold=0.75) -> Optional[dict]**
- Local semantic match via `sentence_transformers.util.cos_sim` (DSGVO-safe, no API)
- Model: `paraphrase-multilingual-MiniLM-L12-v2` (DACH multilingual)
- Lazy-init with `threading.Lock` (double-checked locking, cached module-global)
- Embedding model failure (not installed, download error): returns None, no raise
- Returns first faq dict where best cosine similarity >= threshold

**apply_tabu_filter(text, tabu_begriffe) -> bool**
- Simple case-insensitive substring match (`text.lower()` + `begriff.lower()`)
- Skips None/non-string entries in tabu_begriffe list
- Returns True if any tabu_begriff substring found in text

### Internal Helpers

**_get_embedding_model() -> SentenceTransformer|None**
- Lazy-init with `threading.Lock` (double-checked locking pattern)
- Sets `_MODEL = False` sentinel on failure — prevents retry-per-call DoS
- Returns None on failure (callers check before use)

**_load_qa_template(module, version) -> str**
- DB lookup via `prompt_versions` (module='classifier'/'qa_response', version=X, is_active=True)
- Fallback to `_FALLBACK_CLASSIFIER_PROMPT` or `_FALLBACK_QA_RESPONSE_PROMPT`
- Pattern copied from `ewb_pipeline._load_prompt_template`

**Fallback prompts (module-level constants)**
- `_FALLBACK_CLASSIFIER_PROMPT`: 4-category JSON-only classifier with vorlese-text rule
- `_FALLBACK_QA_RESPONSE_PROMPT`: max 45 words, non-apologetic, `{anrede}` + `{profile_context}` placeholders
