## Threat Model Mitigations Applied

- **T-08.5-01-01 (Tampering — _migrate() re-run):** `CREATE TABLE IF NOT EXISTS` + `INSERT OR IGNORE` + try/except per block — fully idempotent.
- **T-08.5-01-02 (DoS — invalid CLASSIFIER_CONFIDENCE_THRESHOLD):** `float()` conversion raises `ValueError` at startup on invalid env value — fail-fast correct behavior documented.
- **T-08.5-01-04 (Tampering — tabu_begriffe):** Not a DB column; resides in profiles.daten JSON, access controlled by existing org_id isolation in profile CRUD.
