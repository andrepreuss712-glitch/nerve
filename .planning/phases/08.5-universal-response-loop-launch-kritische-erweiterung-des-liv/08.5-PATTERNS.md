**match_faq function** (from RESEARCH.md Code Examples):
```python
def match_faq(utterance: str, faqs: list, threshold: float = 0.75):
    """Semantic FAQ-Match. MUST NOT raise. Returns matching faq dict or None."""
    if not faqs or not utterance:
        return None
    try:
        model = _get_embedding_model()
        from sentence_transformers import util
        q_emb = model.encode(utterance, convert_to_tensor=True)
        faq_texts = [f['frage_muster'] for f in faqs]
        f_embs = model.encode(faq_texts, convert_to_tensor=True)
        scores = util.cos_sim(q_emb, f_embs)[0]
        best_idx = int(scores.argmax())
        if float(scores[best_idx]) >= threshold:
            return faqs[best_idx]
    except Exception as e:
        print(f"[QA] FAQ-Match failed: {e}")
    return None
```

**apply_tabu_filter function** (from RESEARCH.md Code Examples):
```python
def apply_tabu_filter(text: str, tabu_begriffe: list) -> bool:
    """Returns True wenn Text einen Tabu-Begriff enthaelt (→ Antwort verwerfen).
    case-insensitive, v1: einfaches substring-Match.
    """
    if not tabu_begriffe or not text:
        return False
    text_lower = text.lower()
    for begriff in tabu_begriffe:
        if not begriff:
            continue
        if begriff.lower() in text_lower:
            return True
    return False
```
