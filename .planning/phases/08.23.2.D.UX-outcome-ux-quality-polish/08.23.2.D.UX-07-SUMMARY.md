# Phase 08.23.2.D.UX Plan 07: Dashboard Pencil-Edit Button + 7-Class Accordion Summary

**One-liner:** Pencil-icon edit button in every session row opens a 7-class outcome accordion with inline score/outcome DOM update via nerve.css tokens.

## What Was Built

REQ-D.UX-12 — Dashboard Pencil-Edit Button for all calls (not just ai_auto_unsicher). Every session row with a `call_id` now has a dezenter 14px Lucide pencil icon button. Clicking it opens a 7-button accordion below the row. Selecting an outcome POSTs to `correct_outcome`, then updates the Score label and Outcome label inline without reload.

### Changes in `templates/dashboard.html`

1. **`_outcomeLabelDe()` extended to 7 classes** — added `send_info: 'Infos zusenden'`, `gatekeeper_blocked: 'Gatekeeper blockt'`, updated `callback` to `'Rückruf vereinbart'`.

2. **`scoreColor` nerve.css token migration** — replaced hardcoded `#00D4AA / #6B7280 / #F85149` with `var(--btn-primary-bg-from, #00D4AA)` / `var(--page-text-secondary, #6B7280)` / `var(--btn-danger-text, #f87171)`.

3. **Pencil-Edit button in session row** — `n-btn-ghost outcome-pencil-btn`, `data-call-id`, `onclick="event.stopPropagation()"`, inline Lucide SVG 14px. Only rendered when `s.call_id` is present.

4. **Existing unsicher-dot accordion upgraded** — opts array extended from 5 to 7 classes, `followup_intent` added to POST body, response handler now updates `final_score` in score span and preserves unsicher-dot + pencil-btn nodes.

5. **New Pencil-Edit click handler** — event delegation on `.outcome-pencil-btn`. Toggle support (second click closes). 7-button accordion (`outcome-pencil-accordion`). Same POST pattern as unsicher-dot, same DOM update logic. Error state shows inline red message.
