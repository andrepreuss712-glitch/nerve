# Phase 08.23.2.D.UX Plan 06: Score-Berechnung + followup_intent in correct_outcome Summary

**One-liner:** `_calc_coaching_score()` helper with outcome modifier (0.85-1.15) persists 9-key score_breakdown JSONB + followup_intent atomically in correct_outcome endpoint.

## What Was Built

### Task 1: Score-Berechnung + followup_intent im correct_outcome Endpoint (TDD)

**RED phase commit:** 7d888ed — 8 deterministic failing tests for `_calc_coaching_score()`

**GREEN phase commit:** b4855a9 — Implementation:

1. `_OUTCOME_MODIFIERS` dict (7 entries, contract_signed=1.15 .. no_interest=0.85)
2. `_calc_coaching_score(conv, outcome)` helper:
   - Formula: `process_score = kb*0.30 + behandelt_rate*100*0.30 + redeanteil_score*0.20 + skript*0.10 + 0`
   - `final_score = clamp(round(process_score * modifier), 0, 100)`
   - Returns `(coaching_score_float, final_score_int, breakdown_dict)` — both on 0-100 scale
   - `conv=None` uses fallback defaults (kb=30, behandelt_rate=0.5, redeanteil=50, skript=0)
3. `api_calls_correct_outcome` extended:
   - `followup_intent` validated against frozenset `{'none','callback','meeting','send_info','retry_internal'}`
   - `outcome_source` client-override accepted (`ai_auto`, `ai_auto_unsicher`, `user_corrected`)
   - `ConversationLog` fetched via `conversation_log_id` for score inputs
   - `coaching_score`, `score_breakdown`, `score_schema_version=1` written atomically in one commit
   - Response: `{ok, coaching_score, final_score, outcome, followup_intent}`
