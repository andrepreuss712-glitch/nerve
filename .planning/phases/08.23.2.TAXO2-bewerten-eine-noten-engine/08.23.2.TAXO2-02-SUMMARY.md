# Phase 08.23.2.TAXO2 Plan 02: BARS-Engine + Proration Summary

Reine, deterministische rubrik-basierte Noten-Engine (`compute_rubric`) plus der DB-Gewichtssatz
(`mode_weight_config`) und die 7 Dimensionen mit je 3 BARS-Stufen — gebaut, atomar committet,
gepusht. **KEIN Deploy** (André-Direktive: Prod-Migration + Pytest-Gate laufen supervidiert).
Die Engine schreibt NICHTS in `rubric_score`/`calls` (Plan 04) und berechnet KEINEN
`handling_score` (Plan 03) — sie konsumiert nur `handling_score_numeric`.

## Was gebaut wurde (pro Task)

### Task 1 — `mode_weight_config`-Tabelle + ORM + Migration 0021 (Commit `a8302b8`)
- **ORM `ModeWeightConfig`** (`database/models.py`): Spalten `id`, `session_mode VARCHAR(32)`,
  `dimension VARCHAR(48)`, `weight FLOAT`, `enabled BOOLEAN`, `partial_marker VARCHAR(48)`,
  `indirekt_erkannt BOOLEAN`, `confidence_gate FLOAT`, `updated_at`. `UNIQUE(session_mode, dimension)`
  (`uq_mode_weight_config_mode_dim`). Schilder (Punkt 23) auf Tabelle + jeder nicht-trivialen Spalte.
  Globale Config -> **Owner `nerve_app`, KEINE RLS/Policy** (kein per-Call-Datum, kein `tenant_id`).
- **Migration `0021_mode_weight_config.py`**, `revision='0021'`, **`down_revision='0020'`**.
  `create_table` + `create_unique_constraint` + `ALTER TABLE ... OWNER TO nerve_app` + COMMENT-Schilder.
- **Idempotenter D-04-Seed IN der Migration** (Create-All/Seed-Trap-Schutz):
  `INSERT INTO public.mode_weight_config (...) VALUES (...) ON CONFLICT (session_mode, dimension) DO NOTHING`
  ueber alle 21 Default-Zeilen (3 Modi x 7 Dim).
- **N-4:** `session_mode` traegt EXAKT `{cold_call, meeting_consented, training}` — kein `'meeting'`-Kurzform.

### Task 2 — `services/rubric_dimensions.py` (Commit `333de3c`)
- **`DIMENSIONS`** (7 ASCII-Keys): `vorwand_behandlung`, `kaufsignal_nutzung`, `aufschub_behandlung`,
  `phasen_technik`, `fragen_qualitaet`, `gespraechsfuehrung`, `outcome_progression`. Je Dimension
  `bars` (3 Stufen, user-facing deutsch mit Umlauten), `is_measurable` + `score` (reine Funktionen).
- **D-05-Messbarkeit:** Ereignis-Dims messbar ab `>=1` konfidentem Ereignis (Tor-1 D-03, NICHT `>=2`);
  `fragen_qualitaet` via `FRAGEWOERTER` (W-Fragen), **NICHT** ueber `'?'`; `phasen_technik` via
  Call-Dauer + Progression-vs-Steckenbleiben (Festhaengen = Negativ); `gespraechsfuehrung`
  **verzweigt nach Modus** (meeting = Talk-Share Zwei-Sprecher; cold_call = Berater-Speech-Stats
  Sprechdisziplin); `outcome_progression` messbar wenn `outcome` klassifiziert.
- Reine Daten/Logik: KEIN LLM, KEIN DB-Zugriff.

### Task 3 — `services/rubric_engine.py` + 2 Test-Dateien (Commits `1f1ab0e` RED, `081b1ac` GREEN)
- **`def compute_rubric(events, speech_stats, call, mode_config, mode_key=None) -> dict`** — reine Funktion.
- **D-01 Zwei-Stufen-Gate:** (a) config-an (`enabled & weight>0`, sonst `config_off`),
  (b) per-Call-Verfuegbarkeit (`is_measurable`, sonst `na`/`not_reached`). Zwei Gruende SAUBER
  getrennt in `unmeasured_dimensions[{dim, reason}]`.
- **N-4:** `mode_key` aus `call.call_mode` (live) bzw. `'training'` (`origin='training'`) — **NIE**
  `call.session_mode`. Leerer `mode_config`-Lookup -> `status='no_weight_set'` mit Spur (alle 7 als
  `config_off` gelistet), NICHT still 0/NULL.
- **D-02 modus-relative <50%-Schwelle:** `measured_weight_pct = messbares Gewicht / config-an Gewicht des Modus`;
  `< 0.5` -> `coaching_score = None`, `status='insufficient_data'`.
- **Proration:** messbare Dims auf 100% renormalisiert; nie messbar-aber-0 (Stufe immer 1-3,
  sonst `available=false`).
- **D-08 N/A-vs-vergeigt-Guard:** Abbruch-Outcome (`no_interest`/`gatekeeper_blocked`/`wrong_person`)
  + kurze Dauer (`<30s`) -> fehlende Dims `not_reached` (negativ), sonst `na`; `is_provisional=True`
  wenn ueber der Schwelle aber Dims weggeprorated.
- **Req 5 volle Aufschluesselung:** `dimensions[{dim,label,score,weight,available,sample_size,beleg_ref,marker}]`;
  `beleg_ref = {intent_event_id: ...}` (kein freier LLM-Text); `(indirekt erkannt)`-Marker (D-04).
- **Tests** (rein, deterministisch, kein DB-commit -> kein conftest-cleanup noetig; Runtime-Behavior,
  kein Source-Presence-False-Green):
  - `tests/test_proration.py`: **D-02-Pflicht** `test_mode_can_never_score` +
    `test_proration_drops_below_mode_threshold`, Cold-Call-Renormalisierung, D-08-Abbruch-Guard,
    **N-4** `test_mode_key_from_call_mode`, leerer-Config-Trace.
  - `tests/test_rubric_engine.py`: DIMENSIONS-Invarianten (7 Dim, je 3 BARS, ASCII-Keys, callable),
    Aufschluesselungs-Form (Req 5), getrennte unmeasured-Gruende, indirekt-Marker, beleg_ref-als-Event-Ref.
