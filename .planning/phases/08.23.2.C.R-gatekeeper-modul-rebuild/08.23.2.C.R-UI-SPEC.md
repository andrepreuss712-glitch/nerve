## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Inline padding, compact elements |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Toggle-Button min-height (Req-4 D-03e) |
| 2xl | 48px | Layout gaps |
| 3xl | 64px | Page-level spacing |

Exceptions: none — pip-mode-indicator verwendet 2px vertikales Padding als Legacy-Pixel-Wert (kein Spacing-Token, dokumentiert im Component-Abschnitt)

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #F0F2F5 (`--page-bg`) | Page background, PiP body background |
| Secondary (30%) | #FFFFFF (`--glass-bg`) | Cards, PiP container, default mode indicator bg |
| Accent (10%) | #00D4AA (`--btn-primary-bg-from`) | CTA buttons, primary badges |
| Destructive | #EF4444 (`--danger-red`, `--pipeline-error-bg`) | Error states, pipeline errors |

Accent reserved for: primary CTAs, active state badges, teal highlights — NICHT für Modus-Indikatoren.

### Neue CSS-Tokens (Phase C.R — alle in nerve.css `:root` zu definieren)

| Token | Wert | Begründung |
|-------|------|------------|
| `--pip-gatekeeper-bg` | `rgba(96,165,250,0.12)` | Sekretär-Modus-Indikator bg — Blau (Info-Charakter, kein Warn-Amber) |
| `--pip-gatekeeper-text` | `#3b82f6` | Sekretär-Modus-Indikator text — Blue-500, lesbar auf hellem Hintergrund |
| `--pip-gatekeeper-bg-hover` | `rgba(96,165,250,0.22)` | Hover-Feedback für Toggle-Button (leicht intensiver als base) |
| `--pip-bg` | `#F8FAFC` | PiP-Body-Hintergrundfarbe — ersetzt hardcoded `body.style.background = '#F8FAFC'` (Z.1710) |
| `--badge-default-bg` | `rgba(100,116,139,0.08)` | Default-Badge in JS (Z.2582) — Light-Mode-konform, Slate-500 mit 8% Opacity |
| `--badge-default-text` | `#475569` | Default-Badge Text (Z.2582) — Slate-600, lesbar auf hellem Hintergrund |

Farbentscheidung: `--pip-gatekeeper-bg` bewusst nicht Amber (`--pipeline-warning-bg: #f59e0b`) — Amber ist für Pipeline-Fehler reserviert (SPEC.md Req-7). Blau signalisiert informativen Zustandswechsel ohne Warndringlichkeit.

## Component: pip-mode-indicator (span → button)

Einziges neues UI-Bauteil in Phase C.R.

| Eigenschaft | Spezifikation |
|-------------|---------------|
| Element | `<button type="button" id="pip-mode-indicator">` — Migration von `<span>` |
| Mindest-Höhe | 32px (`xl` spacing) |
| Padding | 2px 8px (bestehend, beibehalten) |
| Cursor | `pointer` bei Hover |
| Hover-Bg | `var(--pip-gatekeeper-bg-hover)` |
| Border-Radius | 4px (bestehend) |
| Font-Size | 11px / font-weight 600 (bestehend) |
| Label-Inhalt | Zeigt AKTUELLEN Modus — "Sekretär" (default) oder "Entscheider" |
| aria-label | Zeigt ZIEL-Modus — "Modus wechseln zu Entscheider" / "Modus wechseln zu Sekretär" |
| Keyboard | Tab-Focus + Enter-Klick kostenlos via button-Element |
| Klick-Handler | `socket.emit('manual_mode_toggle', {category: ...})` (bestehender Pattern) |
| Focus-Outline | Browser-default (kein Entfernen von outline — Accessibility) |

**State-Varianten:**

| Zustand | data-mode | Label | Hintergrund |
|---------|-----------|-------|-------------|
| Sekretär (default) | `gatekeeper` | "Sekretär" | `var(--pip-gatekeeper-bg)` |
| Entscheider | `cold_call` / `target` | "Entscheider" | `var(--glass-bg)` + `color: var(--btn-primary-bg-from)` (bestehend) |

## CSS-Sweep Contract (Req-8: Hex → Token)

Drei hardcoded Werte in `pip-launcher.js` werden durch CSS-Tokens ersetzt:

| Zeile | Aktuell | Ersatz-Token | Kommentar |
|-------|---------|--------------|-----------|
| Z.1226 | `color:#06060a` | `color:var(--btn-primary-text)` | Button-Text, Dark-Mode-Rest |
| Z.2582 | `rgba(255,255,255,0.1);color:#c5c9d4` | `var(--badge-default-bg)` + `var(--badge-default-text)` | Default-Badge, auf Light-Bg unsichtbar |
| Z.1710 | `body.style.background = '#F8FAFC'` | `body.style.background = 'var(--pip-bg)'` | PiP-Body-Hintergrund |

SVG-inline-Farben (`#00D4AA` in Icon-Strokes) bleiben — CSS-Cascade greift nicht auf SVG-Attribute. Explicitly out of scope.
