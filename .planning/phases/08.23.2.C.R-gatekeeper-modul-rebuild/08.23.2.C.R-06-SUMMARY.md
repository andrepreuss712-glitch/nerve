- `'Vorzimmer'` → `'Sekretär'` (mode === 'gatekeeper')
- `'Cold-Call'` → `'Entscheider'` (Default-Branch)

**aria-label dynamisch (D-03b):**
```javascript
indicator.setAttribute('aria-label',
  'Modus wechseln zu ' + ((mode === 'gatekeeper') ? 'Entscheider' : 'Sekretär'));
```
Zeigt Ziel-Modus — Screenreader versteht was der Klick auslöst.

**Klick-Handler auf #pip-mode-indicator (D-03i):**
- 300ms Throttle via `_modeBtnThrottle` + `Date.now()` — verhindert Rapid-Click-Spam
- `e.stopPropagation()` — verhindert Event-Bubbling
- Toggle-Logik: `state.contactCategory === 'gatekeeper'` → newCategory = 'target', sonst 'gatekeeper'
- `state.socket.emit('manual_mode_toggle', { category: newCategory })` — bestehender Pattern
