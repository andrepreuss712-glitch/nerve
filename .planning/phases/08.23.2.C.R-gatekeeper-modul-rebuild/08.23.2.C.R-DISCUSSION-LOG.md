## Toggle-Button Design

| Option | Description | Selected |
|--------|-------------|----------|
| Indikator selbst wird klickbar (span → button) | pip-mode-indicator wird zum button. Kein extra DOM-Element. | ✓ |
| Separater button neben dem Span | Zwei DOM-Elemente, mehr visueller Kontrast. | |

**User's choice:** pip-mode-indicator `<span>` → `<button type="button">` Migration mit vollständiger Pflicht-Liste:
1. aria-label dynamisch ("Modus wechseln zu Entscheider/Sekretär")
2. cursor: pointer bei Hover
3. Hover-State via --pip-gatekeeper-bg-hover (neuer CSS-Token)
4. Mindest-Klick-Fläche: 32px Höhe
5. Label zeigt IMMER aktuellen Modus (nicht Ziel)
6. Tab + Enter als sekundärer Pfad
7. CSS-Token-only
