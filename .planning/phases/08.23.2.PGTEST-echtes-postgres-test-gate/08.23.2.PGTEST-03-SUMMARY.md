## Deviations from Plan

### 1. [Rule 3 - Blocking issue] Logic-group anonymizer write-path runs as nerve_anon_worker, not nerve_app

- **Found during:** Task 2.
- **Issue:** The plan said to port the `test_anonymizer_worker.py` logic group against `TEST_DATABASE_URL`
  (= nerve_app). But `training.*` is the DPO vault — `nerve_app` has **no** access to the training schema
  (CONTEXT.md:111; TAXO3-OQ-1: "permission denied for schema training"). The worker's write path
  (`INSERT training.transcript_archive`) would fail with permission-denied as nerve_app → collection/runtime
  error → fail-closed gate blocks every deploy.
- **Fix:** Ported the logic group to the exact two-role harness the RLS group already uses — **seed** the
  crm.* chain as `nerve_app` under the tenant GUC (`nerve_app_pg_conn`), **run** `process_unstamped` as
  `nerve_anon_worker` (`anon_worker_pg_engine`, the only role with training-write + cross-tenant crm-read),
  scoped via `limit_ids` to the test's own mem_ids. SKIP when either DSN is absent. The plan's *intent*
  (logic group against real PG, MERGE/FILTER/HASH/GATING preserved, `_fake_anonymize` stub kept) is honored.
- **Files modified:** `tests/test_anonymizer_worker.py`.
- **Commit:** `495759b`.

### 2. [Rule 2 - Missing critical functionality] Added id-watermark teardown to committing tests

- **Found during:** Tasks 6/7/9/10.
- **Issue:** `test_ewb_rate_api`, `test_profile_editor_validation`, `test_ab_stats`, `test_cost_tracker`
  COMMIT their Org/User/ConvLog/ObjectionEvent/EwbRating/Profile/ApiRate/ExchangeRate/ApiCostLog rows. On the
  persistent nerve_test (D-03) these would leak past the test → the Plan-01 `_baseline_cleanup_guard` (PUBLIC.*
  xmin watermark) would flag drift → fail-closed gate red. The plan's task text for these only addressed the
  email/count/parent issues, not the leak.
- **Fix:** Added a module-autouse `*_cleanup` fixture per file: snapshots the id-watermark per affected public
  table at setup (via its **own** short-lived engine on TEST_DATABASE_URL, decoupled from whichever
  per-test-rebound MODUL-SessionLocal the test uses), and reverse-FK-deletes all rows created after the
  watermark in the POST-yield section (runs even on assertion failure). Honors the CLAUDE.md test-cleanup rule
  and T-PGTEST-34 (teardown lives in a fixture, never `yield` in a plain test body).
- **Files modified:** `test_ewb_rate_api.py`, `test_profile_editor_validation.py`, `test_ab_stats.py`,
  `test_cost_tracker.py`.
- **Commits:** `9b6bc5f`, `199985d`, `2f91f21`, `444b9da`.
