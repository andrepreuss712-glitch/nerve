## Accomplishments
- Headset-Pflicht modal blocks cold call start until user confirms headset usage (DSGVO compliance)
- sessionStorage flag ensures modal shows once per browser session, resets on tab close
- Meeting mode completely unaffected by the modal gate
- Full accessibility: focus trap, Escape=Cancel, Enter=Confirm when checkbox active
- Logout link clears sessionStorage flag with try-catch safety wrapper

## Decisions Made
- sessionStorage chosen over localStorage so flag resets on tab close (DSGVO requirement)
- Modal gate placed before close() in startCall() to keep launcher visible if user cancels
- All event listeners cleaned up on modal close to prevent memory leaks
- Focus trap cycles through 4 elements: checkbox, cancel button, confirm button, why-link
