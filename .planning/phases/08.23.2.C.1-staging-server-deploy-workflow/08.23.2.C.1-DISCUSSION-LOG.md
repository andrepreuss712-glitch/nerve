**User's choice:** Option 3 mit Verfeinerungen:
- `scripts/setup_staging.sh` — idempotent, läuft auf dem Server, prüft ob Schritte schon erledigt
- Scope ON: apt install, useradd, mkdir, Postgres-User+DB anlegen
- Scope OFF: Hetzner-Console, DNS, SSL-Cert (bleiben Runbook-Schritte)
- `deploy/nerve-staging.service` — neue systemd-Datei analog nerve.service
- nginx-Config-Template mit Platzhaltern für SSL-Cert-Pfad + htpasswd-Pfad
