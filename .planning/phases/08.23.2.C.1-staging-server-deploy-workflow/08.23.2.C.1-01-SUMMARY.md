## Offene manuelle Schritte (Andre)

Andre muss das RUNBOOK-staging.md einmalig durcharbeiten:

1. Hetzner CX32 erstellen (Nuremberg NBG1, Ubuntu 22.04, ~8 EUR/Monat)
2. SSH-Key `~/.ssh/nerve_staging` generieren + in Hetzner eintragen
3. DNS A-Record `staging` → `<STAGING_IP>` setzen
4. `setup_staging.sh` auf Server ausfuehren
5. `/etc/nerve/.env` mit Staging-Keys anlegen (separater Anthropic/Deepgram/Stripe-Test-Key)
6. htpasswd-Datei erstellen: `htpasswd -c /etc/htpasswd.nerve-staging staging`
7. nginx-Staging-Config deployen + nginx reload
8. Certbot: `certbot --nginx -d staging.getnerve.app`
9. `./deploy.sh staging` (nach Plan 02 Refactor)
