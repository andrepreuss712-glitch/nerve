# Phase 08.23.2.TAXO2.HANDLING-TIMING Plan 03: Verhaltens-Judge und Cutover Summary

**One-liner:** LLM-Verhaltens-Judge (EIN forced-Tool-Use-Sonnet-Call, temp=0) am Call-Ende (async, Slow Lane): getaggtes Transkript + Marker + Profil/Briefing -> Beobachtungen mit woertlichem Beleg-Zitat je 4 Dims + separates Compliance-Hard-Gate + Cutover von compute_rubric auf den Judge in slow_lane.py.

## Was gebaut wurde

### Task 1: services/judge_runner.py (neu)

**`run_behavior_judge(call, events, db) -> dict`** — der Judge-Einstiegspunkt:

- **transcript_resolved-Gate (Punkt 26):** kehrt mit `{status:'transcript_not_resolved'}` zurueck wenn `call.transcript_resolved==False` — der Judge laeuft dem Transkript-Write nie voraus.
- **Profil + Briefing:** laedt via `build_profile_context(user_id, mode, sid)` (legitimer Referenz-Massstab).
- **Transkript-Segmente:** `db.query(TranscriptSegment).filter(...).order_by(ts_ms.asc(), id.asc()).all()`.
- **Prompt-Bau** (`_build_judge_prompt`): System + User-Prompt. Rubrik (BARS) an ANFANG UND ENDE des System-Prompts (Lost-in-the-Middle). Outcome physisch nicht geladen/uebergeben. Vorschlaege physisch nicht geladen/uebergeben.
- **JUDGE_TOOL (forced Tool-Use):** Schema pro Dimension: Array von `{beleg_zitat, beobachtung, auspraegung}` Objekten (Beleg-VOR-Note erzwungen). Plus SEPARATE Top-Level-Felder `compliance_violation` (boolean) + `compliance_beleg_zitat` (string) — Cross-AI-Finding 2.
- **EIN Anthropic-Call:** `claude_client.messages.create(model=MODEL_JUDGE, temperature=0, tools=[JUDGE_TOOL], tool_choice={'type':'tool','name':'record_observations'})`.
- **Parse** (`_parse_judge_output`): observations_jsonb `{dim:[{beobachtung,beleg_zitat}]}` + ratings_jsonb `{dim: auspraegung}` (auspraegung NUR intern). Compliance in `observations_jsonb['_compliance']={verletzt,beleg_zitat}` — NICHT in ratings_jsonb.
- **KEIN DB-Write** in `run_behavior_judge` — UPSERT im GUC-geklammerten Slow-Lane-Schritt (Task 2).
- **Fehler-Mantel:** `{status:'judge_failed', error:str}` bei jeder Exception (kein Consumer-Crash, T-HT-03-05).

**`_build_judge_prompt(call, events, profile_briefing, segments) -> (system_str, user_str)`:**
- System: Rolle + Bewertungs-Prinzipien + Compliance-Hard-Gate-Instruktion + Rubrik Anfang+Ende.
- User: Profil/Briefing + getaggtes Transkript `[#i speaker ts_ms ms] text` (ts_ms ASC) + Marker-Liste.
- `_assemble_markers(events, call)`: NERVE-Erkennungen + Audio-Health. Kein Outcome, keine Vorschlaege.

**`_build_dim_observation_schema() -> dict` / `JUDGE_TOOL`:**
- Pro Dimension (4 DIMENSIONS-Keys): Array-Schema mit Pflicht-Feldern beleg_zitat/beobachtung/auspraegung.
- Top-Level: `compliance_violation` (boolean) + `compliance_beleg_zitat` (string) separat (Finding 2).
