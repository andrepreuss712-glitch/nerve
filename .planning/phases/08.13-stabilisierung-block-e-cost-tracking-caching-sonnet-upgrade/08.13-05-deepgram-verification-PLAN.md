Deepgram SDK (deepgram-sdk 3.7.0+): result.metadata hat duration-Attribut.
Aus deepgram Python SDK: LiveResultResponse hat `.metadata.duration` (float, Sekunden).
Fallback falls metadata fehlt: `getattr(getattr(result, 'metadata', None), 'duration', 0.0) or 0.0`

Fix-Pattern (aus RESEARCH.md Sektion 6):
```python
# Modul-Level NEU:
_stt_seconds_accumulated = {}  # {sid: float}

# In on_message bei is_final=True:
_dur = getattr(getattr(result, 'metadata', None), 'duration', 0.0) or 0.0
if _dur > 0:
    _stt_seconds_accumulated[sid] = _stt_seconds_accumulated.get(sid, 0.0) + _dur

# In _close_deepgram_connection:
with _sessions_lock:
    connection = _deepgram_sessions.pop(sid, None)
    _session_modes.pop(sid, None)
    _cost_opened_at.pop(sid, None)   # BEHALTEN fuer ggf. Fallback-Logik, aber nicht mehr als Basis
    stt_sek = _stt_seconds_accumulated.pop(sid, 0.0)  # NEU
try:

                     units=minutes, unit_type='per_minute',
```
