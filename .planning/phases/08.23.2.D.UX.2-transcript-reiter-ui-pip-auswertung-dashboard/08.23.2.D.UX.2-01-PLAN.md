  <action>
    Erstelle `static/n-tabs.js` als reines Vanilla-JS-IIFE (kein Modul-System, kein Build-Step — Stack-Constraint).

    Verhalten (exakt nach UI-SPEC §Component Inventory 1):
    1. **Init-Scan:** Bei `DOMContentLoaded` `document.querySelectorAll('[data-tabs]')` scannen und JEDEN
       Container initialisieren (mehrfach-instanzfaehig — NACHTRAG haengt einen zweiten Reiter dran).
       Pro Container: Buttons = `container.querySelectorAll('.n-tab-btn[data-tab-target]')`,
       Panels = die `.n-tab-panel`-Elemente mit passender `id`.
    2. **Aktivierung (`activate(container, tabId)`):** alle Buttons `aria-selected="false"` + Klasse
       `n-tab-btn--active` entfernen; alle Panels `hidden=true`. Dann den Button mit
       `data-tab-target===tabId` `aria-selected="true"` + `n-tab-btn--active` setzen und das Panel
       mit `id===tabId` `hidden=false`.
    3. **Klick-Handler:** auf jeden Button. Bei Klick: `activate(container, tabId)`,
       dann `history.replaceState(null, '', '#' + tabId)` (NICHT pushState — kein History-Spam),
       dann `localStorage.setItem('n-tabs-last-' + pageId, tabId)`.
       `pageId` = `container.getAttribute('data-tabs-id') || location.pathname` (eindeutiger Key pro Seite).
    4. **Initial-Aktivierung (Prioritaet exakt):** (a) wenn `location.hash` (ohne '#') ein gueltiges
       Tab-Target im Container ist → diesen aktivieren; sonst (b) `localStorage.getItem('n-tabs-last-'+pageId)`
       wenn gueltig → diesen; sonst (c) den ersten Button. URL-Hash schlaegt localStorage (R-03).
    5. **A11y:** Container `role="tablist"` bleibt am `.n-tabs-bar` (kommt aus HTML); JS setzt nur
       `aria-selected` + `hidden`. Optional: Pfeiltasten-Navigation (links/rechts) zwischen Tabs — nice-to-have,
       nicht blockierend.

    Harte Regeln:
    - ASCII-only Identifier: Tab-Targets `uebersicht`/`transkript` (lowercase), localStorage-Key-Prefix
      `n-tabs-last-`. KEINE Umlaute in JS-Variablen/Keys (CLAUDE.md Umlaut-Regel).
    - KEIN onclick-Inline, KEINE Abhaengigkeit von switchTab5/fcd-tab (das ist ein bespoke Precall-Picker,
      NICHT wiederverwendbar — RESEARCH Anti-Pattern).
    - Defensiv: wenn ein Container 0 Buttons oder 0 Panels hat → still ueberspringen (kein throw).
    - Kommentar oben: `// Phase 08.23.2.D.UX.2 — n-tabs: reusable declarative tabs (deep-link + last-tab + ARIA)`
  </action>
