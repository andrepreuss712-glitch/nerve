# Plan 01 SUMMARY — n-tabs.js + nerve.css Transcript-Tokens

## Was gebaut wurde

**Task 1 — `static/n-tabs.js` (neu, 167 Zeilen):** Wiederverwendbare deklarative Tab-Komponente
als reines Vanilla-JS-IIFE (kein Build-Step). Scannt bei `DOMContentLoaded`
`document.querySelectorAll('[data-tabs]')` und initialisiert JEDEN Container (mehrfach-instanzfaehig
fuer NACHTRAG). Verhalten:
- `activate(container, tabId)`: ARIA (`aria-selected`), `.n-tab-btn--active`, Panel-`hidden`-Toggle;
  feuert AM ENDE jeder Aktivierung `CustomEvent('n-tab:activated', {bubbles, detail:{tabId, container}})`
  auf JEDEM Pfad (Klick/Hash/localStorage/Erst-Tab/Initial) — DUX2-03.
- Klick-Handler: `activate` → `history.replaceState(null,'','#'+tabId)` (kein History-Spam) →
  `localStorage.setItem('n-tabs-last-'+pageId, tabId)`. `pageId = data-tabs-id || location.pathname`.
- Initial-Aktivierung Prioritaet R-03: URL-Hash > localStorage > erster Tab. Laeuft ueber `activate()`
  → feuert n-tab:activated auch initial (Deep-Link `/session/<id>#transkript` triggert Plan-03-Fetch).
- `hashchange`-Listener (DUX2-03) fuer In-Page-Navigation mit **Loop-Schutz**: no-op wenn der neue
  Hash bereits der aktive Tab ist (der eigene replaceState-Write loest sonst eine Schleife aus).
- Defensiv: Container ohne Buttons/Panels werden still uebersprungen (kein throw).
- Optional: Pfeiltasten-Navigation (links/rechts), nicht blockierend.
- ASCII-Identifier (CLAUDE.md): `uebersicht`/`transkript`, Event `n-tab:activated`, Key-Prefix `n-tabs-last-`.
