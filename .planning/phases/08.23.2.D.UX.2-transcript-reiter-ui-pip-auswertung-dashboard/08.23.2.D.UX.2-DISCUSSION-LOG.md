## Datenquelle Live vs. persistiert

| Option (Live-Quelle) | Description | Selected |
|--------|-------------|----------|
| Roher Echtzeit-Text | RAM-Puffer, unanonymisiert, eigener Bildschirm | ✓ |
| Live anonymisiert | Pipeline live laufen lassen (Latenz/Kosten) | |

| Option (Persistiert) | Description | Selected |
|--------|-------------|----------|
| Neuer Endpoint aus DB | GET /api/transcript/<id>, org-scoped, anonymisiert | ✓ |
| Server-seitig direkt ins Template | Segmente beim Render mit-rendern | |

| Option (Post-Call-PiP) | Description | Selected |
|--------|-------------|----------|
| Live-RAM-Puffer weiternutzen | Sofort, roh, konsistent mit Live | ✓ |
| Frisch aus DB | Endpoint, anonymisiert, Race-Risiko | |

**User's choice:** Live = roher RAM-Text; Dashboard = neuer Endpoint (anonymisiert); Post-Call-PiP = RAM-Puffer.
**Notes:** Bewusste Folge: PiP roh, Dashboard anonymisiert — gewollt.
