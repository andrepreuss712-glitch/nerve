## Color

### 60/30/10 Split — Base Surfaces

| Role | Value | CSS Token | Usage |

| Destructive | #EF4444 | `--danger-red` | No destructive actions in this phase |

### Primary Accent (#00D4AA / `--btn-primary-bg-from`) — Reserved for ONE focal element per screen context

The 60/30/10 hierarchy is preserved by restricting the teal accent to **a single high-signal element per context**. All other interactive affordances use neutral/ghost tokens so the accent reads as the clear primary focal point.

| Screen context | PRIMARY accent target | Rationale |
|----------------|-----------------------|-----------|
| PiP live (Context 1) | **"↓ Neueste" auto-scroll-resume button** | The one action that pulls the user back to the live feed; it must stand out at a glance against the dark compact panel |
| Large evaluation (Context 3) | **Current search match highlight** (`--transcript-highlight-current-bg`) | The exact segment the user is hunting for — transient focal point that changes per keystroke; only the CURRENT match uses strong accent |

**Teal token assignments:**

```css
/* Accent — PRIMARY focal element, PiP live */
/* "↓ Neueste" button — uses --btn-primary-* tokens (background: --btn-primary-bg-from #00D4AA) */

/* Accent — PRIMARY focal element, large eval */
--transcript-highlight-current-bg: rgba(0, 212, 170, 0.55);  /* current search match only */

/* Sub-accent — non-current search matches (transient content emphasis, not interactive chrome) */
--transcript-highlight-bg:         rgba(0, 212, 170, 0.25);  /* 25% opacity — clearly subordinate */
--transcript-highlight-text: inherit;

/* Berater speaker color — brand teal for identity (not interactive affordance) */
--transcript-berater-color:  #00D4AA;
--transcript-berater-bg:     rgba(0, 212, 170, 0.08);
```

> Non-current search matches use 25% teal — acceptable as transient content emphasis (not interactive chrome). Only one CURRENT match shows the strong 55% accent at any time, so the "single focal point" rule is satisfied per render frame.

## Component Inventory

### 1. `n-tabs` Vanilla JS Component (R-01 — THE deliverable)

**Contract:** Declarative HTML via data-attributes. Zero logic duplication across session_detail.html and Phase NACHTRAG.

**HTML signature:**
```html
<div class="n-tabs" data-tabs>
  <div class="n-tabs-bar" role="tablist">
    <button class="n-tab-btn" role="tab"
            data-tab-target="uebersicht"
            aria-selected="true">Übersicht</button>
    <button class="n-tab-btn" role="tab"
            data-tab-target="transkript"
            aria-selected="false">Transkript</button>
  </div>
  <div class="n-tab-panel" id="uebersicht" role="tabpanel">…</div>
  <div class="n-tab-panel" id="transkript" role="tabpanel" hidden>…</div>
</div>
```

**Behavior:**
- On init: read URL hash → activate matching tab; else activate first tab
- On tab click: deactivate all, activate clicked, update hash (`history.replaceState`)
- Remember last tab: `localStorage.setItem('n-tabs-last-{pageId}', tabId)` — lower priority than URL hash
- Hash format: `#transkript`, `#uebersicht` — lowercase ASCII only (CLAUDE.md identifier rule)
- `aria-selected` toggled on each click; `hidden` attribute toggled on panels

**CSS classes (ASCII identifiers per CLAUDE.md):**
```
.n-tabs              — container
.n-tabs-bar          — tab button row
.n-tab-btn           — individual tab button (uses --pill-bg / --pill-text for inactive)
.n-tab-btn--active   — active state: transparent bg, --page-text-color (#1a1a1a), weight 600,
                       2px solid bottom border using --glass-border (#E2E8F0)
                       DO NOT use .n-pill-active (that resolves to teal #00D4AA)
.n-tab-panel         — content panel
.n-tab-panel[hidden] — display: none
```

**File location:** `static/n-tabs.js` (new file) + styles in `static/nerve.css` (new section)

### 2. Transcript Panel — Large Evaluation (Context 3)

**Location:** New `#transkript` tab panel inside session_detail.html (R-02 refactor)

**Layout:**
```
┌─────────────────────────────────────────────────────┐
│  [Übersicht]  [Transkript]          <- n-tabs-bar     │
├─────────────────────────────────────────────────────┤
│  TRANSKRIPT TAB PANEL                               │
│  ┌────────────────────────────────────────────────┐ │
│  │ 🔍 [Suche im Transkript…________] ◀ ▶ 3 / 12  │ │  <- search bar
│  │ [Ganzes Transkript kopieren]                   │ │  <- copy-all button
│  ├────────────────────────────────────────────────┤ │
│  │ BERATER  00:14   Text des Berater-Segments…    │ │
│  │ KUNDE    00:42   Text des Kunden-Segments…     │ │
│  │ BERATER  01:03   Weiterer Text…               │ │
│  └────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

**Transcript segment row:**
- Speaker label: 40px fixed width, uppercase, 11px weight 600, color from speaker token
- Timestamp: 11px JetBrains Mono, `--transcript-timestamp-color`
- Text: 14px Inter weight 400, `--page-text-color`, natural text wrapping, `user-select: text`
- Row padding: 8px top/bottom, 0 horizontal (inner panel handles horizontal padding)
- Row hover: subtle `--glass-bg` background at rgba(0,0,0,0.02)

**Search bar:**
- Input: `--input-*` tokens (border, radius 12px, focus ring via `--input-border-focus`, `--input-focus-glow`)
- Placeholder text: "Suche im Transkript…" (real Umlaut per CLAUDE.md)
- Navigation: ◀ ▶ buttons (ghost, icon-only, 32x32px)
- Counter: "3 / 12" (12px JetBrains Mono) or "Keine Treffer" when 0
- Current match: `--transcript-highlight-current-bg` (teal 55% — PRIMARY accent); other matches: `--transcript-highlight-bg` (teal 25%)
- Text stays in context — no filtering of segments

**Copy-all button:**
- Label: "Ganzes Transkript kopieren"
- Style: `n-btn n-btn-ghost` (existing class — neutral, no teal)
- Feedback: button text switches to "Kopiert ✓" for 1500ms then reverts (no toast, inline)

**Search input HTML id/class (ASCII):** `id="transcript-search-input"`, class `transcript-search-bar`

### 3. PiP Transcript Panel — Live During Call (Context 1, PT-01)

**Trigger:** "Transkript ▶" toggle button inside existing PiP coaching view

**Layout (side-by-side, ≥900px achieved):**
```
┌──────────────────────────────────────────────────────────────────┐
│  PiP Window ~960px                                                │
│  ┌──────────────────┐   ┌──────────────────────────────────────┐ │
│  │  TRANSKRIPT      │   │  COACHING (existing PiP content)     │ │
│  │  (links, ~480px) │   │  (rechts, ~480px)                    │ │
│  │                  │   │                                      │ │
│  │  BERATER  00:14  │   │  [existing coaching panels]          │ │
│  │  Text…           │   │                                      │ │
│  │  KUNDE    00:42  │   │                                      │ │
│  │  Text…           │   │                                      │ │
│  │  ─────────────── │   │                                      │ │
│  │  [↓ Neueste]     │   │                                      │ │
│  └──────────────────┘   └──────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

**Fallback layout (<900px achieved after resize attempt):**
- Overlay panel: absolute-positioned, covers coaching content
- Full width of PiP (480px)
- "Schließen ×" button top-right to dismiss and show coaching again

**Toggle button:**
- Default label (transcript hidden): "Transkript ▶" (icon: `data-lucide="file-text"`, 16px)
- Active label (transcript visible): "Transkript ◀" (same icon)
- Style: `n-btn n-btn-ghost` small variant, padding 6px 12px — neutral, no teal glow in either state
- Active/on state visual: `--btn-ghost-bg-hover` (`rgba(0,0,0,0.07)`) + `--btn-ghost-border-hover` (`rgba(0,0,0,0.2)`) — no accent
- Position: appended to existing PiP header controls row

**Resize-on-toggle behavior (from spike blueprint):**
```
click → resizeTo(960, 900) → setTimeout 350ms → measure pipWindow.innerWidth
  ≥ 900 → render side-by-side
  < 900 → render fallback overlay
```
No auto-resize on page load. Toggle click IS the gesture.

**Compact speaker line (PiP, PT-03):**
- Speaker label: "BERATER" / "KUNDE" — uppercase, 11px, weight 600, speaker color token, min-width 52px
- Timestamp (optional): 10px JetBrains Mono, muted — hidden if segment has no ts_ms
- Text: 13px Inter weight 400, line-height 1.4, truncation: none (full text, wraps)
- No row separator lines — whitespace only (4px gap between rows)
- Horizontal padding: 8px

**Auto-scroll behavior (PT-02):**
- Initial state: auto-scroll ON — list is scrolled to bottom as segments arrive
- Pause condition: user scrolls up (scrollTop + clientHeight < scrollHeight - 10px threshold)
- When paused: show "↓ Neueste" button (fixed at bottom of panel)
  - Style: 28px height, 8px 16px padding, rounded pill, `--btn-primary-*` tokens (teal — PRIMARY accent for PiP context)
  - Label: "↓ Neueste"
  - Click: scroll to bottom, hide button, resume auto-scroll
- Resume auto-scroll: only on "↓ Neueste" click (not on programmatic scroll)

**Data feed mechanism:** Existing SocketIO `transcript` event (already in pip-launcher.js — live RAM buffer, DQ-01). Executor reads existing event payload format: `{speaker, text, ts_ms}` (per UX.1 CONTEXT schema).

**Hidden-by-default (R-01 coordination):** The PiP transcript toggle is NOT a tab — it is a panel toggle. Tabs are for the large evaluation only. PiP uses a show/hide button pattern.

### 4. PiP Post-Call Transcript (Context 2)

**When:** After user confirms outcome on PiP outcome screen (D.UX.4 built the hook — "Platz gelassen").

**Access pattern:** A "Transkript ansehen" link/button appears in the PiP post-call score view, adjacent to the score display. This is a secondary CTA (ghost style), not the primary action.

**Panel behavior:** Same compact speaker-line display as live PiP panel (Context 1). Auto-scroll OFF (call is over — user reads from beginning or scans). No "↓ Neueste" button needed.

**Data source:** Live RAM buffer (DQ-03) — raw text, not anonymised. This is correct and intentional per CONTEXT.md.

**Layout:** Full-width of PiP (480px). Rendered inline below the score summary. No side-by-side needed (call is over, coaching panel irrelevant).

**Toggle:** "Transkript" button with chevron-down icon. Tap to reveal, tap again to collapse. Default: collapsed.
