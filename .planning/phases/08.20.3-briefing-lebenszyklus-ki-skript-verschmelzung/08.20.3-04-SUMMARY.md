## What Was Built

**Task 1 — base.html:**
- `#pip-briefing-tab` div inserted between `#pip-header` and `#pip-anrede-row`
- Collapsible via `max-height: 0` / `max-height: 300px` CSS transition (200ms ease)
- Initial `display:none` — JS controls visibility based on `state.briefingModus`
- `data-briefing-toggle="1"` on header for event delegation in `_wirePipButtons()`
- No `<textarea>`, no `contenteditable` — fully read-only (Req 14)
- Script-load-order comment added (pip-launcher.js before window.mdToHtml consumers)

**Task 2 — pip-launcher.js (7 edits):**
- **Edit 1:** 4 new state keys: `briefingModus`, `briefingTabExpandedAtStreamStart`, `_personalizedSkriptText`, `_personalizeAbortController`
- **Edit 2:** `renderStep()` pre-check for string pseudo-steps `'4b'` / `'4c'` before switch (Landmine L1 fix — switch never matches string vs number)
- **Edit 3:** `_initPipLive()`: show/hide briefing tab, populate title + content via `mdToHtml()`, education hint logic
- **Edit 4:** `_expandBriefingTab()`, `_collapseBriefingTab()`, `_isBriefingTabExpanded()` helper functions
- **Edit 5:** `_wirePipButtons()`: `data-briefing-toggle` event delegation branch with education-hint timer cancel
- **Edit 6:** `pip_stream_start`: set `briefingTabExpandedAtStreamStart` guard; `pip_token_done`: auto-collapse if guard was set
- **Edit 7:** `window.mdToHtml = mdToHtml` exposed at end of IIFE
