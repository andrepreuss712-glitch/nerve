### Task 1 — wizard_create() Schema-Migration

In `routes/profiles.py` Funktion `wizard_create()` (Zeilen 115-129): Das daten-Dict von Flat-Schema auf basis.*-Schema umgestellt.

**Vorher (Flat-Schema):**
```python
daten = json.dumps({
    'firma': firma,
    'produkt': produkt,
    'zielkunden': zielkunden,
    'rolle': rolle,
    'einwaende': einwaende_list,
}, ensure_ascii=False)
```

**Nachher (basis.*-Schema):**
```python
daten = json.dumps({
    'basis': {
        'produktbeschreibung': produkt,
        'zielkunden': zielkunden,
        'einwaende': einwaende_list,
        'phasen': [],
    },
    'ki': {
        'anrede': 'Sie',
    },
    'meta': {
        'firma': firma,
        'rolle': rolle,
    },
}, ensure_ascii=False)
```

Konsistenz sichergestellt mit:
- `qa_pipeline.py` Zeile 374: `basis = (daten.get('basis') or {})`
- `api_tabu_update` in `profiles.py`: schreibt in `pdata['basis']['tabu_begriffe']`
- `BRANCHE_TEMPLATES` aus Plan 01: alle 8 Branchen verwenden `basis.produktbeschreibung`
