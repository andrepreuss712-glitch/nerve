## What Was Built

### Task 1 — LB-11: Onboarding-Redirect in auth.py

In `routes/auth.py` `login_required` Decorator: 3 auskommentierte Zeilen (seit Commit 6b57a77 "deploy hardening") durch aktiven `if`-Block ersetzt.

```python
if not onboarding_done and not request.path.startswith('/onboarding'):
    return redirect(url_for('onboarding.wizard'))
```

`onboarding_done` default=`True` (Zeile 57) stellt sicher dass bestehende User NICHT umgeleitet werden — nur neue User mit `onboarding_done=False`.

T-08.9-03 mitigated: `/onboarding`-Pfad-Guard verhindert Redirect-Loop fuer `/onboarding/` und `/onboarding/complete`.

### Task 2 — H-31/HSR-2: BRANCHE_TEMPLATES auf basis.*-Schema

Alle 8 Branchen in `BRANCHE_TEMPLATES` (SaaS, Versicherung, Consulting, Recruiting, Immobilien, Agentur, Industrie, Sonstiges) erhalten `'basis'`-Wrapper:

```python
'SaaS': {
    'basis': {
        'produktbeschreibung': 'SaaS-Lösung',
        'einwaende': [...],
        'phasen': [...],
    },
},
```

Top-Level-Keys `'produkt'`, `'einwaende'`, `'phasen'` entfernt. Key-Name `produktbeschreibung` (nicht `produkt`) — konsistent mit `qa_pipeline.py` Zeile 374 (`basis = (daten.get('basis') or {})`).

`create_profile_from_template()` angepasst — liest Zaehler aus `template.get('basis', {})`:

```python
_basis = template.get('basis', {})
return jsonify({..., 'einwaende': len(_basis.get('einwaende', [])), 'phasen': len(_basis.get('phasen', []))})
```

Zeile 203 (`daten=json.dumps(template, ...)`) unveraendert — template wird als Ganzes inkl. `basis`-Wrapper gespeichert.

### Task 3 — DB-Migration: Demo-Profile Flat-Schema → basis.*-Schema

Am Ende von `_migrate()` in `app.py` idempotente Migration eingefuegt:

- Prueft Profile IDs 2, 3, 4 in der DB
- Idempotenz-Check: `if 'basis' in _daten: continue`
- Flat-Schema-Erkennung: nur wenn `'produkt'` oder `'einwaende'` auf Top-Level
- Umstrukturierung: `produkt` → `basis.produktbeschreibung`, `einwaende` → `basis.einwaende`, `phasen` → `basis.phasen`
- Print pro migriertem Profil: `[DB] Migration 08.9: Profil ID {pid} auf basis.*-Schema migriert`
