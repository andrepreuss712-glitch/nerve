## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Schema Fields] KiSchema: antwortlaenge + sensitivitaet fehlten**
- **Found during:** Task 1 Smoke-Test
- **Issue:** Profil 1 hatte `ki.antwortlaenge='1-2 Saetze'` und `ki.sensitivitaet='hoch'` — beides echte Production-Felder die der Editor schreibt, nicht im KiSchema modelliert
- **Fix:** `antwortlaenge: str = ''` und `sensitivitaet: str = ''` zu KiSchema ergaenzt
- **Files modified:** services/profile_schema.py
- **Commit:** 51faba5

**2. [Rule 2 - Missing Schema Fields] ZielgruppeSchema: Legacy-Felder position/unternehmen/branche fehlten**
- **Found during:** Task 1 Smoke-Test
- **Issue:** Profile 2/3/4 hatten `zielgruppe.position`, `zielgruppe.unternehmen`, `zielgruppe.branche` — Legacy-Felder aus vor-ZielkundeSchema-Aera, sind auf schema_version=3 und werden nicht nochmals migriert
- **Fix:** 3 Legacy-Felder als `str = ''` in ZielgruppeSchema aufgenommen
- **Files modified:** services/profile_schema.py
- **Commit:** 51faba5

**3. [Rule 1 - Bug] 6 bestehende Tests in test_08_19_01_profile_schema.py brachen durch v3-Migration**
- **Found during:** Task 2
- **Issue:** Tests prueften `schema_version == 2` (Migration jetzt bis v3), `erlaubnis` entfernt (war nie entfernt — transitional), `pitch` entfernt (transitional bis 08.20), `ProfileSchema ignoriert unbekannte Felder` (jetzt extra='forbid')
- **Fix:** Tests auf aktuelles Verhalten aktualisiert
- **Files modified:** tests/test_08_19_01_profile_schema.py
- **Commit:** 8ceb847

**4. [Rule 1 - Bug] Synthetisches basis.einwaende Fixture: List[str] statt List[dict]**
- **Found during:** Task 2 erste Test-Ausführung
- **Issue:** `ProfileSchema.einwaende: List[dict]` — Fixture verwendete `['Zu teuer', 'Kein Budget']` (List[str])
- **Fix:** Fixture auf `[{'einwand': '...', 'gegenargument': '...'}]` (List[dict]) umgestellt
- **Files modified:** tests/test_profile_schema_v3.py
- **Commit:** 8ceb847
