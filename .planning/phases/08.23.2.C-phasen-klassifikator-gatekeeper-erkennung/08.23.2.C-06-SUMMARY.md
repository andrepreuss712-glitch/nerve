## What Was Built

### Task 1: services/gatekeeper.py

Neues Kernmodul mit 6 exportierten Funktionen:

- **`classify_contact(window, ceo_name, mode)`** — UNION/CONSENSUS-Voting (Review Finding 4): `all_persons = spacy | gliner` fuer target (Recall-Maximierung), `consensus = spacy & gliner` fuer gatekeeper (FP-Minimierung). Returnt `'target' | 'gatekeeper' | 'unknown'`.
- **`_names_match(extracted, briefing)`** — RapidFuzz fuzzy (threshold=80), Substring-Overlap, Exact-Match. Kein eigener spaCy/GLiNER-Import (DRY-Pflicht D-02).
- **`detect_trigger_phrases(line)`** — scant einzelne Zeile auf TRIGGER_PHRASES, returnt `{'matches': [...], 'hard_block': bool}`.
- **`detect_uwg_hard_block(line)`** — schneller Single-Purpose-Check auf UWG_HARD_BLOCK_PATTERNS.
- **`apply_hysteresis(state, proposed, mode)`** — 3-Bedingungen: (1) >=2 aufeinanderfolgende Hints, (2) Mindest-Verweildauer aus MIN_PHASE_DURATIONS, (3) Uebergang in ALLOWED_TRANSITIONS. Mutiert state IN-PLACE.
- **`populate_context_notes(state, entity)`** — Foundation-Stub fuer Phase 08.23.2.I (pass-Body).
- **`get_gatekeeper_phase_for_window(window)`** — heuristischer String-Mapper fuer Tests.

### Task 2: Session-State + create_call_for_sid

`init_session_state()` um 9 Phase-C-Keys erweitert (alle in `_session_state[sid]['state']`, NICHT in `ls.state` global):

```
contact_category:   'unknown'   # 'target' | 'gatekeeper' | 'unknown'
current_mode:       'cold_call' # initial; gatekeeper-Erkennung aendert diesen Key
context_notes:      []          # Phase 08.23.2.I befuellt
phase_hint_count:   0           # Hysterese-Counter
pending_phase:      None        # Zwischenspeicher fuer vorgeschlagene Phase
phase_entered_at:   None        # monotonic seconds fuer Dwell-Check
call_id:            None        # UUID nach create_call_for_sid()
uwg_blocked:        False       # True nach detect_uwg_hard_block()
```

`create_call_for_sid(sid, user_id, call_mode)` — legt Call-Record an, mappt unbekannte Modi auf 'cold_call' (CHECK-Constraint), schreibt call_id in State.

### Task 3: Loops verdrahtet

- UWG-Guard am Anfang der for-SID-Schleife: `uwg_blocked -> continue`

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] RapidFuzz-Threshold auf 80 korrigiert (statt 85)**
- **Found during:** Task 1 Verifikation
- **Issue:** Plan schreibt Threshold 0.85, aber Plan-Acceptance-Criterion fordert `_names_match('meyer', 'Meier') == True`. `fuzz.ratio('meyer', 'meier') = 80.0` — Threshold 85 wuerde das Plan-Criterion verfehlen.
- **Fix:** Threshold auf 80 gesenkt. `meyer`/`meier` = 80%, `mueller`/`muller` = 92%, `schroeder`/`schroeder` = 100%. DE-Phonetik-Varianten korrekt abgedeckt.
- **Files modified:** services/gatekeeper.py (Kommentar erklaert Entscheidung)
- **Commit:** 3e01035

**2. [Rule 3 - Blocking] config/__init__.py re-exportiert config.py-Konstanten**
- **Found during:** Task 2 Verifikation

- **Fix:** `config/__init__.py` laedt `config.py` via `importlib.util` und re-exportiert alle public-Namen. Beide Importe funktionieren: `from config import ANALYSE_INTERVALL` (aus config.py) und `from config.phase_transitions import HYSTERESIS_REQUIRED_HINTS` (aus config-Package).
