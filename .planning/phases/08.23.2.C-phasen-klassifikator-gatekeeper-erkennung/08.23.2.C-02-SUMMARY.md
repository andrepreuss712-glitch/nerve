## Decisions Made

- `server_default='cold_call'` in Migration und Model identisch gesetzt — garantiert dass bestehende Postgres-Zeilen automatisch den Default bekommen und compare_type=True kein Drift-Alarm ausloest
- kein SQLAlchemy-Layer-CHECK-Constraint im Model — Postgres erzwingt via Migration; Application-Layer setzt Wert immer aus Hardcoded-Konstanten
- downgrade nutzt `DROP CONSTRAINT IF EXISTS` (defensiv)
