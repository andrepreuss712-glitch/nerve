## Spacing Scale

| Token | Value | Usage |

## Typography

All type is inside the PiP window (dark background). The PiP is a separate `Document` that inherits the copied stylesheets from the main tab.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body / slot text | 14px | 400 | 1.5 | Inter | KI slot streaming text, teleprompter block text, gegenargument text, consent body text, teleprompter empty state |
| Label / section title | 12px | 700 | 1.4 | Inter | "KI-Hinweise", "Skript", slot type labels, consent subtext, slot label badges, opacity slider "BG" label |
| Heading | 16px | 700 | 1.3 | Inter | Consent screen main prompt text, opener headline |
| Mono / timer | 12px | 400 | 1.0 | JetBrains Mono | Call timer, KB score percentage in proactive slot |

**Permitted sizes:** 12px, 14px, 16px (3 sizes — under maximum of 4).
**Permitted weights:** 400 (regular) and 700 (bold) — exactly 2 weights. Weight 600 is not used in this phase.

Maximum 4 sizes declared. No additional sizes permitted in this phase.

## Color

The PiP window is always dark. The main page (--page-bg) is currently `#F0F2F5` (light mode per nerve.css), but PiP uses its own hardcoded dark background of `#06060a` per existing CSS. Phase 06 keeps this PiP-specific dark palette.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) — PiP dark bg | `#06060a` | PiP window base background (rgba alpha = 1.0 default, slider adjustable) |
| Secondary (30%) — card/slot bg | `rgba(255,255,255,0.05)` | Individual KI slots, teleprompter container, consent box background |
| Accent (10%) — teal | `#00D4AA` | Reserved: active teleprompter block left border, streaming cursor, EWB button hover/active, consent [Stattgegeben] button, active slot result border, KB trend positive indicator |
| Destructive | `#f87171` | Reserved: consent [Abgelehnt] button, "Beenden" button hover state, KB trend negative indicator |

Accent `#00D4AA` is explicitly reserved for:
1. Active `.tp-block-active` left border (4px solid teal)
2. Streaming cursor `▌` character color
3. EWB button `border-color` + `color` on hover/press
4. Consent "Stattgegeben" button background
5. "Stattgegeben" confirmation state badge
6. Proactive slot positive KB trend value

Accent is NOT used for: general text, section separators, inactive states, backgrounds.

Secondary semantic color `#d4a853` (gold) is used exclusively for KI-selected EWB button state (`.pip-ewb-ai-selected`). This is an existing pattern — no change in phase 06.

## Component Inventory

### 1. PiP Header (replaces existing header — minimal change)

Structure: `[mode-badge] [timer]` left — `[opacity-slider] [fullscreen-link]` right.

- Mode badge: existing `.pip-mode-badge` — keep as-is
- Timer: existing `.pip-timer` (JetBrains Mono, teal) — keep as-is
- Opacity slider: `<input type="range" id="pip-opacity-slider" min="10" max="100" step="5">` — new element
  - Track: 4px height, `rgba(255,255,255,0.12)` track color
  - Filled track: `#00D4AA` via CSS accent-color or custom pseudo
  - Thumb: 16px diameter, white (`#ffffff`), no border
  - Width: 80px — compact, fits in header
  - Label: "BG" in 12px / weight 700 to left of slider
  - Visible: only when `pip-section-live` is active (hidden in setup and consent)
- Fullscreen link: `aria-label="Vollbild öffnen"` — accessibility label on the `<a>` or `<button>` element

### 2. KI Upper Zone (55% of live area height)

Two-slot horizontal layout. Each slot is equal width (50% - 8px gap).

**Slot structure** (applied to both `#pip-slot-0` and `#pip-slot-1`):
```
.pip-ki-slot
  .pip-slot-label      ← "Antwort A" / "Antwort B" or contextual type label
  .pip-slot-body       ← streaming text rendered here, cursor via ::after
  .pip-slot-result     ← rendered after pip_token_done (hidden during stream)
```

- Slot border: `1px solid rgba(255,255,255,0.08)`
- Slot border-radius: 12px
- Slot padding: 12px (compact token — for small PiP viewport)
- Slot background: `rgba(255,255,255,0.04)` (slightly lighter than window bg)
- Active streaming slot: `border-color: rgba(0,212,170,0.3)` — subtle teal pulse

**Slot label typography:** 12px / weight 700 / letter-spacing 0.08em / uppercase / color `rgba(255,255,255,0.4)` — unobtrusive

**Slot result layout** (after stream completes):
- Einwand-Typ: 12px badge (`.pip-slot-typ-badge`) — color per typ: Preis = gold, Kein Bedarf = coral, Vertrauen = blue, etc. (follow existing badge palette)
- Gegenargument text: 14px / weight 400 / line-height 1.5 / color `#e8ecf4`
- Transition: fade-in over 150ms

**Streaming cursor:**
```css
.pip-slot-body.pip-streaming::after {
  content: '▌';
  animation: pip-cursor-blink 0.7s step-end infinite;
  color: #00D4AA;
  margin-left: 2px;
}
@keyframes pip-cursor-blink {
  0%, 100% { opacity: 1; }
  50% { opacity: 0; }
}
```

**Proactive fill states** (when no einwand active — D-02):
- Phase-Wechsel-Hinweis: slot label = "PHASE", body text = phase name, small right-arrow indicator
- Frage-Vorschlag: slot label = "FRAGE", body = suggested question text
- KB-Trend: slot label = "KAUFBEREITSCHAFT", body = score in JetBrains Mono + trend arrow (up = teal, down = coral)

### 3. Teleprompter Lower Zone (45% of live area height)

Container: `#pip-teleprompter` with `overflow-y: scroll` (not `auto` — always show scrollbar track to reinforce scrollability).

Scrollbar styling (WebKit, inside PiP document):
- Width: 4px
- Track: transparent
- Thumb: `rgba(255,255,255,0.15)`, border-radius 2px

**Block element** `.tp-block`:
- Padding: 12px 16px (compact vertical, md horizontal)
- Border-left: 4px solid transparent (inactive)
- Border-radius: 0 8px 8px 0
- Font: 14px / weight 400 / line-height 1.5 / color `rgba(255,255,255,0.4)` (inactive = 40% opacity — D-14)
- Cursor: pointer (manual scroll override affordance)
- Transition: opacity 200ms, border-color 200ms

**Active block** `.tp-block-active`:
- Border-left: 4px solid `#00D4AA`
- Font color: `#e8ecf4` (full brightness, not rgba)
- Background: `rgba(0,212,170,0.06)` — very subtle teal wash
- Scroll behavior: `scrollIntoView({ behavior: 'smooth', block: 'center' })`

**Empty / null state** `.tp-empty`:
- Text: "Kein Skript hinterlegt — Profil bearbeiten"
- Font: 14px / weight 400 / color `rgba(255,255,255,0.3)` / text-align center
- Padding: 24px 16px

**Divider between upper KI zone and lower teleprompter zone:**
- `1px solid rgba(255,255,255,0.08)` horizontal rule
- No margin-collapse — 0px explicit

### 4. EWB Button Row

Existing pattern `.pip-ewb-row` / `.pip-ewb-btn` — keep unchanged. These buttons sit below the KI upper zone, above the teleprompter divider. Height: 44px row (touch target compliance).

### 5. Consent Screen (`#pip-section-consent`)

Full-height section replacing the live section during consent flow (D-05).

Layout: centered column, padding 24px.

Elements top-to-bottom:
1. NERVE logo mark (12px height "N" lettermark in teal) — optional, but grounding
2. Heading: "Consent erforderlich" — 14px / weight 700 / color `#e8ecf4`
3. Consent text block: `#pip-consent-text` — 14px / weight 400 / line-height 1.6 / color `rgba(255,255,255,0.7)` / background `rgba(255,255,255,0.05)` / border-radius 8px / padding 12px 16px
4. Gap: 16px
5. Two buttons side by side:
   - [Stattgegeben]: `background: #00D4AA` / `color: #06060a` / weight 700 / 14px / border-radius 8px / padding 12px 20px / full width
   - [Abgelehnt]: `background: rgba(248,113,113,0.08)` / `color: #f87171` / `border: 1px solid rgba(248,113,113,0.2)` / weight 700 / 14px / border-radius 8px / padding 12px 20px / full width

### 6. Opacity Slider (detail — D-16)

Implementation: `rgba()` on `#pip-section-live` background — NOT `opacity` property (to avoid cascading to children).

CSS variable approach:
```css
#pip-section-live {
  background: rgba(6, 6, 10, var(--pip-bg-alpha, 1.0));
}
```

JS: `liveEl.style.setProperty('--pip-bg-alpha', value)` — set on the element itself (not `:root`), required because PiP is a separate Document.

Slider range: `min="10" max="100" step="5"` — maps to 0.1–1.0 alpha (min 10% to ensure window boundary is always visible when hovering).

localStorage key: `nerve_pip_opacity` (string, float 0.1–1.0).

## Interaction Contracts

### Streaming Flow

| Event | Frontend Action |
|-------|----------------|
| `pip_stream_start` {slot} | Clear slot body, add `.pip-streaming` class, show cursor |
| `pip_token` {slot, token} | Append token to slot body text, no other action |
| `pip_token_done` {slot, result} | Remove `.pip-streaming`, call `renderPipSlotResult(slot, result)` |
| `pip_stream_error` {slot, error} | Remove `.pip-streaming`, show error text in slot: "KI-Fehler — bitte erneut versuchen" |

### Dual-Slot Decision Logic (frontend state machine — D-03)

Backend determines slot assignment via `slot_id` in events. Frontend state mirrors:

```
_pipSlots[0..1] = { streaming: bool, text: string, result: object|null }
```

On `pip_stream_start` with slot=0 while `_pipSlots[0].streaming === true`:
- Do not clear slot 0 (it finishes naturally)
- Slot 1 receives the new stream

On topic-switch signal (special `pip_stream_start` with `replace_all: true`):
- Both slots: clear text, remove `.pip-streaming`, discard pending tokens
- Both slots: restart from incoming stream

### Teleprompter Manual Override (D-13)

- On `scroll` event on `#pip-teleprompter`: set `_teleprompterManualOverride = true`
- Clear flag after 8 seconds of no new `skript_position` event
- When `skript_position` arrives and override is active: update internal position tracking but do NOT scroll (honor user's manual position)
- When `skript_position` arrives and override is inactive: update block highlight + scroll smoothly

### Opacity Slider

- `input` event (not `change`) — live feedback as slider moves
- Debounce localStorage write at 200ms (not on every pixel)
- Initialize from localStorage on `initPipContent()` call inside `openPipWindow()` callback

## Implementation Notes for Executor

1. **CSS lives in `<style>` block inside `app.html`** — same pattern as all existing PiP styles. New classes prefixed `.pip-ki-`, `.pip-slot-`, `.tp-`, `.pip-consent-`.

2. **Background transparency on PiP root element** — use `rgba(6,6,10,var(--pip-bg-alpha,1.0))` on `#pip-section-live` element's inline style. CSS variable set via `element.style.setProperty()`. Do NOT set on `document.documentElement` of main tab — it won't cross the PiP document boundary.

3. **Scrollbar inside PiP** — target `#pip-teleprompter::-webkit-scrollbar` in the stylesheet that gets copied into the PiP document by `openPipWindow()`. This works because `cssRules` are copied.

4. **`ownerDocument` for element creation** — when building teleprompter blocks via `document.createElement()`, use `container.ownerDocument.createElement()` so elements belong to the PiP document, not the main tab document.

5. **Slot heights** — KI zone uses `flex: 0 0 55%`, teleprompter zone uses `flex: 1` with `min-height: 0` and `overflow-y: scroll`. This prevents teleprompter from being crushed when KI slots have long content.

6. **EWB row position** — EWB row sits inside the KI zone (below the two slots), not between zones. Height 44px. This maintains the "KI+EWB as one operational unit" mental model.
