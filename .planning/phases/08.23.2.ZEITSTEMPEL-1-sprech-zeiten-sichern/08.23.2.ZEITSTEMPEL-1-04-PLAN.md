## 4. Edge-Case-Analyse (Punkt 14)

1. **`words` ist leer bei `is_final=True`** (laut Deepgram bei reinen Interpunktions-Ergebnissen
   moeglich): `_extract_word_times` gibt `(None, None, None)` zurueck; die Zeile wird trotzdem
   geschrieben, mit NULL in allen vier Spalten. Ehrlich statt geraten. `words[0]` wird nie auf
   einer leeren Liste angefasst.
2. **`result` ist kaputt / hat kein `channel`**: `_extract_word_times` faengt `Exception` ab und
   gibt `(None, None, None)`. Muster von `_get_speaker` (`:58-70`). Der Live-Loop-Thread darf hier
   nie sterben.
3. **Ghost-SID** (Session bereits beendet, Callback noch unterwegs): alle drei Zugriffe pruefen
   `sid in ls._session_state` bzw. `.get(sid)` auf `None` — wie der Bestandscode.
4. **Zwei gleichzeitige Anrufe**: alles liegt in `ls._session_state[sid]`, kein Modul-Global.
   `tests/test_no_live_global_state.py` wuerde ein Global fangen; dieser Plan baut keines.

### Race-Condition-Audit — alle vier Fragen (Pflicht, keine "betrifft uns nicht")

1. **Gleichzeitiges Feuern:** Pro Deepgram-Verbindung liefert das SDK die Transcript-Callbacks
   **seriell in einem Thread**; zwei Ergebnisse derselben `sid` ueberlappen nicht. Verschiedene
   `sid` laufen in verschiedenen Threads, teilen aber nichts ausser `_session_state_lock`.
   **Benannte Rest-Kante:** das Lesen von `_dg_ms_offset` und das Hochziehen von
   `_dg_last_end_ms` sind zwei getrennte Lock-Nahmen. Bei einem hypothetischen parallelen
   Callback derselben `sid` koennte ein Segment einen um einen Schritt veralteten Versatz
   bekommen. Bewusst akzeptiert: der Versatz aendert sich heute nur beim Verbindungsaufbau, und
   ein einziger Lock ueber die Extraktion hinweg wuerde reine Rechenarbeit unter den Live-Riegel
   ziehen (Punkt 31/LOCK-Lehre: nichts unter den Riegel, was nicht dorthin muss).
2. **Verbindungsabbruch mitten in der Operation:** `_make_on_close`/`_make_on_error`
   (`:339-359`) machen ausschliesslich `print` + `sio.emit`. Es bleibt kein halbfertiger Zustand:
   das Eintrags-Dict wird **vollstaendig gebaut und dann in einem Zug** angehaengt. Bricht die
   Verbindung ab, fehlen schlicht die folgenden Abschnitte — die bereits geschriebenen bleiben
   gueltig.
3. **Reconnect mit altem Zustand:** siehe Task 2 — der einzige Pfad, der fuer eine bestehende
   `sid` erneut oeffnet, ruft vorher `pop_session_state` + `init_session_state`
   (`deepgram_service.py:764-766`) und loescht damit `conversation_log`, `_dg_last_end_ms` und
   `call_id`. Die Versatz-Regel ist dort **absichtlich** wirkungslos (siehe Begruendung in Task 2).
4. **Tab im Hintergrund:** Der Browser drosselt Timer, das Mikrofon laeuft weiter; die
   SDK-KeepAlives halten die Verbindung offen. Kommt in einem gedrosselten Tab **weniger oder
   kein** Audio an, steht die Deepgram-Uhr still, die Wall-Clock nicht — dieselbe Klasse wie
   eine Pause, aber **ohne** Marker, weil `handle_audio_chunk` in diesem Fall gar nicht feuert.
   **Das ist eine echte, benannte Restluecke** (siehe `RESTLUECKEN` in Task 2) und ausdruecklich
   NICHT Teil dieser Phase.

```python
def _extract_word_times(result, offset_ms=0):
    """Phase 08.23.2.ZEITSTEMPEL-1 (D-07/D-08) — Deepgram-Wortzeiten -> (start_ms, end_ms, word_count).

    word.start/word.end sind Float-SEKUNDEN ab Oeffnung der Deepgram-Verbindung
    (developers.deepgram.com/docs/diarization) — eine ANDERE Achse als ts_ms (Wall-Clock,
    Sekunden-Aufloesung). offset_ms ist der Versatz aus D-05 und wird auf BEIDE Zeiten addiert,
    nie auf die Wortanzahl.

    Die Wortanzahl kommt aus den ROHEN Wortobjekten, also VOR der Anonymisierung: der
    Platzhalter [PERSON_A] ersetzt zwei gesprochene Woerter durch eines und wuerde das
    Sprechtempo systematisch nach unten verzerren.

    Gibt (None, None, None) zurueck, wenn keine Wortobjekte vorliegen oder das Ergebnis
    unerwartet geformt ist. NIEMALS 0 als Ersatz — 0 hiesse 'hat nichts gesagt', None heisst
    'unbekannt' (D-04). Der Live-Loop-Thread darf hier nie sterben (Muster _get_speaker).
    """
    try:
        words = result.channel.alternatives[0].words
        if not words:
            return (None, None, None)
        start_ms = int(round(float(words[0].start) * 1000)) + offset_ms
        end_ms = int(round(float(words[-1].end) * 1000)) + offset_ms
        return (start_ms, end_ms, len(words))
    except Exception:
        return (None, None, None)
```
