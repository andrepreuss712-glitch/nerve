## Summary

Phase 08.23.2.B baut `services/anonymization.py` als DSGVO-Foundation-Modul von Grund auf (Greenfield). Das Modul exportiert drei Funktionen und eine Klasse: `AnrufAnonymisierer`, `anonymize()`, `anonymize_output()`, `register_briefing_pii()`. Es wird in vier aktive Schreib-Pfade verdrahtet: `deepgram_service.py` (STT-Transkript-Input), `claude_service.py` (Coaching/Painpoint-Output), `deepgram_service.py` (EWB-Antwort-Output), und die In-Memory-Lifecycle-Verwaltung in `live_session.py`.

Die kritische Architekturentscheidung ist die duale Pipeline: INPUT-Pfad tokenisiert rohe STT-Ausgabe per Regex + spaCy NER; OUTPUT-Pfad nutzt Cache-Reverse-Lookup (mapping-Keys durch Tokens ersetzen) fuer Claude-generierten Text, der bereits bekannte Namen echoen koennte. Der Token-Cache (`AnrufAnonymisierer`-Instanz) lebt ausschliesslich in RAM fuer genau einen Anruf — nie in DB, Redis oder Logs.

Es gibt einen Scope-Konflikt zwischen SPEC Req-4 (`anonymize()` gibt `None` zurueck bei Art-9-Treffer) und D-05 (`anonymize()` gibt stets `Tuple[str, str]` zurueck). Die SPEC ist juengeres Dokument und fachlich konsistenter (None signalisiert dem Caller "diesen Snippet nicht persistieren" klarer als `('[ART9_REDACTED]', 'C')`). Der Plan-Author soll diesen Konflikt vor Implementation klaeren.

**Primary recommendation:** `anonymize()` gibt `None` zurueck bei Art-9-Treffer (SPEC-konform), andernfalls `Tuple[str, str]`. Caller-Code prueft auf `None` und ueberspringt den Insert. `[ART9_REDACTED]`-String wird im quality_tier='C'-Fall bei Einzel-Pipeline-Exceptions verwendet.

### Pattern 1: spaCy Lazy-Load (Modul-Level, einmal pro Prozess)

```python
# Source: spaCy docs + Explosion.ai threading blog
import spacy
from functools import lru_cache

_nlp = None
_nlp_lock = threading.Lock()

def _get_nlp():
    """Thread-safe lazy load von de_core_news_lg. Einmal pro Prozess."""
    global _nlp
    if _nlp is None:
        with _nlp_lock:
            if _nlp is None:  # Double-checked locking
                try:
                    _nlp = spacy.load("de_core_news_lg")
                    print("[ANON] de_core_news_lg geladen")
                except Exception as e:
                    print(f"[ANON] KRITISCH: de_core_news_lg nicht ladbar: {e}")
                    # is_pipeline_healthy = False wird gesetzt (D-08 Kat. A)
    return _nlp
```

**Thread-Safety:** spaCy-Modell-Inference ist thread-safe fuer read-only-Verwendung. Das geladene `nlp`-Objekt kann aus mehreren Threads gleichzeitig fuer `nlp(text)` aufgerufen werden — kein Lock um `nlp()` herum noetig. [VERIFIED: explosion.ai/blog/multithreading-with-cython]

**Gunicorn:** Jeder Worker-Prozess laedt das Modell einmalig in seinen eigenen Memory-Space. Bei 2 Workers: ~1.4GB RAM gesamt. Akzeptabel auf Hetzner CX22 (4GB). [ASSUMED: kein Pre-Fork via `--preload` konfiguriert — muss im Deploy geprueft werden]

### Pattern 2: AnrufAnonymisierer-Klasse (aus CONTEXT.md D-03)

```python
import threading
from typing import Optional

class AnrufAnonymisierer:
    """Thread-safe Token-Cache fuer einen Anruf. Lifecycle: init_session_state -> pop_session_state."""

    def __init__(self):
        self._lock = threading.Lock()
        self.mapping: dict = {}          # 'Mueller' -> '[PERSON_A]'
        self.counters: dict = {'PERSON': 0, 'ORG': 0, 'LOC': 0}

    def get_or_assign_token(self, entity_text: str, entity_type: str) -> str:
        with self._lock:
            if entity_text in self.mapping:
                return self.mapping[entity_text]
            idx = self.counters[entity_type]
            # > 26 Treffer: [PERSON_AA], [PERSON_AB], ...
            if idx < 26:
                suffix = chr(ord('A') + idx)
            else:
                suffix = f'A{chr(ord("A") + (idx - 26))}'
            token = f'[{entity_type}_{suffix}]'
            self.mapping[entity_text] = token
            self.counters[entity_type] += 1
            return token
```

**CLAUDE.md-Konformitaet:** Key 'anonymisierer' im `_session_state[sid]`-Dict — ASCII (kein Umlaut). Klassen-Name 'AnrufAnonymisierer' — OK (User-facing Name, nicht DB-Spalte oder Dict-Key). Interne Attribute `mapping`, `counters` — ASCII. [VERIFIED: CLAUDE.md §ASCII-Pflicht fuer Code-Identifier]

### Pattern 3: Pipeline-Interface und Reihenfolge

Laut SPEC Req-4 laeuft Art-9-Filter VOR Regex und NER:

```python
def anonymize(text: str, cache: AnrufAnonymisierer) -> Optional[tuple]:
    """
    Gibt (anonymized_text, quality_tier) oder None (Art-9-Treffer) zurueck.
    quality_tier: 'A' = sauber, 'B' = unsichere NER-Treffer, 'C' = Pipeline-Exception
    """
    if not text or not text.strip():
        return ('', 'A')

    # Schritt 0: Art-9-Filter (ZUERST — 0% False-Negative Pflicht)
    if _check_art9(text):
        return None   # Caller ueberspringt Insert

    # Schritt 1: Regex-Vorfilter
    text, tier = _apply_regex_filter(text, cache)

    # Schritt 2: spaCy NER
    try:
        nlp = _get_nlp()
        if nlp and is_pipeline_healthy:
            text, ner_tier = _apply_ner(text, cache, nlp)
            if ner_tier == 'B':
                tier = 'B'
    except Exception as e:
        # Kat. B: Einzel-Exception
        print(f"[ANON] Snippet-Exception (len={len(text)}): {type(e).__name__}")
        return ('[ANON_FEHLER]', 'C')

    return (text, tier)
```

**WICHTIG — KONFLIKT CONTEXT.md D-05 vs. SPEC Req-4:**
- D-05 sagt: `anonymize()` returns `Tuple[str, str]` immer
- Req-4 sagt: bei Art-9-Treffer return `None`
- Empfehlung: SPEC Req-4 folgen (`None` bei Art-9). `None`-Return ist fachlich klarer als `('[ART9_REDACTED]', 'C')` weil Caller-Code `if result is None: skip_insert()` deutlicher ist als `if text == '[ART9_REDACTED]': skip_insert()`. `[ART9_REDACTED]` verbleibt im Modul als Sentinel fuer potenzielle spaetere Verwendung.

### Pattern 4: anonymize_output() — Cache-Reverse-Lookup

```python
def anonymize_output(text: str, cache: AnrufAnonymisierer) -> str:
    """
    Ersetzt alle bekannten Klartext-Entitaeten aus cache.mapping durch ihre Tokens.
    Verwendet fuer Claude-generierte Texte, die Briefing-Namen echoen koennen.
    """
    if not text or not cache:
        return text
    # Laengere Keys zuerst (verhindert Partial-Matches: 'Dr. Mueller' vor 'Mueller')
    with cache._lock:
        items = sorted(cache.mapping.items(), key=lambda x: len(x[0]), reverse=True)
    for original, token in items:
        if original in text:
            text = text.replace(original, token)
    return text
```

**Warum kein NER fuer Output-Pfad:** Claude-generierter Text koennte neue Personen erwaehnen die nicht im Cache sind. Output-Pfad ist bewusst auf Cache-Reverse-Lookup beschraenkt — Claude-"Halluzinationen" neuer Namen landen als Klartext (akzeptables Risiko fuer EA-Launch). [ASSUMED]

### Pattern 6: Regex-PII-Patterns (Schritt 1)

```python
_RE_STEUERNR = re.compile(r'\b\d{2,3}[\s/]\d{3}[\s/]\d{4,5}\b')

)

# Kreditkarte: 13-19 Ziffern in Luhn-Gruppen (Luhn-Check vor Tokenisierung!)
_RE_KREDITKARTE = re.compile(r'\b(?:\d[\s-]?){13,19}\b')

def _luhn_check(number_str: str) -> bool:
    digits = [int(d) for d in number_str if d.isdigit()]
    odd_digits = digits[-1::-2]
    even_digits = digits[-2::-2]
    total = sum(odd_digits)
    for d in even_digits:
        total += sum(divmod(d * 2, 10))
    return total % 10 == 0

def _parse_phone_de(text: str) -> list:
    """Extrahiert DE-Telefonnummern via phonenumbers (graceful fallback auf Regex)."""
    found = []
    try:
        for match in phonenumbers.PhoneNumberMatcher(text, 'DE'):
            found.append(text[match.start:match.end])
    except Exception:
        # Fallback: einfaches Regex fuer DE-Nummern
        for m in re.finditer(r'(?:\+49|0049|0)\s*\d{2,5}[\s/\-]?\d{3,}[\s\d]{0,10}', text):
            found.append(m.group())
    return found
```

### Pattern 7: Fallback-Architektur (D-08)

```python
# Modul-Level-Flag in services/anonymization.py
is_pipeline_healthy: bool = True
_error_timestamps: list = []    # monotonic-Timestamps der letzten Exceptions
_error_lock = threading.Lock()

ROLLING_ERROR_THRESHOLD = int(os.environ.get('ANON_ERROR_THRESHOLD', '5'))
ROLLING_ERROR_WINDOW_S = int(os.environ.get('ANON_ERROR_WINDOW_S', '600'))  # 10 min

class AnonymizationPipelineUnavailable(Exception):
    """Raised wenn is_pipeline_healthy=False (spaCy-Lade-Fehler, Kat. A)."""
    pass

def _register_error() -> None:
    """Prueft Rolling-Error-Rate und setzt is_pipeline_healthy bei Schwellenwert."""
    global is_pipeline_healthy
    now = time.monotonic()
    with _error_lock:
        _error_timestamps.append(now)
        cutoff = now - ROLLING_ERROR_WINDOW_S
        while _error_timestamps and _error_timestamps[0] < cutoff:
            _error_timestamps.pop(0)
        if len(_error_timestamps) > ROLLING_ERROR_THRESHOLD:
            is_pipeline_healthy = False   # Kat. C: degraded
```

### Anti-Patterns to Avoid

- **Cache in DB schreiben:** `AnrufAnonymisierer.mapping` darf NIEMALS in DB landen — persistiertes Mapping = Pseudonymisierung (nicht Anonymisierung), BfDI-Verletzung.
- **Re-Load pro Aufruf:** `spacy.load()` pro `anonymize()`-Aufruf — ~1-2 Sek. Latenz macht Echtzeit-Betrieb unmoeglich.
- **spaCy-Confidence-Score fuer quality_tier='B':** spaCy NER (`de_core_news_lg`) exponiert **keine Confidence-Scores** fuer NER-Entities. Das ist eine bekannte Limitation des greedy transition-based NER. [VERIFIED: github.com/explosion/spaCy/issues/5917] — `quality_tier='B'` muss ueber andere Heuristiken bestimmt werden (z.B. Token-Laenge < 3 Zeichen, alle-Grossbuchstaben, Sonderzeichen in Entity-Text).
- **Umlaute in Code-Identifiern:** Dict-Key `'anonymisierer'` ist korrekt (ASCII). Klassen-Attribute `mapping`, `counters` korrekt (ASCII). Vorsicht: kein `'anonymisierer'` -> `'anonymisierer'` vs `'anonymisierer'`. [VERIFIED: CLAUDE.md]
- **json_extract() in integration_engine.py:** Das bestehende Raw-SQL in `run_postcall_engine()` nutzt SQLite-spezifisches `json_extract()`. Nicht anfassen in dieser Phase (Scope). [VERIFIED: integration_engine.py Z.162]

## Common Pitfalls

### Pitfall 1: spaCy NER liefert keine Confidence-Scores

**What goes wrong:** Plan nimmt an, entity.confidence oder entity.score gibt Sicherheitswert zurueck → `AttributeError` oder stets 0.0.

**Why it happens:** spaCy's greedy transition-based NER berechnet keine Marginalprobabilitaeten fuer einzelne Entities. [VERIFIED: github.com/explosion/spaCy/issues/5917]

**How to avoid:** quality_tier='B' ueber strukturelle Heuristiken bestimmen: Entity-Text enthaelt Sonderzeichen, Token-Laenge < 3, keine Grossschreibung, ungewoehnliche Zeichen.

**Warning signs:** Code der `ent.kb_id_` oder `ent.sent.ents` fuer Confidence nutzt.

### Pitfall 2: Art-9-Filter return-Wert vs. D-05 Tuple-Kontrakt

**What goes wrong:** anonymize() gibt `None` bei Art-9, aber Caller erwartet Tuple → `TypeError: cannot unpack non-iterable NoneType`.

**Why it happens:** Konflikt zwischen CONTEXT.md D-05 (immer Tuple) und SPEC Req-4 (None bei Art-9).

**How to avoid:** Alle Caller-Stellen explizit mit `result = anonymize(...)` + `if result is None: continue/skip` schreiben, NICHT `text, tier = anonymize(...)` direkt.

### Pitfall 3: Ghost-SID beim anonymize() Aufruf

**What goes wrong:** `get_anonymisierer(sid)` gibt `None` zurueck wenn SID bereits disconnected ist, anonymize() wird mit `cache=None` aufgerufen.

**Why it happens:** Race-Condition zwischen Deepgram-Callback (async) und `pop_session_state()` (disconnect).

**How to avoid:** `anonymize()` muss `cache=None` defensiv behandeln — wenn kein Cache vorhanden, Regex-Only-Modus (kein Token-Cache, kein NER-Entitystorage). NER-Entities in diesem Fallback-Fall als anonymer Token ohne Mapping-Persistenz ([PERSON_X] statt [PERSON_A]).

### Pitfall 4: /api/session-rating kein SID-Kontext

**What goes wrong:** `ConversationLog.kommentar` (User-Freitext-Kommentar nach Call) soll durch `anonymize()` — aber `/api/session-rating` ist ein HTTP-Request NACH dem Call, der Token-Cache ist bereits geloescht (`pop_session_state()` durch disconnect/stop_live_session).

**Why it happens:** HTTP POST /api/session-rating kommt zeitlich nach Session-Ende, `AnrufAnonymisierer` fuer SID existiert nicht mehr.

**How to avoid:** Zwei Optionen: (a) Kommentar ohne Token-Cache anonymisieren (nur Regex + NER ohne Mapping-Persistenz — neue Entities bekommen temporaere Tokens), (b) `quality_tier='B'` setzen wenn kein Cache verfuegbar. Plan-Author entscheidet.

### Pitfall 5: Gunicorn Preload und Modell-Sharing

**What goes wrong:** Wenn gunicorn mit `--preload` gestartet wird, wird das spaCy-Modell VOR dem Fork geladen und alle Worker teilen denselben Memory-Space fuer das Modell-Objekt. Concurrent Calls koennen zu Problemen fuehren.

**Why it happens:** `--preload` laedt App im Master-Prozess vor Fork. spaCy-Modell ist danach shared memory.

**How to avoid:** Lazy-Load NACH dem Fork (aktuelles Pattern — Modul-Level `_nlp = None`, erst beim ersten `anonymize()`-Aufruf geladen). Explizit kein `--preload` in nerve-Service-Config. [ASSUMED: gunicorn config muss geprueft werden]

```python
# Source: D-05 CONTEXT.md + SPEC Req-2/3/4 + Pitfall-Analyse
import threading
import time
import os
import re
from typing import Optional, Tuple
import phonenumbers

is_pipeline_healthy: bool = True
_error_timestamps: list = []
_error_lock = threading.Lock()

ROLLING_ERROR_THRESHOLD = int(os.environ.get('ANON_ERROR_THRESHOLD', '5'))
ROLLING_ERROR_WINDOW_S  = int(os.environ.get('ANON_ERROR_WINDOW_S', '600'))


class AnonymizationPipelineUnavailable(Exception):
    pass


class AnrufAnonymisierer:
    def __init__(self):
        self._lock = threading.Lock()
        self.mapping: dict = {}
        self.counters: dict = {'PERSON': 0, 'ORG': 0, 'LOC': 0}

    def get_or_assign_token(self, entity_text: str, entity_type: str) -> str:
        with self._lock:
            if entity_text in self.mapping:
                return self.mapping[entity_text]
            idx = self.counters[entity_type]
            suffix = chr(ord('A') + idx) if idx < 26 else f'A{chr(ord("A") + idx - 26)}'
            token = f'[{entity_type}_{suffix}]'
            self.mapping[entity_text] = token
            self.counters[entity_type] += 1
            return token


def anonymize(text: str, cache: Optional[AnrufAnonymisierer]) -> Optional[Tuple[str, str]]:
    global is_pipeline_healthy
    if not is_pipeline_healthy:
        raise AnonymizationPipelineUnavailable("Pipeline nicht verfuegbar")

    if not text or not text.strip():
        return ('', 'A')

    # Schritt 0: Art-9-Filter (0% False-Negative Pflicht)
    from services.art9_keywords import ART9_KEYWORDS
    text_lower = text.lower()
    for keywords in ART9_KEYWORDS.values():
        if any(kw in text_lower for kw in keywords):
            return None   # Caller ueberspringt Insert, setzt quality_tier='C'

    # Schritt 1: Regex-Vorfilter
    try:
        text, tier = _apply_regex_filter(text, cache)
    except Exception as e:
        _register_error()
        print(f"[ANON] Regex-Fehler (len={len(text)}): {type(e).__name__}")
        return ('[ANON_FEHLER]', 'C')

    # Schritt 2: spaCy NER
    try:
        nlp = _get_nlp()
        if nlp:
            text, ner_tier = _apply_ner(text, cache, nlp)
            if ner_tier == 'B':
                tier = 'B'
    except Exception as e:
        _register_error()
        print(f"[ANON] NER-Fehler (len={len(text)}): {type(e).__name__}")
        return ('[ANON_FEHLER]', 'C')

    return (text, tier)
```
