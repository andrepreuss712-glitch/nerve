## Summary

This phase maps the existing `neue_stimmung` score (-5 to +5) to ElevenLabs `voice_settings` parameters (`stability`, `style`) using a 4-zone step model. The secretary types (SEKRETAERIN_TYPES) get fixed voice presets instead of dynamic mood tracking. The implementation is surgical: extend `text_to_speech()` with an optional `voice_settings` parameter, create a mapping function for mood-to-settings, add presets to the secretary dict, and wire everything up in 3 TTS call sites in `routes/training.py`.

**Primary recommendation:** Create a `mood_to_voice_settings(stimmung: int) -> dict` mapping function in `training_service.py`, extend `text_to_speech()` to accept optional `voice_settings`, and pass computed settings at each TTS call site.

## ElevenLabs voice_settings API Parameters

### Parameter Reference

| Parameter | Type | Range | Default | Description |
|-----------|------|-------|---------|-------------|
| `stability` | float | 0.0 - 1.0 | 0.5 | Lower = more emotional variation, broader range. Higher = monotone, consistent. [CITED: elevenlabs.io/docs/api-reference/voices/settings/get-default] |
| `similarity_boost` | float | 0.0 - 1.0 | 0.75 | How closely AI adheres to original voice. **Fixed at 0.75 per D-05.** [CITED: elevenlabs.io/docs/api-reference/voices/settings/get-default] |
| `style` | float | 0.0 - 1.0 | 0.0 | Style exaggeration. Higher = more expressive/dramatic. Non-zero increases latency. [CITED: elevenlabs.io/docs/api-reference/voices/settings/get-default] |
| `use_speaker_boost` | boolean | true/false | true | Boosts similarity to original speaker. **Unchanged per D-06.** [CITED: elevenlabs.io/docs/api-reference/voices/settings/get-default] |
| `speed` | float | 0.5 - 2.0 | 1.0 | Speech speed. Not used in this phase. [CITED: elevenlabs.io/docs/api-reference/voices/settings/get-default] |

### Key Insight for Mood Mapping

- **stability LOW + style HIGH** = emotional, dramatic, unpredictable voice (angry customer)
- **stability HIGH + style LOW** = calm, steady, controlled voice (positive/warm customer)
- **stability MID + style 0** = neutral baseline (current default)

This maps perfectly to D-01's zone definitions. [VERIFIED: ElevenLabs docs + current codebase defaults]

## Architecture Patterns

### Recommended Implementation Pattern

```python
# In training_service.py — new function

MOOD_VOICE_ZONES = {
    'positiv':  {'stability': 0.65, 'similarity_boost': 0.75, 'style': 0.15},
    'neutral':  {'stability': 0.50, 'similarity_boost': 0.75, 'style': 0.00},
    'gereizt':  {'stability': 0.35, 'similarity_boost': 0.75, 'style': 0.45},
    'wuetend':  {'stability': 0.20, 'similarity_boost': 0.75, 'style': 0.70},
}

def mood_to_voice_settings(stimmung: int) -> dict:
    """Map mood score (-5 to +5) to ElevenLabs voice_settings. 4-zone step model (D-01)."""
    if stimmung >= 2:
        return MOOD_VOICE_ZONES['positiv'].copy()
    elif stimmung >= -1:
        return MOOD_VOICE_ZONES['neutral'].copy()
    elif stimmung >= -3:
        return MOOD_VOICE_ZONES['gereizt'].copy()
    else:
        return MOOD_VOICE_ZONES['wuetend'].copy()
```

**Value reasoning (Claude's Discretion area):**

| Zone | stability | style | Rationale |
|------|-----------|-------|-----------|
| Positiv (+2 to +5) | 0.65 | 0.15 | Warm, steady but not robotic. Slight style for friendliness. |
| Neutral (-1 to +1) | 0.50 | 0.00 | Current baseline, proven working. |
| Gereizt (-2 to -3) | 0.35 | 0.45 | Noticeable tension. stability drop creates variation, style adds edge. |
| Wuetend (-4 to -5) | 0.20 | 0.70 | Dramatic difference. Very unstable + high style = clearly agitated. |

These are starting values. The context says "Feintuning nach Testergebnis" -- these should be easy to adjust as they are in a constant dict. [ASSUMED: exact values will need testing]

## Don't Hand-Roll

| Problem | Don't Build | Use Instead | Why |
|---------|-------------|-------------|-----|
| Mood-to-settings mapping | Complex interpolation/curve | Simple zone dict lookup | D-02 mandates fixed zones, no interpolation. Dict lookup is explicit and tunable. |
| Voice parameter validation | Range checking logic | Trust ElevenLabs API defaults | API clamps out-of-range values. Keep it simple. |

## Common Pitfalls

### Pitfall 1: similarity_boost Drift
**What goes wrong:** When building voice_settings dicts, forgetting to include `similarity_boost: 0.75` causes the API to use its default or a different value, making the voice sound like a different person.
**How to avoid:** Every voice_settings dict (zones AND secretary presets) must include `similarity_boost: 0.75`. The mapping function and presets bake it in.

### Pitfall 2: Secretary Getting Dynamic Mood Settings
**What goes wrong:** The `is_sek` check at line 509 determines if the current speaker is secretary. If this flag is not checked before applying mood_to_voice_settings, the secretary could get mood-based voice changes despite D-08 saying fixed presets.
**How to avoid:** Always check `is_sek` (or `hat_sekretaerin` for first message) before deciding which voice_settings to use.

### Pitfall 3: Missing voice_settings Import in Routes
**What goes wrong:** `mood_to_voice_settings` is defined in `training_service.py` but called in `routes/training.py`. Forgetting the import causes runtime NameError.
**How to avoid:** Add to the existing import line 15: `from services.training_service import ..., mood_to_voice_settings`

### Pitfall 4: Chef Durchstellung Getting Wrong Settings
**What goes wrong:** After Durchstellung (line 548-555), the chef responds for the first time. Applying the secretary's mood or the current stimmung would be wrong -- the chef is a new speaker with neutral mood.
**How to avoid:** Leave chef first-message TTS call without voice_settings (uses default neutral). Subsequent chef turns will go through the normal mood path.
