## Stimmungs-Mapping

| Option | Description | Selected |
|--------|-------------|----------|
| Stufenmodell (3 Zonen) | Positiv / Neutral / Negativ — einfach, klare Unterschiede | |
| Lineares Mapping | Jeder Stimmungspunkt verschiebt Parameter graduell — fein aber kaum hörbar | |
| Exponentielles Mapping | Neutrale Zone breit, Extreme stark — natürlicher aber in Praxis wie Stufen | |
| **Stufenmodell (4 Zonen)** | Positiv / Neutral / Gereizt / Wütend — empfohlen von Claude | ✓ |

**User's choice:** 4-Zonen-Stufenmodell (Option A erweitert)
**Notes:** Claude empfahl 4 statt 3 Zonen weil der Unterschied zwischen "leicht genervt" (-2/-3) und "kurz vor Auflegen" (-4/-5) hörbar sein muss. User stimmte zu. ElevenLabs bietet nicht genug Granularität für lineares Mapping.
