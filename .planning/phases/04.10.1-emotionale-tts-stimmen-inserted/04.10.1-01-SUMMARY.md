# Phase 04.10.1 Plan 01: Emotional TTS Voice Settings Summary

4-zone mood-to-voice mapping (stability + style) with fixed secretary presets, wired at all 3 TTS call sites for audible customer mood shifts during training

## What Was Built

### MOOD_VOICE_ZONES and mood_to_voice_settings()
- 4-zone constant dict mapping zone names to ElevenLabs voice_settings (stability, similarity_boost, style)
- Zones: positiv (warm/steady), neutral (baseline), gereizt (tense), wuetend (agitated)
- mood_to_voice_settings(stimmung: int) maps -5 to +5 score to correct zone with fixed boundaries per D-02
- Returns .copy() to prevent mutation of shared dict

### Secretary Voice Presets
- Each of the 3 SEKRETAERIN_TYPES entries now has a voice_settings key:
  - blockerin: stability 0.60, style 0.10 (cool, even)
  - helferin: stability 0.45, style 0.25 (friendly, open)
  - abwimmlerin: stability 0.35, style 0.50 (hectic, annoyed)
- All presets include similarity_boost 0.75 per D-05

### Extended text_to_speech()
- New optional parameter: voice_settings: dict = None
- When provided, used as-is in API payload
- When None, falls back to existing default {"stability": 0.5, "similarity_boost": 0.75}
- Fully backward compatible

### Call Site Wiring (routes/training.py)
- Line 309 (first message): secretary -> fixed preset, customer with personality -> mood zone, else -> None
- Line 529 (main response): is_sek -> fixed preset, personality_data -> neue_stimmung zone, else -> None
- Line 560 (chef after Durchstellung): unchanged, uses neutral default
