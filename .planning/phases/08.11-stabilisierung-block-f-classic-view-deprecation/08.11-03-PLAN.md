**Schritt 1 — Alle Vorkommen von `legacyOpener` und `profileDaten.opener` finden:**

**Schritt 2 — Fuer jede gefundene Stelle:**

a) `var legacyOpener = ...` Zeile: komplett loeschen.

b) Stellen wo `legacyOpener` als Fallback benutzt wird, z.B.:
```javascript
var displayOpener = (state.openerItems && state.openerItems.length > 0) 
  ? state.openerItems[0].text 
  : legacyOpener;
```
→ Vereinfachen zu:
```javascript
var displayOpener = (state.openerItems && state.openerItems.length > 0) 
  ? state.openerItems[0].text 
  : '';
```

(Leerer String als Fallback — openerItems ist die einzige Quelle)

c) Falls `legacyOpener` in einem Ternary als dritten Wert benutzt wird, durch `''` ersetzen.

d) Falls `legacyOpener` direkt als Wert zugewiesen wird (ohne openerItems-Conditional), die gesamte Zeile loeschen oder durch `''` ersetzen.

**Wichtig:** Nur die legacyOpener/profileDaten.opener Stellen aendern. Keine anderen pip-launcher.js Stellen anfassen. Die openerItems-Logik selbst bleibt vollstaendig erhalten.

**Nach den Aenderungen:** Sicherstellen dass keine `undefined`-Fehler durch fehlende Variable entstehen koennten — alle Stellen wo legacyOpener referenziert wurde muessen sauber gehandelt sein.
