<decisions>
## Implementation Decisions (LOCKED — André 2026-07-08)

### D-01 — Absolute Firmen-Grenze im normalen UI, KEINE Superadmin-Ausnahme
Owner/Admin sehen auf der normalen Logs-Seite + im Dashboard-Widget nur Logs der EIGENEN Firma. **Eine Regel
für alle** — auch ein `is_superadmin`-Konto sieht auf dem NORMALEN Pfad nur die eigene Firma (kein `is_superadmin`-Bypass
im Filter). DSGVO/Least-Privilege.

### D-02 — Filter-Mechanik: org→User-IDs DB-Lookup + UID-Extraktion aus Dateiname
- Org-User-IDs: `db.query(User).filter_by(org_id=g.org.id)` (Muster `organisations.py:28`; `User.org_id` FK NOT NULL `models.py:69`). Inklusive inaktiver (aktiv=False behalten org_id).
- Dateiname → UID via Regex `_U(\d+)_` extrahieren, Mitgliedschaft im org-User-ID-Set prüfen (robust; kein Substring-Fehlmatch).
- non-admins: weiterhin nur eigene UID (bestehendes Verhalten bleibt).
- **Fail-closed:** kann die Org-User-Liste nicht ermittelt werden (DB-Fehler) → LEERE Liste / 403, NIE „alle zeigen".

### D-03 — Getrennter Founder-Log-Pfad (superadmin-only, KEIN Filter-Loch)
Neue **superadmin-only** Route(n) im Admin-Bereich: Liste ALLER Call-Log-Dateien (alle Firmen) + Download.
Sicherheits-Muster kopiert von `register_admin_screenshot_route` (`admin_views.py:224-235`): `@superadmin_required`
(`services/auth_decorators.py:5`) + Path-Traversal-Guard (`..`, führendes `/`) + `send_from_directory`/`send_file`
mit `LOG_DIR` statt UPLOAD_DIR. **NICHT** die Transkript-Route `learning.py:608` (`api_transcript`) mitbenutzen —
die filtert hart auf eigene Calls (`user_id==g.user.id` → 404 bei fremd).

### D-04 — Founder-Zugriff: Grund-Pflicht + FAIL-CLOSED Audit-vor-Download
- Jeder Founder-Abruf (Liste? mind. Download) verlangt ein **Grund**-Feld und schreibt VORHER einen `audit_log`-Eintrag
  via `services/audit.py:log_action` (`action='founder_log_access'`, `details`-JSON mit Datei + Grund).
- **FAIL-CLOSED:** schlägt der Audit-Write fehl → **kein Download** (abort). `audit.py:log_action` schluckt Fehler
  heute leise (`:24-26` `except: print`) — für DIESEN Pfad umkehren (strict-Variante, die re-raist; Route bricht ab).
- Reihenfolge: Audit committen → erst dann `send_file`.

### D-05 — Audit-Inhalt: NUR Metadaten
Der Audit-Eintrag enthält NUR wer/wann/welche Datei/warum — **NIEMALS Transkript-Inhalt** (DSGVO; audit.py-Docstring
sagt das bereits).

### D-06 — Zwei Wächter (Test-Netz-Ratsche, erst-rot)
- **`test_logs_org_boundary`:** owner/admin sehen auf der normalen Logs-Seite/im Widget nur die eigene Firma;
  Cross-Org-Datei-Download → 403. Auch ein `is_superadmin`-Konto → nur eigene Firma auf dem NORMALEN Pfad.
- **`test_logs_founder_access`:** (a) owner/admin (nicht-superadmin) → **403** auf dem Admin-Founder-Pfad;
  (b) jeder erfolgreiche Founder-Download erzeugt **genau einen** `audit_log`-Eintrag; (c) Audit-Fehler → kein Download.
