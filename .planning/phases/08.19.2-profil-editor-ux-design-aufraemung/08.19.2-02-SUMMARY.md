**Task 4 — Backend:**
- `ProfileOpener.type = Column(String(20), nullable=False, server_default='opener')` hinzugefuegt
- Migration Step A: `ALTER TABLE profile_opener ADD COLUMN type` (idempotent per try/except)
- Migration Step B: Backfill `name='Pitch' AND type='opener'` → `type='pitch'`
- Migration Step C: `erlaubnis`-Feld aus daten JSON → `ProfileOpener type='erlaubnis'` pro Profil
- Bestehende opener/pitch INSERTs in Migration auf type-Spalte aktualisiert
- `opener_liste` filtert jetzt `type='opener'` (kein pitch/erlaubnis Mix)
- `opener_erstellen` setzt `type='opener'` explizit
- Pitch CRUD: `/<pid>/pitches` GET/POST/PUT/DELETE mit `_pitch_dual_write()`
- Erlaubnis CRUD: `/<pid>/erlaubnis` GET/POST/PUT/DELETE mit `_erlaubnis_dual_write()`
- Dual-write: nach jedem Commit alle items concatenieren → `Profile.daten['pitch'/'erlaubnis']` updaten
- `daten.pop('erlaubnis', None)` aus profile_schema.py entfernt
- `daten.pop('pitch', None)` aus profile_schema.py entfernt
- `daten.pop('opener', None)` bleibt (kein dual-write fuer opener)
