## Decisions Made

- **ALTER ersatzlos statt IF NOT EXISTS** — nerve_app hat auf Prod keine ALTER-Rechte (app.py:136); IF-NOT-EXISTS wuerde an Permissions scheitern = leisere, aber weiterhin vorhandene Mine. Die Spalte existiert in jeder create_all-/Prod-DB (models.py server_default), also ist Loeschen sicher (Fable P5a; Pre-Execute-Audit: Step-B-Waisen=0).
- **Guard (a) JSON-basiert** — `profiles` hat keine `schema_version`-Spalte; die Version lebt im `daten`-JSON (Cross-Layer Punkt 21/22).
- **v4-Batch unangetastet** — er liegt in `_migrate()` mit PG-early-return (:140) und ist auf Prod tot; nur 1-Zeilen-Marker. v2/v3->v4-Heben ist DEFERRED (Backlog PROFILE-MIGRATE-CONSOLIDATE).
