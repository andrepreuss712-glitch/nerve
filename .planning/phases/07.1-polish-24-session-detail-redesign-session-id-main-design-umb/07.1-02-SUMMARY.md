## Key Technical Decisions

### B-01 — Hidden Minibars statt `style="--w: 0%"`

Erste Template-Version hatte `<span style="--w: 0%">` auf den zwei hidden
Minibars (Training Stimmung-Ende + Skript-Abdeckung). Obwohl diese inline-Styles
die Form `style="--w: ..."` hatten, enthielten sie keine Template-Expression
und galten damit als statisch. Der automatisierte B-01-Check scheiterte
genau deswegen.

**Rule-1-Fix:** Span ohne `style`-Attribut rendern, CSS-Fallback `var(--w, 0%)`
greift. Visibility:hidden via Klasse bewirkt dass Wert sowieso nicht sichtbar
ist. Ergebnis: 0 statische Inline-Styles, alle dynamischen Inline-Styles
enthalten `{{ ... }}`.

### W-06 Score-Hero konsumiert `score_total`

Das Template setzt `{% set score = score_total %}` einmal oben in Section 2
und nutzt die lokale Variable durchgaengig. Trend-Delta `{% set delta = score -
trend_avg %}` ist damit semantisch konsistent: fuer Live beide Seiten via
`_calc_call_score`-Formel, fuer Training wird Trend-Badge ohnehin nicht
gerendert (double-gate `trend_avg is not none AND conv.typ != 'training'`).

### W-05 Minibar-Hidden Strategie

Alternative waere gewesen, die zwei em-dash-Breakdown-Rows komplett per Jinja-
Conditional zu verstecken. Entscheidung: Layout-Konsistenz (4 Rows fuer
Training wie Live) wichtiger als ein leerer Slot — Minibar bleibt im DOM,
aber unsichtbar. `.n-session-detail-minibar--hidden { visibility: hidden; }`.

### Chart.js Light-Mode-Transform

Kopiert aus `dashboard.html:880-923` (Dark-Mode-Template), aber Farben
getauscht:
- Ticks: `#8B949E` (Dark-Text) -> `#6B7280` (MAIN-DESIGN Text-Secondary)
- Grid: `rgba(255,255,255,0.05)` (Licht auf dunkel) -> `rgba(0,0,0,0.06)`
  (Schatten auf weiss)
- Fill: `rgba(0,212,170,0.1)` -> `rgba(0,212,170,0.08)` (UI-SPEC Rev 4)

### Auto-fixed Issues

**1. [Rule 1 - Bug] Statische Inline-Styles auf hidden Minibars entfernt (B-01)**

- **Found during:** Task 2 Verify-Lauf
- **Issue:** Plan-Template hatte `<span style="--w: 0%">` auf zwei hidden
  Minibars. B-01-Regex `[s for s in re.findall(r'style="[^"]*"', html) if
  '{{' not in s and '{%' not in s]` flaggte diese als statisch — exakter
  Verstoss gegen B-01-Regel "nur dynamische Template-Expressions erlaubt".
  Wortgetreue Ausfuehrung haette zu Verifier-Fehlschlag `AssertionError:
  Static inline styles found (B-01): ['style="--w: 0%"', 'style="--w: 0%"']`
  gefuehrt.
- **Fix:** `style`-Attribut von beiden span-Elementen entfernt. CSS-Fallback
  `width: var(--w, 0%)` greift. Sichtbares Ergebnis identisch (Minibar
  visibility:hidden durch `.n-session-detail-minibar--hidden`).
- **Files modified:** templates/session_detail.html
