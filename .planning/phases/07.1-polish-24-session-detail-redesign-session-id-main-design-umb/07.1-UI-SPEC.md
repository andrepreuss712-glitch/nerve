## Spacing Scale

Declared values (alle Vielfache von 4, orientiert am 8-Punkt-Raster):

| Token | Value | Usage in diesem Phase |
|-------|-------|-----------------------|
| xs | 4px | Icon-Gaps in Badges, Badge-Inner-Gap |
| sm | 8px | Zwischen Label und Value in KPI-Cards, Chart-Legend-Gap |
| md | 16px | Default Card-Padding vertikal (Section-Header zu Content), Grid-Gap zwischen Kacheln |
| lg | 24px | Card-Padding Innen (`.n-session-detail-card`), vertikal zwischen Sektionen (1-8) |
| xl | 32px | Top-Padding der Seite unter dem Header, Abstand Score-Hero zu Chart-Sektion |
| 2xl | 48px | Abstand Header-Block zu erster Inhaltssektion (Score-Hero), Bottom-Padding vor Footer |
| 3xl | 64px | Nicht verwendet (Page ist content-dense, kein Hero-Breathing-Space noetig) |

**Exceptions:**
- Chart-Canvas-Hoehe: 280px (fixer Pixel-Wert, keine Spacing-Token — Chart.js rendert auf Canvas-Pixelmass, responsive via Chart.js-Option `maintainAspectRatio:false`)
- Phasen-Strip-Hoehe: 32px (horizontaler Balken, feste Hoehe damit Phasen-Segmente lesbar bleiben)
- Progress-Bar-Hoehe: 8px (Skript-Abdeckung, abgeleitet aus `--metric-track-height` in nerve.css skaliert um 2.7x fuer groessere Prominenz)
- Badge-Padding (Modus-Badge): nutzt bestehendes `--badge-padding: 3px 10px` aus nerve.css — nicht neu definieren
- Mobile-Breakpoint `<768px`: Grid kollabiert auf `1fr`, Card-Padding reduziert auf `md` (16px)

## Typography

Exakt 4 Groessen, 2 Gewichte (400 regular + 600 semibold). Body-Line-Height 1.5, Heading-Line-Height 1.2. Alles abgeleitet aus bestehenden Tokens in nerve.css.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Display (Score-Hero-Zahl) | 64px | 600 | 1.0 | JetBrains Mono | Die grosse Score-Zahl im Score-Hero (Section 2), linksbuendig |
| Heading (Section-Headline `.n-h2`) | 20px | 600 | 1.2 | Inter | Section-Ueberschriften ("Kaufbereitschafts-Verlauf", "Einwand-Timeline", etc.) |
| Body (Default, Timeline-Eintraege, Chart-Labels) | 14px | 400 | 1.5 | Inter | Alle Fliesstexte, Zeitstempel in Timeline, Phasen-Beschriftungen |
| Label (Meta-Info, Kacheln-Label, Score-Komponenten-Labels) | 12px | 600 | 1.3 | Inter, uppercase, letter-spacing 0.5px | Label-Zeilen ("Modus", "Dauer", "Skript-Abdeckung", "kb_end 40%"), alle `.n-label` |

Page-Title (Section 1 Header "Session #123"): 28px / 600 / 1.2 — nutzt die bestehende `.n-h1` Klasse aus nerve.css (nicht neu definieren). Diese liegt ausserhalb der 4 deklarierten Rollen, da sie One-Off im Page-Header ist.

**Keine weiteren Groessen.** Keine Italics, keine extra-bold (>600). Keine Serif-Font.

2. Trend-Badge "+X vs Schnitt letzte 5" (wenn positiv) — `.n-badge-primary` (teal bg tint)

5. Progress-Bar-Fill in Skript-Abdeckung — Linear-Gradient `--metric-fill-primary-from` → `--metric-fill-primary-to` (teal)
6. Zurueck-Link Hover-State — teal text
7. Phasen-Strip: aktive/dominante Phase bekommt Teal-Fill, inaktive Phasen Neutral-Grau (`#E2E8F0`). - Gelb/Gold (`#E8B040`, `#b8872e`) — Phase 7 RULE, kein Re-Introduction
- `data-theme` Attribut — Phase 7 hat Dead-Code entfernt, nicht wieder einfuehren

## Chart.js Spezifikation (Section 3 — Kaufbereitschafts-Verlauf)

Chart.js ist bereits in base.html via `static/vendor/chart.umd.min.js` geladen. Diese Phase fuegt einen einzigen Chart hinzu. Konfiguration:

| Property | Value |
|----------|-------|
| Chart-Typ | `line` |
| Canvas-ID | `sd-kb-verlauf` (ASCII) |
| Container-Klasse | `.n-session-detail-chart-wrap` |
| Canvas-Hoehe | 280px (fix, responsive Breite via Chart.js) |
| `maintainAspectRatio` | `false` |
| Line-Color (dataset.borderColor) | `#00D4AA` |
| Fill-Color (dataset.backgroundColor) | `rgba(0,212,170,0.08)` |
| `fill` | `true` (Flaeche unter Linie) |
| `tension` | `0.3` (smoothe Kurve, kein Spline-Overshoot) |
| `borderWidth` | `2` |
| `pointRadius` | `3` |
| `pointHoverRadius` | `5` |
| `pointBackgroundColor` | `#00D4AA` |
| Y-Achse Min/Max | `0` / `100` (Kaufbereitschaft ist Prozent) |
| Y-Achse Grid | `rgba(0,0,0,0.06)` |
| Y-Achse Ticks-Color | `#6B7280` / 12px Inter |
| X-Achse Label | Zeit in Sekunden (0s, 30s, 60s ...) oder Datenpunkt-Index wenn Timestamps fehlen |
| X-Achse Grid | `false` (weniger Noise) |
| X-Achse Ticks-Color | `#6B7280` / 12px Inter |
| Legend | `display: false` (nur eine Linie, Titel der Card reicht) |
| Tooltip-Background | `#FFFFFF` |
| Tooltip-Border | `#E2E8F0` 1.5px |
| Tooltip-Text | `#1a1a1a` |
| Responsive | `true` (Chart.js-Default) |

**Datenquelle:** `conv.kb_verlauf` (TEXT JSON nach DB-Migration) — Array von `{t: seconds, v: 0-100}` oder `{v: 0-100}` (Index als X). Wenn `kb_verlauf` null/leer: Chart ausblenden, Empty-State-Block rendern.

**Kein Score-Donut.** (CONTEXT erwaehnt "evtl. Score-Donut" — Entscheidung in UI-SPEC: nein. Score-Hero zeigt grosse Zahl + Mini-Bars pro Komponente, das ist visuell ausreichend und spart einen zweiten Canvas.)
