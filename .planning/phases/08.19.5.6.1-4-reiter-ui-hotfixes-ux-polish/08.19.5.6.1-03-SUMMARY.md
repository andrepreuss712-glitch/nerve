# Plan 08.19.5.6.1-03 — WR-01/WR-02/WR-03 Gap Closure

## Changes Applied

### WR-01 — Pitch-only scenario fix in `_initTeleprompter()` (lines 2467–2481)

**Problem:** `_initTeleprompter()` never resolved `selectedPitchId` into `inhalt`. Pitch-only selection (no Skript, no Opener, no Erlaubnisfrage) showed "Kein Skript hinterlegt" instead of the Pitch text.

**Fix A** (line ~2467): Added Pitch resolution block after Skript resolution:
```js
// WR-01: Pitch als Fallback wenn kein Skript selektiert
if (!inhalt && !state.selectedSkriptId && state.selectedPitchId) {
  var selPitch = (state.openerItems || []).find(function (o) { return o.id === state.selectedPitchId; });
  if (selPitch) inhalt = selPitch.inhalt || '';
}
```

**Fix B** (line ~2477): Added `var hasPitch = !!state.selectedPitchId;` and extended early-return guard:
```js
if (!hasOpener && !hasErlaubnis && !hasPitch) {  // was: !hasOpener && !hasErlaubnis
```

**Fix C**: Removed misleading comment that claimed Pitch was already handled in the existing block.

### WR-02 — `_wireInlineEdit()` state corruption guard (line 1214)

**Problem:** All three inline-edit buttons (opener, erlaubnis, pitch) called `_wireInlineEdit()` with `type='opener'`. The guard `if (type === 'opener')` fired for erlaubnis/pitch edits, overwriting `state._editedOpenerText` with unrelated tab content.

**Fix** (line 1214):
```js
// was: if (type === 'opener') state._editedOpenerText = newText;
if (type === 'opener' && state.activeTab === 'opener') state._editedOpenerText = newText;
```

### WR-03 — `r.ok` checks on both `/api/precall/personalize/save` fetch chains

**Problem:** Both `.then(function(r) { return r.json(); })` calls had no `r.ok` check. HTTP 4xx/5xx responses with non-JSON bodies would reach `.then(data =>)` and not be caught by `.catch()`.

**Fix** (line 669 — `_savePersonalizedAndStartCall`):
```js
.then(function (r) { if (!r.ok) throw new Error('HTTP ' + r.status); return r.json(); })
```

**Fix** (line 815 — cap-delete-save handler):
```js
.then(function (r) { if (!r.ok) throw new Error('HTTP ' + r.status); return r.json(); })
```
