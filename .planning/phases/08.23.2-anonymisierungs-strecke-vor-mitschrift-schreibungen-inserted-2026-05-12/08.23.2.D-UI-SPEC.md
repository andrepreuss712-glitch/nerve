## Component Inventory

New components required for this phase. All use existing `nerve.css` CSS custom properties.

### 1. PostCall Outcome Section (PiP overlay)

Rendered inside the existing `nlp-section-postcall` panel in `pip-launcher.js`.

**High confidence (> 0.90) — Auto-confirm state:**
- Layout: `n-glass` card, 16px padding, full-width inside postcall section
- Outcome label: 14px/400, color `--page-text-secondary`
- Outcome value: 14px/600, color `--page-text-color`, uppercase
- Countdown ring: 28px circular SVG ring, stroke `#00D4AA`, background `rgba(0,212,170,0.1)`, 30-second countdown
- Countdown text: JetBrains Mono 600 28px centered inside ring
- "Bestätigt in Xs"-label: 11px/600 `--page-text-secondary` below ring
- Auto-confirm triggers silently — no modal, no user action needed

**Medium confidence (0.70–0.90) — Auto-confirm + Dashboard marker:**
- Same as high-confidence layout
- Additional badge: pill badge `ai_auto_unsicher` with `--warning-bg` (#f59e0b) background at 8% opacity, text `#f59e0b`, label "Unsicher — wird im Dashboard markiert"
- Badge: `--badge-radius: 9999px`, padding `3px 10px`, size 11px/600

**Low confidence (< 0.70) — Correction modal:**
- Layout: `n-glass` card replacing the auto-confirm ring
- KI-Vorschlag label: 11px/600/uppercase `--page-text-secondary`
- KI-Vorschlag value: 14px/600 `--page-text-color`
- Subheading: 12px/400 `--page-text-secondary` "Bitte korrigieren:"
- 5 outcome correction buttons in a 2+3 grid (or single column on narrow PiP):
  - Button style: `n-btn-ghost` pill, 44px min-height, 14px/600
  - Values: `meeting_booked` / `callback` / `no_interest` / `wrong_person` / `contract_signed`
  - Display labels (German): "Termin gebucht" / "Rückruf" / "Kein Interesse" / "Falsche Person" / "Abschluss"
  - Active/selected state: `--btn-primary-bg-from` background, white text
  - On click: immediately locks selection, sends correction to backend

### 2. Outcome Note Textarea (PiP postcall section)

Rendered below the outcome section in the postcall panel.

- Label: "Notiz (optional)" — 12px/700/uppercase, spacing 0.5px, `--label-color`
- Textarea: `n-input` styles — background `--input-bg`, border `--input-border`, focus border `--input-border-focus`, radius 12px, padding 12px/16px
- Placeholder text: "Stichworte zum Gespräch…" (echte Umlaute — user-facing)
- Height: 3 rows default, non-resizable (resize: none)
- Subtext: 11px/400 `--page-text-muted` "Wird vor dem Speichern anonymisiert."
- No character counter needed

### 3. Live Audio Health Warning (PiP header area)

Transient indicator, appears and disappears.

- Trigger: Socket.IO `audio_health_warning` event
- Position: Adjacent to the existing microphone/session-status area in PiP header
- Indicator: Lucide `mic-off` icon, 16px, tinted `#f59e0b`
- Tooltip: `data-tip="Audio-Qualität schlecht"` — use existing `_tooltip.html` pattern
- Duration: Visible 5 seconds, then auto-hides (CSS transition `opacity 0.3s ease`)
- Animation: pulse animation (1.5s ease-in-out infinite, opacity 1.0 → 0.5) while visible
- No Vollbild-Modal, no call interruption
- Hysteresis enforced in JS — second appearance blocked until score > 0.80

CSS class: `.pip-audio-warn` — new utility class added inline in pip-launcher.js template section or in nerve.css.

### 4. Dashboard Outcome Reminder Card

New card in `dashboard.html`, rendered conditionally by Jinja2 when `unsichere_outcomes_count > 0`.

- Position: Top of the session history section, below the weekly KPI row
- Layout: Horizontal stripe card — left border 4px solid `#f59e0b`, background `rgba(245,158,11,0.04)`, border `rgba(245,158,11,0.15)`, radius 12px, padding 16px
- Icon: Lucide `alert-circle` 20px, color `#f59e0b`, left-aligned
- Heading: "{{ unsichere_outcomes_count }} Anruf-Outcome{{ 's' if unsichere_outcomes_count != 1 }} warten auf Bestätigung" — 14px/600 `--page-text-color`
- Body: "Letzte 7 Tage — klicke auf einen Anruf um den Outcome zu korrigieren." — 12px/400 `--page-text-secondary`
- No close/dismiss button — card disappears automatically when all unsichere Outcomes in 7 days are confirmed
- Cursor: default (informational, not a clickable link itself)

### 5. Dashboard Yellow Dot + Inline Correction

Within the existing `.db2-session-row` calls-list rows in `dashboard.html`.

**Yellow dot:**
- Element: `<span class="outcome-unsicher-dot">` — 10px diameter, background `#f59e0b`, border-radius 50%, display `inline-block`, vertical-align middle, margin-left 6px
- Rendered only when `call.outcome_source == 'ai_auto_unsicher'`
- No dot for `ai_auto` or `user_corrected` entries

**Outcome label:**
- Existing row text area — add outcome value text (e.g. "Termin gebucht") in 12px/400 `--page-text-secondary`

**Inline correction (on yellow-dot click):**
- Trigger: click on the yellow dot
- Pattern: inline expand below the row — smooth `max-height` CSS transition (0.25s ease)
- Content: Row of 5 `n-btn-ghost` pill buttons (same labels as PiP correction modal) — 12px/600, 36px height
- On selection: row collapses, yellow dot disappears, outcome label updates in-place
- No confirmation dialog needed — action is reversible by clicking another option

## Interaction States

### Auto-Confirm Countdown (30s)
- **Idle (counting down):** Ring animates, counter decrements each second
- **User clicks elsewhere / interacts:** Timer pauses; if user clicks a correction button, timer cancels permanently
- **Timer reaches 0:** Outcome saved with `outcome_source = 'ai_auto'`; ring replaced by teal confirmation badge "Bestätigt"

### Audio Health Warning (PiP)
- **Normal (score >= 0.80):** No indicator shown
- **Warning triggered (score < 0.70):** `.pip-audio-warn` appears with pulse animation
- **Auto-hide:** After 5 seconds, opacity fades to 0, element removed from layout
- **Suppressed state:** JS sets `_audioWarnSuppressed = true` after first warning; next warning only allowed when score passes 0.80 again

### Outcome Correction Inline (Dashboard)
- **Collapsed:** Single-row display, yellow dot visible
- **Expanded (dot clicked):** Row expands, 5 correction buttons visible
- **Button hovered:** Ghost button hover state — `--btn-ghost-bg-hover`
- **Button selected:** Teal primary fill, white text, immediate collapse + save
- **Saving state:** Row shows 11px spinner or opacity 0.6 for 300ms while PATCH request resolves
- **Save complete:** Yellow dot disappears, outcome label updates in-place with new value
