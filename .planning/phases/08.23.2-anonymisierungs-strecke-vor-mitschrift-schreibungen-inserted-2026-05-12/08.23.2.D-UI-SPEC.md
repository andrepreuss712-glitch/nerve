### 3. Live Audio Health Warning (PiP header area)

Transient indicator, appears and disappears.

- Trigger: Socket.IO `audio_health_warning` event
- Position: Adjacent to the existing microphone/session-status area in PiP header
- Indicator: Lucide `mic-off` icon, 16px, tinted `#f59e0b`
- Tooltip: `data-tip="Audio-Qualität schlecht"` — use existing `_tooltip.html` pattern
- Duration: Visible 5 seconds, then auto-hides (CSS transition `opacity 0.3s ease`)
- Animation: pulse animation (1.5s ease-in-out infinite, opacity 1.0 → 0.5) while visible
- No Vollbild-Modal, no call interruption
- Hysteresis enforced in JS — second appearance blocked until score > 0.80

CSS class: `.pip-audio-warn` — new utility class added inline in pip-launcher.js template section or in nerve.css.

- **Brand-Korrektur 2026-05-26:** Vorher `#f59e0b` (Warning-Yellow). Stripe-Struktur identisch zu `.n-backup-warning`-Pattern, aber Brand-Teal statt Warning-Yellow — keine echte Warnung, sondern Aufmerksamkeits-Marker für Korrektur-Möglichkeit. CLAUDE.md HART Punkt 8 Brand-Konsistenz.

## Interaction States

### Auto-Confirm Countdown (30s)
- **Idle (counting down):** Ring animates, counter decrements each second
- **User clicks elsewhere / interacts:** Timer pauses; if user clicks a correction button, timer cancels permanently
- **Timer reaches 0:** Outcome saved with `outcome_source = 'ai_auto'`; ring replaced by teal confirmation badge "Bestätigt"

### Audio Health Warning (PiP)
- **Normal (score >= 0.80):** No indicator shown
- **Warning triggered (score < 0.70):** `.pip-audio-warn` appears with pulse animation
- **Auto-hide:** After 5 seconds, opacity fades to 0, element removed from layout
- **Suppressed state:** JS sets `_audioWarnSuppressed = true` after first warning; next warning only allowed when score passes 0.80 again

### Outcome Correction Inline (Dashboard)
- **Collapsed:** Single-row display, Unsicher-Marker (Teal-Outline-Kreis) visible
- **Expanded (Marker clicked):** Row expands, 5 correction buttons visible
- **Button hovered:** Ghost button hover state — `--btn-ghost-bg-hover`
- **Button selected:** Teal primary fill, white text, immediate collapse + save
- **Saving state:** Row shows 11px spinner or opacity 0.6 for 300ms while PATCH request resolves
- **Save complete:** Unsicher-Marker disappears, outcome label updates in-place with new value
