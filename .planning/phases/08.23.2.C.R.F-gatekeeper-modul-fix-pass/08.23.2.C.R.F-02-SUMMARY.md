# Phase 08.23.2.C.R.F Plan 02: iOS Toggle Switch fuer pip-mode-indicator

**One-liner:** iOS-style sliding toggle (28x16px track + 10px knob, 3-state: gatekeeper/target/meeting) ersetzt das unsichtbare Pill/Badge-Design des pip-mode-indicators, mit korrigierten CSS-Tokens und Meeting-Track-Hide-Logik.

## What Was Built

### Task 1 — base.html
Der `<button id="pip-mode-indicator">` erhaelt drei Kinder-Elemente ohne Whitespace-Textknoten:
- `<span class="pip-toggle-track" aria-hidden="true">` — der Track (CSS-gesteuert)
- `<span class="pip-toggle-knob">` — der Knob (verschiebt sich per translateX)
- `<span class="pip-toggle-label">Sekretär</span>` — das Label (JS-Ziel)

### Task 2 — nerve.css + pip-launcher.js

**nerve.css:** Vollstaendiger Ersatz des alten Pill/Badge-Blocks (~40 Zeilen) durch iOS-Toggle-CSS (~70 Zeilen):
- `.pip-toggle-track`: 28x16px, border-radius 8px, Transition fuer Hintergrund + Border
- `.pip-toggle-knob`: 10px Kreis, position:absolute, Transition fuer transform + Hintergrund
- `.pip-toggle-label`: Farbe via `var(--page-text-secondary)` (Token-Fix)
- `[data-mode="gatekeeper"]`: Track blau (pip-gatekeeper-bg), Knob rechts (translateX(12px)), Label blau
- `[data-mode="meeting"]`: Track `display:none`, Label in Brand-Teal (btn-primary-bg-from)
- Hover-Effekt via `#pip-mode-indicator:hover .pip-toggle-track`

**pip-launcher.js:** `_updateContactCategory` nutzt jetzt `querySelector('.pip-toggle-label')` statt `indicator.textContent` direkt. Else-Fallback fuer T-RF-07 Null-Safety (querySelector gibt null wenn DOM-Struktur fehlt).

## Cross-AI Review Fixes (beide MEDIUM umgesetzt)

**Token-Fix:** Urspruenglicher Plan hatte `var(--text-muted)` / `var(--text-secondary)` — diese Tokens existieren nicht in :root. Korrigiert auf `var(--page-text-muted)` / `var(--page-text-secondary)` (bestaetigt nerve.css Zeilen 18-19). Kein Fallback-Wert noetig.

**Meeting-Mode-Fix:** 3-State-Logik (gatekeeper/meeting/target) nicht auf binaeren Toggle mappen. Meeting blendet den Track aus (`display:none`) und zeigt Label in Brand-Teal — kommuniziert "gesperrter Zustand / andere Kategorie" klar.
