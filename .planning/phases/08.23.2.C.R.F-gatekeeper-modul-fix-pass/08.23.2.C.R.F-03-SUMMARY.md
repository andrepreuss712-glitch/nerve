### Task 1: Vollstaendiger Ersatz der Testdatei

Die alten Tests hatten zwei fundamentale Qualitaetsprobleme (Cross-AI-Review HIGH):

**Alter Test 1 (`test_mode_switch_event_payload_fields`):** Instanziierte `CallEvent` manuell und pruefte Felder direkt — ohne den Handler aufzurufen. Testete nur dass Python Objekte erstellen kann, nicht dass der Handler-Code korrekt funktioniert. Dead-Code-safe, logik-blind.

**Alter Test 2 (`test_mode_initial_event_payload_fields`):** Dasselbe Muster fuer `mode_initial` — kein Handler-Aufruf, reiner Objekt-Konstruktions-Test.

```python

register_audio_handlers(mock_sio)
handler = registered['manual_mode_toggle']
```
