## state dict Strategie

| Option | Description | Selected |
|--------|-------------|----------|
| Nested: `_session_state[sid]['state']` | 1:1 Sub-Key — minimaler Diff, Caller-Pattern bleibt ähnlich | ✓ |
| Flat-Merge in `_session_state[sid]` | Alle ~30 Felder direkt promoten — sauber aber großer Diff + Overlap-Auflösung | |
| Eigener `_per_sid_state` dict | Separates Dict mit eigenem Lock — analog zu `_per_sid_transcript` | |

**User's choice:** Nested: `_session_state[sid]['state']`
**Notes:** Minimaler Caller-Diff als Entscheidungskriterium.
