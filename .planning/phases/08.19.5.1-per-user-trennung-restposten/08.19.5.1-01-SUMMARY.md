# Phase 08.19.5.1 Plan 01: Per-User-Trennung Restposten Summary

**One-liner:** WR-01 + WR-02 nachmigiert — `_write_ft_assistant_event` liest Session-Kontext per-SID aus `_session_state[sid]` statt globalem `ls.state`; `analyse_loop` Learning-Cards-Read ebenfalls per-SID isoliert; 10/10 Tests gruen.

## What Was Built

### WR-01: `_write_ft_assistant_event` per-SID Migration

**File:** `services/claude_service.py` lines 142-221

- Signatur um `sid: str | None = None` erweitert
- Return-Early bei `sid=None` mit `print('[FT] skip — no sid for module={module}')` (D-01)
- Ersetzte `with ls.state_lock: ls.state.get(...)` durch `with ls._session_state_lock: ls._session_state.get(sid, {})`
- Top-level Keys: `user_id`, `market`, `language`, `mode` aus `_session_state[sid]`
- Sub-Keys: `ft_session_id`, `kaufbereitschaft` aus `_session_state[sid]['state']`
- `if ft_session_id is None or user_id is None: return` bleibt unveraendert (greift jetzt auf per-SID Werte)

**Caller-Updates:**
- `analyse_loop` (~Zeile 1008): `sid=sid` hinzugefuegt
- `coaching_loop` (~Zeile 1557): `sid=sid` hinzugefuegt

### WR-02: `analyse_loop` Learning-Cards-Read per-SID

**File:** `services/claude_service.py` line 924

Ersetzte:
```python
with ls.state_lock:
    _lk_cards = ls.state.get('active_learning_cards', [])
```
durch:
```python
with ls._session_state_lock:
    _lk_cards = ls._session_state.get(sid, {}).get('state', {}).get('active_learning_cards', [])
```
