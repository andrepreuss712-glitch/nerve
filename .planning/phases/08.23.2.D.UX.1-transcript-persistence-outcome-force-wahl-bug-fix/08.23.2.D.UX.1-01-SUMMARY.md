## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug in plan snippet] func.now() instead of text('now()')**
- **Found during:** Task 3 (server deploy — staging crash-loop)
- **Issue:** The `text` column attribute shadows the imported sqlalchemy `text()` within the class body → `server_default=text('now()')` called the Column object → TypeError, crashing models.py import.
- **Fix:** Use `func.now()` (module-level, unshadowed). DDL-equivalent to migration's `DEFAULT now()`.
- **Committed in:** `31c0881`

**2. [Rule 2 - Missing critical] ALTER TABLE OWNER TO nerve_app**
- **Found during:** Task 3 (privilege check before applying)
- **Issue:** nerve_app lacks CREATE on schema public → migration must run as postgres → table would be postgres-owned → app (nerve_app) could not read/write it (permission denied class).
- **Fix:** Added `ALTER TABLE public.transcript_segments OWNER TO nerve_app` (consistency with calls/conversation_logs, both nerve_app-owned).
- **Committed in:** `35f2da1`
