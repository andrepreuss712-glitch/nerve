**Create-table + CHECK + index pattern** (from 0008 Z.28-46 — note: `op.execute` with raw SQL is the house style for Postgres-specific DDL, NOT `op.create_table`; 0008 uses BIGSERIAL + TEXT + CHECK(speaker IN ...) + TIMESTAMPTZ DEFAULT now() verbatim, which is exactly the DA-02 schema):
```python
def upgrade() -> None:
    op.execute("""
        CREATE TABLE IF NOT EXISTS public.transcript_segments (
            id                  BIGSERIAL   PRIMARY KEY,
            conversation_log_id INTEGER     NOT NULL
                                REFERENCES conversation_logs(id) ON DELETE CASCADE,
            ts_ms               INTEGER     NOT NULL,
            speaker             TEXT        NOT NULL
                                CHECK (speaker IN ('berater', 'kunde', 'system')),
            text                TEXT        NOT NULL,
            created_at          TIMESTAMPTZ DEFAULT now()
        )
    """)
    op.execute(
        "CREATE INDEX IF NOT EXISTS idx_transcript_segments_conv_ts "
        "ON public.transcript_segments (conversation_log_id, ts_ms)"
    )
    # GRANT for the DPO/anon worker — 0008 Z.41-46 + 0009 explicitly DEFER this grant to D.UX.1.
    # 0009 docstring: "GRANT on public.transcript_segments (reserved for D.UX.1 in 0008's note)
    #                  is NOT here — that table still does not exist."
    # So 0010 MUST add it (mirror 0008's GRANT SELECT lines):
    op.execute("GRANT SELECT ON public.transcript_segments TO nerve_anon_worker")
    # If the anon worker INSERTs (Variante A double-write goes to training.* not here),
    # SELECT-only is correct — verify against DA-06 (worker reads public, writes training).
```

**Downgrade pattern** (0008 Z.54-63 — reverse order, REVOKE before DROP, IF EXISTS guards):
```python
def downgrade() -> None:
    op.execute("REVOKE SELECT ON public.transcript_segments FROM nerve_anon_worker")
    op.execute("DROP INDEX IF EXISTS idx_transcript_segments_conv_ts")
    op.execute("DROP TABLE IF EXISTS public.transcript_segments")
```

> **0008/0009 batch-alter alternative:** for ALTER TABLE 0008 uses `with op.batch_alter_table('users') as batch_op:` (Z.47-51). 0010 is a pure CREATE so it does NOT need batch mode. Mention this so the planner does not over-engineer.

**CheckConstraint + Index in `__table_args__`** (CallEvent Z.710-715 + Call Z.678-697 are the canonical examples):
```python
class TranscriptSegment(Base):
    __tablename__ = 'transcript_segments'
    id                  = Column(BigInteger, primary_key=True, autoincrement=True)
    conversation_log_id = Column(Integer, ForeignKey('conversation_logs.id', ondelete='CASCADE'), nullable=False)
    ts_ms               = Column(Integer, nullable=False)        # ms ab Call-Start, fuer Reihenfolge
    speaker             = Column(Text, nullable=False)           # 'berater'|'kunde'|'system'
    text                = Column(Text, nullable=False)           # anonymisierter Text (Pipeline B)
    created_at          = Column(DateTime(timezone=True), server_default=text('now()'))
    __table_args__ = (
        CheckConstraint("speaker IN ('berater', 'kunde', 'system')", name='ck_transcript_segments_speaker'),
        Index('idx_transcript_segments_conv_ts', 'conversation_log_id', 'ts_ms'),
    )
```

> **Server-default note:** ConversationLog uses `Column(DateTime, default=utcnow)` (Python-side, Z.307). Migration 0008 uses `TIMESTAMPTZ DEFAULT now()` (DB-side). For TIMESTAMPTZ-with-DB-default the Call model uses `DateTime(timezone=True)` + `server_default`. `text` is already imported (models.py Z.2). Pick DB-side `server_default=text('now()')` to match the migration's `DEFAULT now()` exactly (keeps ORM and DDL consistent — Punkt 21).
> **ASCII rule:** attribute names `ts_ms`, `speaker`, `text`, `conversation_log_id` are all ASCII — compliant. Speaker *values* `'berater'/'kunde'/'system'` are data, already ASCII in 0008.
