**Aenderung A — _updateSliderFill-Helper (neu, z.B. direkt oberhalb _initOpacitySlider oder als innere Funktion):**

```javascript
function _updateSliderFill(slider) {
  if (!slider) return;
  var min = parseFloat(slider.min) || 0;
  var max = parseFloat(slider.max) || 100;
  var val = parseFloat(slider.value);
  if (!isFinite(val)) val = max;
  var pct = ((val - min) / (max - min)) * 100;
  pct = Math.min(100, Math.max(0, pct));
  slider.style.setProperty('--pip-slider-pct', pct + '%');
}
```

**Aenderung B — localStorage-Read-Clamp + _updateSliderFill-Integration in _initOpacitySlider:**
