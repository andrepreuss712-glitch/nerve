## Architektur-Entscheidungen der Session (wichtig für morgen)

1. **Manual-EWB trennt instant vom KI-Flow** — Profil-Default ist immer verfügbar, Claude ist Nice-to-have. Wenn Haiku überlastet ist, Slot 0 rettet die Usability.
2. **EWB-Label-Chain strikt zweistufig**: `kurzlabel > kategorie`. Kein Name, kein einwand-Truncate. User pflegt Kurzlabels → mehr Buttons. User pflegt nicht → Kategorien kollabieren bewusst.
3. **WebSocket statt Polling**: nicht forcieren (`['websocket','polling']`), Fallback-Chain intakt falls Kunde hinter ungünstiger Proxy sitzt.
4. **Event-Delegation am pip-Document**: Capture-Phase, ein Listener für alle Click-Targets. Überlebt jede DOM-Mutation.
5. **`chown www-data` in deploy.sh**: tar-over-ssh von Windows kann 197609-UIDs mitbringen. Post-deploy-chown ist jetzt fix im Skript.
6. **PiP-Größe bleibt konstant 480×900**: Chrome ignoriert `resizeTo`/zweites `requestWindow` mit neuen Dimensions.
