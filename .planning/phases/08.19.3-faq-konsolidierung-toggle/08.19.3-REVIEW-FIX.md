### WR-02: `_pitch_dual_write` silent failure logging

**Files modified:** `routes/profiles.py`

### WR-03: `resp.content[0]` access without length guard in `claude_service.py`

**Files modified:** `services/claude_service.py`
**Commit:** 938c7e2
**Applied fix:** Added `if not resp.content` / `if not msg.content` guards with a `print(f"[claude] empty content from API (module=...)")` log line before each `.content[0].text` access at all three sites:
- `classify_phase` (was `resp.content[0]`) — returns `None` on empty
- `infer_customer_state` (was `resp.content[0]`) — returns `None` on empty
- `analysiere_mit_claude` (was `msg.content[0]`) — returns `{}` on empty

Return values match each function's documented failure contract.

### WR-04: DOM stale reference guard in `_revertAndNotify`

**Files modified:** `static/profile_editor.js`
**Commit:** ad02e8b
**Applied fix:** Added `if (!document.body.contains(row)) return;` as the first line of `_revertAndNotify()`. If the FAQ row has been removed from the DOM (e.g., by a concurrent `loadFaqs()` re-render in another tab), the revert silently no-ops instead of writing to a detached DOM element.
