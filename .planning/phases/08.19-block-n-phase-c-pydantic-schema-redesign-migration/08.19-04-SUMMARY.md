## Implemented

### templates/profile_wizard.html

**Chip-Select Block (Step 2, nach Zielkunden-Input):**
- 5 `.groesse-chip`-Divs mit onclick-Werten exakt gleich UnternehmensgroesseEnum Literals: `'<10'`, `'10-50'`, `'50-250'`, `'250-1000'`, `'1000+'`
- HTML-Entity `&lt;` nur im sichtbaren Text-Content (`&lt;10 MA`), NICHT im onclick-String
- Hidden input `name="unternehmensgroesse"` `id="unternehmensgroesseInput"`
- UI-Hint per D-03 exakter Wortlaut: "Mehr Profil-Details = besseres Live-Coaching. Du kannst auch später ergänzen unter Profil → Tiefe."

**JS — selectGroesse():**
- Entfernt `.selected` von allen `.groesse-chip`-Elementen
- Setzt `.selected` auf geklickten Chip
- Schreibt Enum-Wert in hidden input
- Loescht boxShadow-Highlight (UX-Verbesserung: Feedback bei korrekter Auswahl)

**JS — initGroesseChip() (Reviews v2 DOM-State-Init):**
- Liest Wert aus `unternehmensgroesseInput`
- Falls vorhanden: sucht Chip mit passendem onclick-String und setzt `.selected`
- Wird direkt nach Funktionsdefinition aufgerufen (kein DOMContentLoaded-Wrapper noetig)

**nextStep() — Validation Step 2→3:**
- Prueft `unternehmensgroesseInput.value` vor Step-3-Uebergang
- Bei leerem Wert: `groesseGrid.style.boxShadow = '0 0 0 2px var(--n-accent)'` + `return` (kein Uebergang)
