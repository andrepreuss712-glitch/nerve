## Pydantic Strict vs. Permissive Mode

*User-initiierter Diskussionspunkt (Punkt 5)*

| Option | Description | Selected |
|--------|-------------|----------|
| Strict Write / Permissive Read | `extra='forbid'` beim Speichern; `extra='ignore'` beim Laden (nach Migration) | ✓ |
| Strict ueberall | Harte Validierung in beide Richtungen | |
| Permissive ueberall | Kein extra='forbid', maximale Flexibilitaet | |

**User's choice:** Strict Write, Permissive Read
**Notes:** Alte Profile vor 08.19 haben Drift-Felder (z.B. zielgruppe.alter) die im neuen Schema fehlen — Strict bei Read waere Selbst-Sabotage. Strict bei Write verhindert kuenftige Drift-Erzeugung. Test: alle 4 Profile nach Migration mit model_validate(strict=True) prueferbar.
