### Task 1 — Migration 0012 (`9569243`, GIN parity in `821f43a`)
`alembic/versions/0012_crm_schema_tables_rls.py`, `revision='0012'`, `down_revision='0011'`. All-ASCII identifiers.
- **Step A — schema + grants** (mirror proven 0008/0009): `CREATE SCHEMA IF NOT EXISTS crm`; `GRANT USAGE` to nerve_app + nerve_anon_worker; `ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA crm GRANT SELECT,INSERT,UPDATE,DELETE ON TABLES TO nerve_app` (+ sequences); `GRANT SELECT ON TABLES TO nerve_anon_worker`. **NO `ALTER ROLE nerve_app NOBYPASSRLS`** and **NO `ALTER ROLE nerve_app SET search_path`** (proven unnecessary; documented in docstring). Owner-split kept (postgres-owned, NO `ALTER TABLE crm.* OWNER TO nerve_app`).
- **Step B — 4 tables** born with `tenant_id UUID NOT NULL REFERENCES public.tenant_orgs(id)`: `accounts`, `contacts`, `account_memory` (schema_version SMALLINT, meddpicc/context_hooks JSONB, last_call_summary, `anonymized_at TIMESTAMPTZ` (Variante A), CHECK(account_id OR contact_id)), `meetings` (call_id soft link, NO FK — D-08). `gen_random_uuid()` core on PG 16.14.
- **Step C — RLS per table**: `ENABLE` + `FORCE ROW LEVEL SECURITY`; `CREATE POLICY tenant_isolation ... USING (tenant_id = current_setting('app.tenant_id', true)::uuid) WITH CHECK (...)`; `idx_<table>_tenant`.
- **Step C.2 — FK-column indexes**: idx_account_memory_account_id, idx_account_memory_contact_id, idx_meetings_account_id, idx_meetings_contact_id, idx_contacts_account_id.
- **Step C.3 — GIN index** on `crm.account_memory(meddpicc)` (added for DDL/ORM parity — Rule 2).
- **downgrade()** symmetric: drops indexes (incl. GIN) → policies + tenant indexes → tables (reverse FK order) → revoke grants → DROP SCHEMA.

### Task 3 — Session tenant-UUID + transaction-local GUC (`2139f08`)
- `database/db.py`: `_current_tenant_id` contextvar + `set_current_tenant()` / `clear_current_tenant()` helpers + a `Session` `after_begin` event hook (Postgres-dialect-gated) issuing **parameterized** `SELECT set_config('app.tenant_id', %s, true)` via `connection.exec_driver_sql` (third arg `true` = transaction-local; bound param → injection-safe, T-G2-05). The SET fires at transaction begin on the same connection ⇒ SET and tenant queries share ONE transaction (B-1 fix). NO checkin RESET (SET LOCAL auto-clears at COMMIT/ROLLBACK; documented), pooler-agnostic, worker-thread-safe.
- `routes/auth.py` `_login_user`: resolve `tenant_orgs.id WHERE legacy_org_id = user.org_id`, store `session['tenant_id']` (string UUID or None; non-fatal — missing row → RLS fails closed).
- `app.py` `before_request _load_user`: publish `session['tenant_id']` into the contextvar on EVERY request (before any early return); `teardown_request` clears it (hygiene).
