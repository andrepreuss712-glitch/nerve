**Raw-DDL via op.execute + IF NOT EXISTS** (0008:27-40 pattern). For `tenant_orgs` (placement: `public` per RESEARCH A5/Punkt-2 note — it is tenancy infra; `calls.tenant_id` FK stays intra-public):

### `alembic/versions/0012_*.py` — Wave 2 migration (crm schema + tables + RLS + grants + role restrict)

**Analog:** `0008` (CREATE SCHEMA + grants + ALTER DEFAULT PRIVILEGES) + `0010` (OWNER assignment + index).

**Schema + grants block — MIRROR the proven training pattern** (RESEARCH §5, derived from 0008:27/41 + 0009:33-37). Runs as `postgres` (migration owner):
```python
op.execute("CREATE SCHEMA IF NOT EXISTS crm")
op.execute("GRANT USAGE ON SCHEMA crm TO nerve_app")
op.execute("ALTER ROLE nerve_app SET search_path = crm, public")          # D-18.1 role-level
op.execute("ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA crm "      # D-18.2 — critical
           "GRANT SELECT, INSERT, UPDATE, DELETE ON TABLES TO nerve_app")
op.execute("ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA crm "
           "GRANT USAGE, SELECT ON SEQUENCES TO nerve_app")
op.execute("GRANT USAGE ON SCHEMA crm TO nerve_anon_worker")               # worker read
op.execute("ALTER DEFAULT PRIVILEGES FOR ROLE postgres IN SCHEMA crm "
           "GRANT SELECT ON TABLES TO nerve_anon_worker")
```
- **Owner split (load-bearing for D-16):** crm tables created by postgres are postgres-owned → nerve_app gets DML via ALTER DEFAULT PRIVILEGES but NOT ownership → does NOT bypass RLS. This is the INVERSE of public tables (which nerve_app owns — 0010:36-40 had to `OWNER TO nerve_app` deliberately). **Do NOT `ALTER TABLE crm.* OWNER TO nerve_app`** on RLS tables.

**RLS per table** (RESEARCH §2, D-12.4/.5/.6). For each of accounts/contacts/account_memory/meetings:
```python
op.execute("ALTER TABLE crm.accounts ENABLE ROW LEVEL SECURITY")
op.execute("ALTER TABLE crm.accounts FORCE ROW LEVEL SECURITY")            # D-12.4 owner-bypass kill
op.execute("""
    CREATE POLICY tenant_isolation ON crm.accounts
      USING (tenant_id = current_setting('app.tenant_id', true)::uuid)
      WITH CHECK (tenant_id = current_setting('app.tenant_id', true)::uuid)
""")                                                                        # D-12.5 USING + WITH CHECK
op.execute("CREATE INDEX IF NOT EXISTS idx_accounts_tenant ON crm.accounts(tenant_id)")  # D-12.6
```
- Use `current_setting('app.tenant_id', true)` (missing_ok) → unset GUC yields NULL → 0 rows fail-closed, NOT an error (RESEARCH §2 D-12.1).
- **Verify + fix nerve_app BYPASSRLS** (RESEARCH A2, KNOWN GAP): first thing this migration / runbook does — `\du nerve_app` as postgres; if it has BYPASSRLS → `ALTER ROLE nerve_app NOBYPASSRLS`.

**account_memory CHECK + JSONB** — RESEARCH §6 verbatim sketch (lines 331-342). JSONB cols need `schema_version SMALLINT` (D-19). MEDDPICC 8 ASCII keys: `metrics, economic_buyer, decision_criteria, decision_process, paper_process, pain, champion, competition`.

**Index/JSONB DDL parity with ORM** — mirror `Call`/`CallEvent` style (models.py:694-696, 714: GIN index on JSONB via `postgresql_using='gin'`).

### RLS session GUC set/reset — `database/db.py` + `app.py` (Wave 2, infra hook, event-driven)

**Analog:** `database/db.py:20-24` — the ONLY existing `@event.listens_for(engine, ...)` hook (SQLite WAL on `connect`). Same mechanism, new events.

**Existing engine** (db.py:16): `engine = create_engine(_DATABASE_URL, connect_args=_connect_args)` — no pool events yet for checkout/checkin (greenfield wiring, but the event idiom is established).

**Pattern to add** (RESEARCH Open-Q 1, lines 256-266) — checkout SET + checkin RESET (the leakage killer, D-12.3):
```python
from sqlalchemy import event
@event.listens_for(engine, "checkin")
def _reset_tenant(dbapi_conn, conn_record):
    cur = dbapi_conn.cursor(); cur.execute("RESET app.tenant_id"); cur.close()
```
- Use `set_config('app.tenant_id', :uuid, false)` PARAMETERIZED on checkout/per-request — NEVER string-interpolate the UUID (SQL-injection).
- Belt-and-suspenders RESET also in `teardown_request` (Flask app-context boundary).
- **Worker-thread race** (RESEARCH §1 last bullet + Open-Q 4): live-session worker threads run outside the request that opened them — they must SET the GUC on their own connection or read 0 rows. Audit `services/live_session.py` against new crm table names; currently N/A (tables absent).

**Existing teardown reference** (db.py:38-43 `get_db` generator + 46-48 `get_session`): sessions are manually closed via try-finally (`db.close()`), not context-managed (CLAUDE.md Database Patterns). RESET must survive this manual model — hence the pool-`checkin` event, not just teardown.

### CSV-export endpoint (Wave 2, route, request-response → file-I/O)

**Analog:** `routes/admin_dashboard.py:712-754` — `_csv_response()` helper + `export_einnahmen_csv()`.

**Copy directly** (admin_dashboard.py:712-725):
```python
def _csv_response(rows, headers, filename):
    import csv
    from io import StringIO
    from flask import Response
    buf = StringIO()
    writer = csv.writer(buf, delimiter=';', quotechar='"', quoting=csv.QUOTE_MINIMAL)
    writer.writerow(headers)
    for row in rows: writer.writerow(row)
    data = '\ufeff' + buf.getvalue()  # UTF-8 BOM for Excel
    return Response(data, mimetype='text/csv; charset=utf-8',
        headers={'Content-Disposition': f'attachment; filename={filename}'})
```

## Shared Patterns

### get_session() try-finally (ALL service/route DB access)
**Source:** `database/db.py:46-48` + every consumer (precall_service.py:314-324, admin_dashboard.py:735-754, app.py:2200-2207).
**Apply to:** every new service/route touching DB. No context manager — manual `db.close()` in `finally` (CLAUDE.md Database Patterns:195-198).
```python
db = get_session()
try:
    ...
finally:
    db.close()
```

### Raw-DDL migration idiom
**Source:** `0008` / `0009` / `0010` — `op.execute("""...""")` for CREATE/GRANT/POLICY, `op.batch_alter_table` only for ALTER COLUMN. Revision chain `revision`/`down_revision` header. `IF NOT EXISTS` guards. Symmetric `downgrade()` REVOKE/DROP in reverse.
**Apply to:** all 3 new migrations.

### Error handling — swallow non-critical, never kill request
**Source:** `services/audit.py:24-26` (`except Exception: print(...)`), `app.py:2224-2245` (global JSON 500 handler, HTTPException passthrough), precall_service graceful degradation.
**Apply to:** anonymizer worker (per-record errors logged, batch continues), briefing extension (non-fatal account_memory read), trigger (idempotent).

### ASCII identifiers / German user-text split
**Source:** CLAUDE.md:103-141.
**Apply to:** ALL — DB column names, JSONB keys, dict keys, route slugs ASCII (`paper_process`, `economic_buyer`). User-facing strings keep Umlaute.

### Prefixed-tag logging
**Source:** CLAUDE.md:151-157; `[ANON]`, `[DB]`, `[PreCall]`, `[AUDIT]`.
**Apply to:** worker `[ANON]`, migrations runbook output.
