## (a) André-Direktive 2026-06-02: Firma = PFLICHTFELD (design change, both layers)

The original Plan 04/05 design allowed a blank Firma (→ `account_id` NULL, no accounts row). André changed
this: Firma is the key that later assigns the meeting to the right briefing (Phase MODES), so an orphan
meeting with `account_id` NULL is undesirable. Enforced on BOTH layers:
- **Frontend (Plan 05, `pip-launcher.js`):** Firma input carries `required aria-required="true"` + a visible
  `*` marker (`.n-meeting-required-mark`); `_onSaveMeeting()` blocks an empty Firma with an inline error
  ("Firma ist Pflicht.") and an early return — **no POST, input preserved** (Datum/Notiz behalten Werte).
- **Backend (`routes/crm_export.py` `save_meeting`, already live → redeployed):** empty firma → `400
  'Firma ist Pflicht'`, fail-closed BEFORE any DB write (defensive, in case a non-browser client posts).
- Ansprechpartner / Datum / Thema stay **optional** (no `required`).
